|---|---|---|

## 2. 현재 구현 상태 (Lobby.gd / Lobby.tscn)

**구현됨**
- 시설 5종 × 3단계 (왕좌/성벽/묘지/무기고/연회장) — **수치만**
- 인트로 슬라이드 4컷, 첫 로비 진입 가이드 1회
- 하단 슬라이드 패널 (시설 탭 → 업그레이드 UI)
- 해골 정원 — 위치 배치 + 색 틴트 + 등장 연출(`play_arrival`)
- 왕관 조각 카운터 / 해골 카운터 라벨
- 출정 버튼 (현재 챕터-스테이지 표기)

**미구현 (기획에는 있음)**
- ❌ 시설 시각 4단계 sprite (5시설 × 4단계 = 20장)
- ❌ 어둠의 제단 / 신앙 / 축복 시스템 **(돌봄 축 통째로 0%)**
- ❌ 해골 idle 작업 애니메이션 (장인 칼 갈기 등)
- ❌ 해골 외형 차별 (앞치마/후드/주걱)
- ❌ 해골 탭 시 시각 반응 (점프/손 흔들기)
- ⚠ 일일 출석 보상 — 로드맵 ✅인데 코드에 안 보임 (검증 필요)

## 3. 축별 진단

### 🔍 관찰 — *얕음*
- 해골이 정적. 색만 다름. *"누가 살고 있다"* 보다 *"점이 찍혀 있다"*에 가까움.
- 모바일 5~7분 세션에서 로비 체류 시간이 짧음 (출정 버튼이 빠르게 시야에 잡힘).
- 탭 반응 없음 → 인터랙션 0.

### 🤲 돌봄 — *비어 있음*
- 제단·신앙·축복 미구현. 축이 통째로 0%.
- 3축 중 1축이 작동 안 함 → 메타 루프가 기획 의도대로 굴러가지 않고 있음.
- 도입 시 추가 자원(신앙) + 추가 UI(제단/축복카드) 필요 — 무게 큼.

### 📈 성장 — *수치만, 시각 0*
- 왕관 조각 모아도 성은 폐허 그대로. **컨셉의 핵심 시각이 빠짐**.
- 수치 보상감은 패널의 텍스트로만 존재 ("최대 HP +50") — *전투에서 체감*되어야 의미가 산다.
- 메인 광고 컷·스토어 스크린샷이 *시설 변화*에서 나와야 하는 게임인데, 현재 자산으로는 그 컷 자체가 만들어지지 않음.

## 3.5 COL 참조 — 실제 메커니즘 정리

출처: Cult of the Lamb Fandom Wiki, Steam 베타·정식 가이드, Game Informer / Kotaku / The Gamer 기사.

### 자원 (다중·연쇄·압박)
- **신앙(Faith)** — 컬트원에게서 생성. 떨어지면 반란.
- **충성도(Loyalty)** — 컬트원 개별. 축복·돌봄·요구 응답으로 ↑.
- **헌신(Devotion)** — 종교 자원. 사원 업그레이드용.
- **일반 재료** — 나무·돌·고기·뼈. 건축·의식 재료.
- **골드** — 의식(십일조)·상점.
- → **늘 부족함. 의식 한 번이 큰 결정.**

### 일과 (매일 능동 운영)
- 컬트원 깨우기 → 작업 배정 (벌목/농사/요리/시신처리)
- 매일 1회 **설교** (사원) — 신앙 부스트
- 컬트원 개별 **축복** (충성도 ↑)
- **청소** (배설물 방치 시 신앙 ↓)
- **식사 제공** (굶기면 신앙 ↓)
- **의식** (특수 효과, 자원 大 소비)
- **선교지 파견** — 컬트원이 자원 가져옴 (실패 확률)

### 컬트원의 능동성
- 개별 특성·욕구·요구
- 만족 → 충성도 ↑ → 헌신 생산
- 불만 → 신앙 ↓ → 반란
- → **돌봄이 아니라 *경영 압박*. 컬트원은 인력이자 위협.**

### 교리(Doctrine)
- 컬트의 규칙 선택 (식인·이단처형·결혼 등) → 영구 효과 + 시각 변화

### 던전 ↔ 베이스 관계
- 던전 → 신규 컬트원·자원·교리 점수 획득
- 베이스 → 컬트원이 자원·헌신 *생산*
- → **양방향 의존**

## 3.6 우리 기획 vs COL — 갭 분석

| 항목 | COL | 우리 기획문서 §11 | 갭 |
|---|---|---|---|
| 메타 활동 빈도 | 매일 능동 운영 | 출정 사이 1회 축복 클릭 | **크다** |
| 자원 압박 | 늘 부족, 의식이 결정 | 왕관 조각만 — 모이면 쓰면 됨 | **크다** |
| 부하의 능동성 | 요구·반응·반란 | 정적, 색 틴트만 | **매우 크다** |
| 시각적 성장 | 건축 행위 자체가 액션 | 버튼 한 번 → 단계 변경 | **중간** |
| 메타 ↔ 전투 의존 | 양방향 | 단방향(메타→전투) | **크다** |

**진단**: 기획문서의 *"COL식 가벼운 이식"*은 사실상 **COL의 *시각적 결과물*만 흉내낸 패시브 시뮬레이션**. COL의 진짜 재미인 *능동 운영 루프*는 빠져 있다.

→ 진짜 결정 포인트는 *"3축이냐 2축이냐"*가 아니라 **"COL을 어디까지 이식할 것인가"**. 축 분할(B/C)은 그 결정 *위에서* 정해지는 하위 문제.

## 4. 검토 의제 (순서대로 결정 예정)

각 의제는 결론 나면 결정 로그(§5)에 박제하고 다음으로 넘어간다.

### Q1. COL을 어디까지 이식할 것인가? (메타 깊이)
§3.5/3.6 결과 — 진짜 결정은 *축 분할*이 아니라 *운영 깊이*.

| 안 | COL 이식 깊이 | 결과 |
|---|---|---|
| **α. 능동 운영 이식** | 컬트원 작업 배정·의식·요구 응답을 매 런 사이 실제로 함 | 깊이 ↑↑, 작업량 폭증, 캐주얼 디펜스 정체성 흔들림 |
| **β. 시각·서사만 이식** | 부하들이 *살아있는 분위기*만, 운영 메커니즘 없음 | MVP 정직, 깊이 ↓. 기획문서의 *"경영 + 전투"* 의도와 거리 |
| **γ. 절충 — 가벼운 능동 메타** | 출정 사이 *의미 있는 결정 액션 1~2개* (의식? 명령?) + 시각 살림 | 모바일 호흡에 맞춤, 깊이 중간. β보다 1단계 더 적극적 |

이전에 사용자가 유력 후보로 본 **B(2축 압축 = 성장+관찰)**는 사실상 β에 가깝다. γ로 가면 B 위에 *능동 결정 1~2개*가 얹힘.

### Q1.5 (Q1 결정 후) 축 분할 — B(2축) vs A(3축) vs C(1축)
Q1이 β/γ로 정해지면 그 위에서 *어떤 축에 자원을 쓸지* 정함.

### Q2. γ의 결정 액션은 어떤 형태인가? ← **현재 의제**
γ = "출정 사이 의미 있는 결정 1~2개". *어떤 결정 액션*을 넣을지가 핵심.

후보 (각각이 어느 축을 능동화하는지 표시):

| 후보 | 형태 | 능동화되는 축 | 비고 |
|---|---|---|---|
| **(a) 의식** | 매 런 전 어둠의 제단에서 의식 1개 선택, 자원 소비, 다음 런 효과 | 돌봄 + 성장 | 기획문서의 *축복*과 통합 가능 |
| **(b) 작업 배정** | 해골을 어느 시설에 둘지 매번 결정, 시설 효율 변동 | 관찰 (능동) + 성장 | 자동 배치 컨셉과 충돌, 결정 공간 큼 |
| **(c) 요구 응답** | 매 런 사이 해골 1명이 요구 (음식/장비/축복), 1탭 결정 | 관찰 (능동, 강력) | COL 핵심 감각 가장 잘 살림 |
| **(d) 교리** | 가끔 큰 영구 결정 (식인/순결 등) — *매 런*은 아님 | 성장 (능동) | 빈도 낮아 매 런 결정 공간엔 부적합 |

**조합 추천**: **(a) 의식 + (c) 요구 응답** — 의식은 *주 결정*(자원 압박), 요구 응답은 *관찰 축 능동화*. 둘 다 1탭, 모바일 적합.

자원 압박 메커니즘은 (a)와 함께 따로 논의 필요 (어떤 자원으로 압박을 만드는가).

### Q3. 의식 효과 카테고리 — 풀 디자인 (D3로 *전투 의식 상점* 메뉴가 됨)
의식이 *무엇을* 하는지 먼저 합의. 자원 결정(Q4)은 이 위에서.

**카테고리 후보**:
1. **다음 런 시작 부스트** — 시작 영혼/HP/해골/카드 등급 (기획문서 축복 그대로). 안전, 무게 낮음.
2. **다음 런 동안 변형** — 기본공격 연쇄 폭발, 소환 쿨 -2초 등. 스타일 변화. 무게 중.
3. **트레이드오프 의식 (COL식)** — 희생/맹세/광기/저주. *진짜 결정 공간*. 무게 ↑↑.
4. **영구 효과 (시설 별도 트랙)** — 시설과 차별 모호. ❌ 추천 안 함.
5. **메타 자원 변환** — 시스템 윤활용. 의식 메인 풀로는 ❌.

**풀 구성 후보**:

| 안 | 구성 | 결정 무게 | COL 가까움 |
|---|---|---|---|
| i. 부스트만 | 1번 5~6종 | 낮음 | × |
| ii. 부스트+스타일 | 1+2 각 3종 | 중 | △ |
| **iii. 부스트+트레이드오프** | 1+3 각 3~4종 | 중-상 | ✅ |
| iv. 전부 트레이드오프 | 3번 4~5종 | 상 | ✅✅ |
| v. 전부 혼합 | 1+2+3 각 2종 | 중-상 | ✅ |

**추천 — iii**. 매 런 *안전 부스트 vs 트레이드오프 도박* 선택 구조 → 진짜 결정 공간. 부스트만이면 "그냥 첫 번째" 위험. 트레이드오프만이면 모바일 캐주얼 정체성과 충돌.

**풀 예시 (iii, 6~8종, 매 런 3개 노출 → 1개 선택)**:
- *부스트*: 풍요(영혼+30) / 묘지(HP+50) / 어둠의부름(해골+1) / 어둠의시야(첫카드 고급)
- *트레이드오프*: 희생(HP-30/영혼+60) / 맹세(소환불가/특수기×2) / 광기(보스↑/보상×2) / 저주(드롭-20%/공격+30%)

### Q4. 의식이 소비할 자원 — 메타 자원 구조 (D3로 *영혼*이 유력 후보)
D3로 의식이 전투 상점이 됨 → *영혼*이 자연스러운 비용 자원. 신앙 자원 폐기 검토. 별도 의제로 계속 봄.

### Q5. 교리(Doctrine) 시스템 — 로비의 큰 결정 ← **새 의제 (D3 산물)**
COL식 영구 규칙 선택. 매 N스테이지 1회 정도. 로비 거점화의 핵심.

**디자인 변수**:
- *빈도*: 매 챕터 1회? 매 3스테이지? — 너무 자주면 무게 ↓
- *비용 자원*: 왕관 조각? 별도 자원?
- *풀*: 식인/순결/희생/평화 등 COL식 — 영구 효과 + 시각 변화
- *UI 거점*: 어둠의 제단 격상? 별도 거점?
- *되돌리기*: 가능/불가능 — COL은 가능(자원 소비), 우리는?

### Q6. 요구 응답 디자인 — 로비 관찰 축 능동화 (D2 c)
- *빈도*: 매 런? 2런마다?
- *요구 종류*: 자원/장비/축복/대화 등
- *응답*: Yes/No, 보상/페널티 비대칭

### Q7. 폴리싱 작업목록 (Q3~Q6 결론 후)
D2로 *의식*이 결정되면서 *소비 자원*을 정해야 함. 이벤트 노드 메모리 잠금 해제 트리거.

**현재 자원 상태**:
- 왕관 조각 (영구, 시설 업그레이드)
- 신앙 (누적, 캡 3, 축복 비용) ← *지금 비어 있는 시스템*
- 해골 (개수, 카드풀 단계 + 신앙 누적속도)

**원칙 후보**:
- 자원 수는 *늘리지 않는다* (메타 자원 풀어내기 메모리 진전과 일치)
- 메타↔전투 *양방향 의존*을 살린다 (§3.6 갭 해소)

**옵션**:

| 안 | 의식 비용 자원 | 보조 변화 | 양방향 의존 |
|---|---|---|---|
| **A. 영혼 전량 이월** | 런 끝 남은 영혼 → 메타 영혼 | 신앙 폐기 | ✅ 강 |
| **B. 영혼 비율 이월** | 남은 영혼의 N%만 이월 (캡 가능) | 신앙 폐기 | ✅ 강 |
| **C. 영혼 결정체** | 보스 처치 시 별도 드롭 (1런에 0~3개) | 신앙 폐기, 영혼은 전투 전념 | ✅ 중 (보스=트리거) |
| **D. 신앙 유지** | 기획문서 그대로, 시간 누적 | 변화 없음 | ⛔ 단방향 |

해골은 어느 안에서도 *비자원*으로 둠 (개수만 카운트, 카드풀 영향).

**추천 — C (영혼 결정체)**. 이유:
- 보스 처치 = *큰 메타 결정 트리거*로 격상 (서사 일치: 보스 = 권력의 일부)
- 영혼은 전투 *결정 공간*에 전념 (특수기/소환/상점) — 4중 결정 회피
- 1런에 0~3개 드롭 → 의식 1~2회 가능, *자원 압박* 살아있음
- 직관적 — 보고 셀 수 있는 단위, idle 누적 아님 (앱 안 켜도 누적되는 신앙의 *모바일 idle 게임화* 위험 회피)
- 메타 자원 *왕관 조각(영구·시설) + 영혼 결정체(영구·의식)* 2종으로 단순화

대안 B도 강력 — 영혼 이월이 *전투-메타 직결*을 가장 강하게 만듦. 단, 영혼이 4역할되어 결정의 무게가 분산되는 위험.

### D4 (2026-05-28) — 시스템 영역 분리 원칙 (교리 풀 재설계)

| 죽음의 율법 | *처형* — 처치 시 1초 내 연쇄 처형 (가까운 적 즉사) | *자비* — 적 일부 도주, 다음 웨이브 약화 |

| 영혼의 율법 | *영혼 비축* — 미사용 영혼 일부 메타 이월 | *영혼 폭주* — 특수기 후 5초 영혼 드롭 ×2 |
| 부하의 율법 | *명예* — 해골 사망 시 유령으로 5초 잔존 | *소모* — 해골 사망 시 주변 적 폭발 |
| 지배의 율법 | *카리스마* — 영주 시야 내 하인 공격속도 ×2 | *공포* — 보스 제외 적 패닉 (무작위 정지) |

**시각 분리**:
- 시설 = *외형* 변화 (Lv 단계)
- 해골 = *직업 외형*
- 교리 = *전투 연출/대사* (안개·잔영·도주 비명 등)

### D3 (2026-05-28) — 결정 리듬: **γ. 의식=전투, 로비=영구 트랙 + 교리**

**사용자 통찰**: COL의 진짜 재미는 *반응 결정*(상황 보고 결정)인데, *런 전 의식*은 *사전 결정*(STS 보스 유물형)이라 결이 다름. iii 풀(부스트+트레이드오프)이 COL이 아니라 STS 패턴이었음.

**해결**: 의식을 *전투 중* 자리(영혼 상점)로 옮김. 로비는 영구 트랙+거주+드문 큰 결정(교리).

**새 구조**:

| 영역 | 시스템 | 결정 리듬 |
|---|---|---|
| **전투** | 영혼 상점(W3/W9) → **의식 상점**으로 격상. iii 풀(부스트+트레이드오프) 흡수 | 반응 결정 (영혼으로 결제) |
| **로비** | 시설(영구) + 거주 분위기 + **교리**(매 N스테이지 1회 큰 결정) + **요구 응답** (D2 c 유지) | 영구 결정 + 가벼운 반응 (요구) |

**영향**:
- D1 γ는 *전투 능동 메타*로 재정의됨. 로비 자체는 실질 β로 회귀 + *교리* 1축 추가.
- D2 (a) 의식 → 위치 변경(전투). (c) 요구 응답 → 로비 유지.
- 영혼 = 메타 자원으로 자연 격상. Q4 자원 결정의 우선 후보.
- iii 풀 자체는 여전히 유효 (효과 표현만 *현재 상태*에 작용하도록 다듬음 — *시작 영혼 +30* → *지금 영혼 +30* 등).

### D2 (2026-05-28) — 결정 액션 형태: **(a) 의식 + (c) 요구 응답** 조합
- (a) 의식 = *주 결정* (자원 압박) — 기획문서의 *축복*을 흡수해 격상
- (c) 요구 응답 = *관찰 축 능동화* — 해골이 *정적 점*에서 *말 거는 캐릭터*로
- → **D3에서 부분 수정**: (a) 의식은 *로비*가 아니라 *전투*로 이동. (c) 요구 응답은 로비 유지.

### D1 (2026-05-28) — 메타 깊이: **γ. 절충 (가벼운 능동 메타)**
- *시각·서사 이식 + 출정 사이 의미 있는 결정 액션 1~2개*.
- β(시각만)와 α(능동 운영) 사이의 절충점.
