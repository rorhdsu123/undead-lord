## 1. 한 줄 컨셉

웨이브 사이에 *이벤트 노드*가 등장. 매번 **이진 선택** — `⚔ 도전 (자원 비용 → 보상)` vs `🚶 지나가기 (안전, 변화 없음)`. 컬트오브더램의 "맵 선택" 대신 카피바라고의 "도전/통과" 패턴을 차용 — 모바일 환경에서 인지 부담 ↓, 결정 한 단위는 항상 *한 번의 탭*.

---

## 2. 폐기된 대안 — 분기 시스템

원래 안: 스테이지 중간에 갈림길 → 카드 3장 중 1장 → 경로별 다른 웨이브 진행.

폐기 사유:
- 모바일에서 *"내가 지금 어디 있고 어디로 갈지"* 인지 부담
- 트리/맵 UI 별도 필요
- 분기·합류 로직 구현 비용 ↑
- 카피바라고식이 *결정의 무게는 유지하면서 복잡도는 휙 낮춤*

---

## 3. 빈도 — 합의 (B안)

스테이지당 **2개 고정 (전반 1 + 후반 1)**, 위치만 살짝 랜덤.

```
전반 슬롯: W1, W2, W4 중 랜덤 1자리 → 이벤트 등장
후반 슬롯: W6, W7, W8 중 랜덤 1자리 → 이벤트 등장
```

스테이지 구조 (1-2 기준)에서 빈 슬롯 6개(W1, 2, 4, 6, 7, 8) 중 2개만 활용. W3/W9(상점), W5(중간보스), W10(최종보스)와는 겹치지 않음.

### 왜 2개인가
1. **결정 인플레이션 방지** — 매 웨이브 카드 선택 + 보스 와인드업 + 소환·특수기 결정이 이미 많음
2. **리듬감** — 전반 = *이번 런 방향 잡기*, 후반 = *보스 대비 마지막 한 수*
3. **각 이벤트의 무게감 ↑** — 자주 안 나오니 한 번이 중요
4. **온보딩 부담 ↓** — 첫 런에서 2번만 만나면 학습 용이

### ⚠ 스테이지별 차등 조정 — 미합의

사용자 요청: *"스테이지마다 차등조정할거야"*. 다음 세션의 첫 논의 주제.

검토 후보:
- 1-1 (튜토리얼): 0개? — 시스템 부담 ↓
- 1-2: 1~2개? — 이벤트 도입
- 1-3 이후: 2개 고정?
- 챕터 후반부(3+): 3개로 확장? — 후기 깊이 보강

## 4. 이벤트 구조 — 합의

```
W3 클리어 → [이벤트 등장] 
           "수상한 무덤이 빛을 낸다..."
           
           ⚔ 도전 (영혼 50)         🚶 지나가기
```

- 도전 = *자원 비용* + *보상*
- 지나가기 = *항상 안전*, 변화 없음
- *"피로감 0"* 약속 유지 — 자원 부족하면 그냥 지나가기

---

## 5. 이벤트 풀 — 예시 6종 (확정 X)

다음 세션에서 풀 크기·확률 재검토. 현재 표는 *결의 종류 보여주기 위한 샘플*.

| 이벤트 | 도전 | 지나가기 |
|--------|------|---------|
| 🪦 수상한 무덤 | 영혼 50 → 고급 카드 1장 확정 | 변화 없음 |
| 👻 떠도는 영혼 | 즉시 엘리트 1마리 등장 → 처치 시 영혼 +150 | 변화 없음 |
| 💰 폐허의 보물 | 성 HP 20 → 영혼 100 즉시 | 변화 없음 |
| ⚒ 굶주린 부하 | 영혼 30 → 이번 런 하인 공격력 +10% | 변화 없음 |
| 📜 어둠의 계약서 | 다음 보스 HP −20% / 단 이번 보스 HP +20% | 변화 없음 |
| 🌑 잠든 사념 | 신앙 1 → 다음 보스 와인드업 +1초 | 변화 없음 |

**결의 결 (이벤트 풀 디자인 원칙):**
- *영혼* 비용: 즉발 카드/엘리트
- *성 HP* 비용: 자원 변환 (방어→공격)
- *신앙* 비용: 메타 자원으로 보스전 영향
- *시간차 비용/보상*: 다음 보스/다음 런에 영향

## 6. 미해결 결정 (다음 세션 시작점)

### 6-1. 스테이지별 차등 빈도 ⭐ 사용자 명시 — 최우선

위 §3 마지막 후보들 중 선택. 챕터별 페이싱 곡선까지 함께 결정.

### 6-2. 노출 시점

- A. 웨이브 클리어 직후 자동 팝업 → 흐름 자연스러움
- B. *"다음 진행"* 버튼 누르기 전 → 카드 선택 후 한 박자 두고 등장
- C. 일반 카드 선택 화면 한쪽에 이벤트 버튼 → 통합 결정 UI

### 6-3. 풀 크기 vs 등장 확률

풀 10종에서 매 런 2회 노출? 풀 6종 균등 분포? 등급(일반/희귀)? 

### 6-4. 도전 실패 처리 (자원 부족 시)

- A. 도전 버튼 *회색 비활성* → 지나가기만 가능 ← 제 추천 (단순)
- B. 도전 가능하지만 결과가 *덜 좋음* → 좌절감 우려

### 6-5. 메타 진행 연동

- 어둠의 제단 축복으로 특정 이벤트 등장률 ↑?
- 특정 이벤트 누적 클리어 → 영구 보상/도전과제?
- 신앙·왕관 조각과의 자원 흐름 영향?

### 6-6. 튜토리얼·온보딩

- 1-1에서 0개로 두면 첫 만남은 1-2. 그때 *어떻게 학습시킬지* (FTUE 가이드 오버레이?)
- 자원 부족 시 도전 불가 학습은 어떻게?
