# 07. 연출 / 튜토리얼 (Juice & Onboarding)

> 전투의 손맛(juice)과 서사 대사, 그리고 첫 플레이(FTUE) 가이드 오버레이.
> 메커니즘이 아니라 *체감*을 담당 — 화면 흔들림·데미지 숫자·대사·튜토리얼 손가락.

## 책임

- 화면 연출: 스크린 셰이크·플래시·히트스톱, 데미지 숫자, 사망/폭발/진화/소환/펄스 이펙트
- 영주·보스 대사 출력 (상황별 라인 풀)
- 튜토리얼 가이드 오버레이: 첫 웨이브·카드·상점·특수기 안내, 전투 일시정지 가이드

## 현재 상태

| ID | 기능 | 상태 |
|---|---|---|
| FX1 | 스크린 셰이크 / 플래시 | ✅ |
| FX2 | 데미지 숫자 (떠오름) | ✅ (치명타 3계층은 [05](../05_보스/) BS7 미구현) |
| FX3 | 사망·폭발·진화·소환·펄스링 이펙트 | ✅ |
| FX4 | 상황별 대사 (시작·웨이브클리어·보스·게임오버·클리어) | ✅ |
| FX5 | 보스 타이틀 표시 | ✅ |
| FX6 | FTUE 가이드 오버레이 (웨이브/카드/상점 안내) | ✅ |
| FX7 | 특수기 해금 팁 + 전투 freeze 가이드 | ✅ |

## 미해결 의제

- **치명타 풀 연출 패키지** — 히트스톱 0.1s·금색 1.8× 숫자·"치명타!"·금 파티클·카메라 줌인·캔슬음·햅틱. 기획 확정·미구현 → [05_보스 BS7](../05_보스/) · devlog wip §4. 신규 헬퍼(히트스톱·카메라 줌·햅틱) 필요.
- **대사 코드 ≠ 기획/세계관** — 영주·보스 라인이 "언데드 영주" 톤. 세계관 피벗(마지막 고대 괴수) + [[블랙코미디 톤]](전원 진지·상황 부조리) 기준으로 전면 재작성 대상.
- **모바일 햅틱·사운드** — 오디오(Phase 4)·모바일(Phase 3) 미진입. 연출 훅만 존재.
- **튜토리얼 범위** — 현재 전투 내 가이드만. 로비 온보딩은 [Lobby/06_온보딩](../../Lobby/06_온보딩/).
