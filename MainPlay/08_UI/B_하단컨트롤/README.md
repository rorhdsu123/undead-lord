# B. 하단 컨트롤 클러스터

> 레이어 **L1 (상시 HUD)**. 화면 최하단에 고정된, 플레이어가 직접 조작하는 영역 전체.
> **자원 표시 + 그 자원을 쓰는 액션 버튼**을 한 클러스터로 묶음 — 영혼 수치(B1)는 소환·특수기 비용(B3·B4)이 존재하는 이유라 떼어 보면 안 됨.
> 3개 행 구조: (행0) 자원 라벨, (행1) 소환 버튼 4종, (행2) 특수기 + 희생.

## 현행 — 운영자 리디자인 반영 (2026-06-14, RD15~RD18 + MD12)

> ⚠️ 아래 `구성 요소`·`레이아웃`·`B1~B5`·`디자인 의제`는 **운영자 리디자인 이전(영혼 소모품 + 특수기/희생 모델)** 기록 — *역사*로 보존. 현재 전투 하단은 [02 RD13~](../../02_영주_전투/) · [03 MD12](../../03_하인_소환/) 로 전환됨. 코드 정본 = `Game.gd` 하단 함수군.

현재 하단 클러스터 구성(아래→위, `_layout_bottom_ui_phase_c()`):

- **접지 트레이** (`_bottom_tray`): 다크보라 반투명 패널 1장을 하단 밴드(y795~960)에 최하단 z로 깔아 컨트롤을 접지. → 이전 "투명/패널 없음" 결정(§디자인 의제)을 **뒤집음**. 근거: 컨트롤이 맨 흙바닥에 떠 있어 좌하단 쏠림·안 예뻐 보임(운빨존많겜 레퍼런스 대조).
- **자원 readout 행**: `● 골드 N`(`souls_icon`+`souls_label`) + `■ N / M` 하인 카운트(N=`active_minions`, M=`max_minions`, `_minion_icon`은 하인 아트 입고 전 ■ 플레이스홀더). 캡 도달 시 readout 우상단에 **빨간 `MAX` 배지**(`_max_badge`).
- **소환 버튼 3종** (전사/궁수/탱크, 폭탄병 제외): 이름/비용을 **자식 라벨 분리**(`_summon_name_lbls`/`_summon_cost_lbls`)해 숫자만 독립 색. **상시 활성**(골드 부족이어도 비활성 안 함), 골드 부족 시 **비용 숫자만 빨강**(`UI_COST_SHORT`). 튜토리얼 잠금만 `disabled`(🔒).
- **강화 버튼**: `▲(초록 글리프 오버레이 `_upg_icon`) 강화` → 탭 시 위로 펼쳐지는 팝업(타이틀 "강화", 종류별 가로 카드 = Lv + 비용 알약 `UpgBtn_*`). 알약도 **상시 활성 + 부족 시 숫자 빨강**(배경 골드 유지).
- **권능 버튼** (우하단): `AbilitySystem` 원형 글로우 2슬롯이 **특수기/희생 버튼(B4·B5)을 대체**.
- **골드 획득 플로터**: 골드 획득 시 `souls_icon` 위로 `● +N` 팝→상승+페이드(~0.55s), 버스트 시 자동 세로 스택(소프트캡 8). `add_souls()` 단일 퍼널에서 트리거. **강화 팝업 열림 중엔 생략**(팝업 위 어색함 방지).

캡 룰: 종류별 캡 폐지 → **전역 총량 캡 기본 6**([03 MD12](../../03_하인_소환/README.md)). 다양성은 강제 대신 **적 로스터 분화**([01 BD1](../../01_전장_흐름/README.md))로 유도.

## 자원 표시 상태

### B1 영혼 수치
- 평상시 "◆ N" (아이콘 ◆ + 숫자), 색상 기본. affordability(쓸 수 있는지)는 **버튼 점등**이 담당 → 카운터 자체엔 색 변화 없음(중복 방지).
- **아이콘(2026-06-10)**: 한글 단어 "영혼:"을 떼고 임시 심볼 ◆(금색 `Color(1.0,0.82,0.35)`)로 교체. 코드 생성 Label(`souls_icon`), **아트 입고 시 노드만 교체**. 글리프는 폰트 100% 포함 보장 문자(◆)로 선택(두부 방지).
- **살아있는 카운터(2026-06-10 구현)**: 값 변화 시 ①**롤업** 옛값→새값 0.25s 이징(QUAD out), ②**범프 펀치** 1.15× 튕김(0.07s out+0.10s in, pivot=좌측-수직중앙). 모든 영혼 변화가 `_update_souls_ui()` 한 곳으로 모여 처치 획득·소환/특수기 소비 양쪽에 동일 적용. 방향 틴트(획득 녹색/소비 적색)는 **범위 제외**(미채택).

### B2 하인 슬롯
| 상태 | 색상 | 조건 |
|---|---|---|
| 여유 | `Color(0.85, 1.0, 0.85)` 연두 | active < max |
| 가득 참 | `Color(1.0, 0.5, 0.5)` 빨강 | active >= max (소환 버튼 동시 비활성) |

슬롯 기본 3, 키스톤 「언데드 군단」 선택 시 +2 (최대 5).

- **아이콘(2026-06-10)**: 한글 단어 "하인 슬롯"을 떼고 임시 심볼 ●(`slot_icon`, 코드 생성 Label) + "n/n" 우정렬. 표기 방식(n/n 숫자)은 **유지** — 카드로 슬롯이 크게 늘 수 있어 핍 미채택. 아이콘은 위 여유/포화 색상을 숫자와 함께 따라감. 아트 입고 시 노드만 교체.

## 액션 버튼 상태

### B3 소환 버튼
| 상태 | 텍스트 | 조건 |
|---|---|---|
| 활성 | "{종류}\n{비용} 영혼" | 웨이브 활성 + 슬롯 여유 + 영혼 충분 |
| 비활성 | "{종류}\n{비용} 영혼" | 위 중 하나라도 불충족 |
| 튜토리얼 잠금 | "{종류} (잠금)" | 1-1, W0은 전부·이후 전사만 해금 |

비용: 전사 15 / 궁수 25 / 탱크 35 / 폭탄병 20. `minion_cost_reduction` 카드로 감소.

### B4 특수기 버튼
| 상태 | 텍스트 | 조건 |
|---|---|---|
| 활성 | "특수기 (N)" | 웨이브 활성 + 영혼 ≥ 비용 |
| 영혼 부족 | "특수기 (현재/필요)" | 웨이브 활성 + 영혼 < 비용 |
| 비활성 | "특수기 (N)" | 웨이브 비활성 |
| 튜토리얼 잠금 | "특수기 (잠금)" | 1-1 특수기 미해금 |

기본 50 영혼. **충전 게이지 없음** — 영혼 비용으로만 게이팅 (→ 상위 README "의도된 부재"). 키스톤 「파멸」 시 비용↑·위력↑.

> **점등 어포던스(2026-06-09 확정)**: 영혼이 비용에 도달하는 순간 disabled→active로 글로우/펄스 1회. B3 소환도 동일. 영혼 부족↔충분 전이를 능동 통지.

### B5 희생 버튼
| 상태 | 텍스트 | 조건 |
|---|---|---|
| 활성 | Loc `sacrifice_btn_idle` | 웨이브 활성 + 상주 하인 존재 + 쿨 없음 |
| 쿨다운 | Loc `sacrifice_btn_cooldown` + "N초" | 발동 후 8초 (가제) |
| 하인 없음 | `sacrifice_btn_idle` disabled | 상주 하인 0명 |
| 비활성 | `sacrifice_btn_idle` disabled | 웨이브 비활성 |
| 튜토리얼 잠금 | `sacrifice_btn_locked` | 1-1 전체 잠금 |

발동 시 전선 하인(적에 가장 가까운 상주 하인) 자동 선택 → 폭발(반경 70, 피해 40, 가제).

> **쿨게이지(2026-06-09 확정)**: 쿨다운 상태를 버튼 위 파이/바 게이지로 시각화(텍스트 초카운트 대체). 채워질수록 재사용 임박.

## 디자인 의제

> 방향(2026-06-09 확정): **미니멀하게 두되, 가치 높은 어포던스만 더한다.** 클러스터는 투명, 게이팅 가시화는 자원 점등·쿨게이지로 한정.

- ✅ **클러스터 통합 레이아웃** — *결정*: **투명/미니멀**. 패널 배경으로 묶지 않음 — 전장 가시영역(하단 ~165px가 이미 차지) 보존 우선. "조작 영역" 구획은 위치만으로.
- ✅ **자원↔버튼 연동 피드백** — *해소*: 영혼이 비용 도달 시 버튼이 disabled→active로 **점등**(글로우/펄스 1회). "이제 쓸 수 있다"를 능동 통지. (기존 조용한 토글 대체)
- ✅ **B5 쿨다운 시각화** — *해소*: 버튼 위 **파이/바 쿨게이지**. 텍스트 초카운트 대체.
- **슬롯 포화 ↔ 소환 비활성 시각 연결** — *보류(후순위)*: 미니멀 유지 위해 B2 빨간 라벨 텍스트로 충분 판단. 플테에서 "왜 소환이 동시에 꺼졌나" 혼동 시 재검토.
- **B3 소환 버튼 아트** — *보류*: 하인 아트 교체(귀여운 마물, MD11) 입고 후 버튼 아이콘 반영. 현재 텍스트만.
- **상점 진입 시 전환** — 상점(D) 열리면 B3·B2 숨김. 클러스터 일부만 사라지는 전환이 자연스러운지 확인.
- ✅ **자원 아이콘화(2026-06-10)** — *적용*: B1·B2 한글 단어를 임시 심볼(◆/●)로 교체, 미니멀 유지(패널 배경 없음). 표기 방식·색·롤업·범프 전부 보존. 세계관/아트 확정 후 노드 텍스처 교체.
- **명명** — "영혼" 가제. 현재 아이콘은 폰트 글리프 임시 심볼(중립).
