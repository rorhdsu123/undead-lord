# 03. 시설 시스템 (Growth)

> 영주의 영구 성장 축. 왕관 조각을 소비해 시설을 3단계까지 업그레이드. *§기획문서 11. 성장 축*.

## 책임

- 5개 시설(왕좌·성벽·묘지·무기고·연회장) 데이터 (효과·비용)
- 시설 버튼 (성 위 좌표에 탭 영역)
- 하단 슬라이드 업그레이드 패널 (정보 + 업그레이드 버튼)
- 업그레이드 가능 시 강조 표시 (황금 색)
- 업그레이드 시 자원 차감 + 영구 저장

## 현재 상태

| ID | 기능 | 상태 |
|---|---|---|
| C1 | 시설 버튼 5종 | ✅ |
| C2 | 하단 슬라이드 패널 | ✅ |
| C3 | 시설 데이터 (`FACILITIES` 배열) — 수치 효과·비용·3단계 | ✅ |
| C4 | 업그레이드 가능 강조 | ✅ |
| C5 | 시설 시각 4단계 sprite | ❌ |

## 시설 데이터 요약

| 시설 | 효과 (Lv1/2/3) | 비용 (Lv1/2/3) |
|---|---|---|
| 왕좌 | 시작 영혼 +20/+40/+60 | 5/8/13 |
| 성벽 | 최대 HP +50/+100/+150 | 5/8/13 |
| 묘지 | 웨이브 회복 +15/+30/+50 | 5/8/13 |
| 무기고 | 공격력 +10%/+22%/+37% | 6/10/15 |
| 연회장 | 영혼 획득 +20%/+40%/+60% | 6/10/15 |

## 코드 위치

- `scripts/Lobby.gd`
  - `FACILITIES` — 시설 데이터 상수
  - `_build_facility_buttons()` — 버튼 생성
  - `_build_bottom_panel()`, `_open_panel`, `_close_panel`, `_refresh_panel_content` — 패널
  - `_upgrade(id)` — 업그레이드 처리
- `scripts/GameSave.gd` — `facility_levels` 영구 저장

## 미해결 의제

- **시설 시각 4단계** (C5) — sprite 5×4=20장 작업. ROI 토론 필요 → [07_미구현_의제/시설시각성장.md] (예정)
- 효과가 *수치만* — 전투 체감 강화 (이펙트·텍스트 부각)
- 시설 종류 5개가 적정한가 (M4 거점 확장 논의)
- D4 *시스템 영역 분리 원칙* — 시설 = 수치 부스트, 카드 = 빌드 다양화. 영역 침범 없는지 효과 정기 점검

## 관련 결정

- [D4](../핵심재미_검토.md) — 시설 = *시작 조건 + 시각 성장*, 수치 부스트. 다른 시스템과 영역 분리.
