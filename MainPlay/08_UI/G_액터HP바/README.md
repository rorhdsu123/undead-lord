# G. 액터 HP 바

> 레이어 **L3 (월드 부착)**. 전장 내 각 액터(적·하인·보스) 머리 위에 붙는 HP 게이지.
> 고정 HUD가 아니라 액터 씬 내부에 있고 액터와 함께 움직임.

## 구성 요소

| ID | 이름 | 노드 경로 | 역할 |
|---|---|---|---|
| G1 | 적 HP 바 | `Enemy.tscn` 내 `$HPBar` | 일반 적 전원 |
| G2 | 하인 HP 바 | `SkeletonWarrior.tscn` 내 `$HPBar` | 소환 하인 전원 |
| G3 | 보스 HP 바 | `Boss.tscn` 내 `$HPBar` | 보스 전용 |

## 공통 동작

- 모두 ProgressBar (0~100). 피해 시 `value = (hp/max_hp)*100` 즉시 갱신
- 액터 사망 → 노드 삭제 → 바도 사라짐

## 개별 특성

### G1 적 HP 바
- 일반 적 4종(normal/scout/brute/swarm) 공통. 동시 다수 표시 — 작고 깔끔해야 화면 안 복잡.

### G2 하인 HP 바
- 소환수 4종 공통. 희생 시 바 없이 즉시 사라짐. 폭탄병은 소환=발사라 표시 시간 극히 짧음.

### G3 보스 HP 바
- 화면 내 단 1명 — 크기/위치 차별화 가능
- HP 25%(`hp <= max_hp*0.25`) 이하 → 페이즈 3 진입(색상 변화 연출)
- 와인드업(분노 게이지) 중 보스 본체 색상 펄스

## 디자인 의제

- **G1 ↔ G2 아군/적군 구분** — 적·하인 바 색상이 구분돼야 판단 가능. 현재 구분 여부 .tscn 확인 필요.
- **G3 위치** — 보스 위 부착 vs 화면 상단 고정(도타식). 후자가 가독성 더 나을 수 있음.
- **G3 페이즈 표시** — 3페이즈(~50%, ~25%, 발악). HP 바 페이즈 경계선 검토.
- **G3 와인드업 표시** — 특수기 준비 중(`rage_charge_time`) 충전 게이지 표시 검토. 현재 색상 펄스만.
- **G1 스케일** — 적 5~15명 동시. 바 최소 크기 기준 설정.
