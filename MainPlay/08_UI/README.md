# 08. UI 설계 — 메인플레이씬

> 작성: 2026-06-09
> 캔버스: 480×960 (모바일 세로). 모든 좌표는 이 기준.
> 목적: UI 디자이너에게 넘기는 기능 단위 기획서. 각 폴더가 하나의 UI 기능 단위.
> 세계관 명명은 가제 상태 — 확정 후 일괄 리스킨 예정. [[세계관 (초보 마왕)]]

## 두 가지 읽는 법

이 문서는 **단위(A~H)** 로 폴더가 나뉘지만, 디자이너는 **레이어(행동 성격)** 로 보는 게 빠릅니다. 아래 레이어 표 → 각 단위 폴더 순으로 읽으세요.

### 레이어 뷰 (디자이너 관점 — 무엇이 언제·어떻게 뜨나)

| 레이어 | 성격 | 노출 | 포함 단위 |
|---|---|---|---|
| **L1 상시 HUD** | 전투 중 항상 표시, 서로 안 가림 | 웨이브 활성 내내 | A (상단 상태) · B (하단 컨트롤) |
| **L2 모달 인터럽트** | 전투를 가리고 입력을 독점, **상호 배타** | 특정 시점에 1개만 | C (카드) · D (상점) · E (결과) |
| **L3 월드 부착** | 액터를 따라다님, HUD 아님 | 액터 생존 중 | G (액터 HP 바) |

## 화면 상태 머신 (모달 배타·z-order)

> 디자이너 필독 — 모달끼리 겹치지 않도록 노출 규칙을 명시. 충돌하면 입력 먹통·시각 깨짐 발생.

L2 모달 3종(카드/상점/결과)은 **동시에 뜨지 않습니다.** 웨이브 루프가 한 번에 하나만 호출:

```
       [웨이브 전투 중]  ← L1 HUD만 보임
            │
   웨이브 클리어 ─────┬─→ (일반)     → C 카드 패널
            │         ├─→ (상점 웨이브) → D 상점 패널
            │         └─→ (스테이지 끝)  → E 결과 시퀀스(클리어)
            │
   성 HP 0 ───────────────────────────→ E 결과 시퀀스(게임오버)
```

- 모달이 떠 있는 동안 **L1 하단 컨트롤(B)은 숨김/비활성** (상점은 명시적으로 소환 컨테이너 숨김)
- 모달 닫기 → 다음 웨이브 → 다시 L1 전투 상태로
- **z-order(위→아래)**: L5 튜토리얼(H) > L2 모달 > L4 페이드/오버레이(F) > L1 HUD > L3 액터바(G, 월드) > 전장
- L5 튜토리얼(H)은 L1·L2 위에 얹혀 특정 요소를 강조 (카드 패널 위 가이드 등)

## ⚠ 설계상 의도된 부재 (디자이너 오해 방지)

- **플레이어(영주) HP 바가 없다** — 영주는 체력/사망 개념이 없는 불사 캐스터. **성(Castle) HP가 유일한 패배 풀**(A3). "주인공 체력바"를 찾지 말 것. 긴장은 성 HP + 영혼 부족에서 나옴.
- **특수기 충전 게이지가 없다** — 특수기는 시간 충전이 아니라 **영혼 비용(50)** 으로만 게이팅. 쿨다운/충전 바 없음 (B 참조).

## 레이아웃 개요

```
┌─────────────────────────────┐  ← y=0
│  [A] 성 HP 분절바 (상단 고정)│  y ≈ 0~ (0순위, 전폭)
│  [A] 스테이지 1-1 (라벨)      │
│  [A] ◆◇◇…★ 압축 트래커      │  앞3 + … + 최종보스
│                              │
│  (전장 — 적·하인·보스 이동)  │
│  [G] 액터 HP 바 (각자 위)   │
│  [F] 플로팅 텍스트 (이벤트) │
│      └ 성 피격 데미지 숫자도 │
│                              │
│ ┌─ B 하단 컨트롤 클러스터 ─┐ │
│ │ 영혼 수치 / 하인 슬롯    │ │  y ≈ 820~840
│ │ 소환 버튼 4종            │ │  y ≈ 858
│ │ 특수기 (60%) │ 희생(40%) │ │  y ≈ 910~960
│ └──────────────────────────┘ │
└─────────────────────────────┘  ← y=960
```

## 공통 설계 규칙

- 모든 사용자 노출 텍스트는 `Loc.gd` 경유 (하드코딩 금지)
- 비활성(disabled) 상태와 활성 상태를 명확히 시각 구분
- 터치 타겟 최소 44px (모바일 기준)
- 명명은 세계관 피벗 후 일괄 교체 예정 — 가제로 작업
