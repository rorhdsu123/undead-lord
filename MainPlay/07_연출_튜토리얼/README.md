# 07. 연출 / 튜토리얼 (Juice & Onboarding)

> 전투의 손맛(juice)과 서사 대사, 그리고 첫 플레이(FTUE) 단계적 온보딩.
> 메커니즘이 아니라 *체감*을 담당 — 화면 흔들림·데미지 숫자·대사·튜토리얼 가이드.

## 책임

- 화면 연출: 스크린 셰이크·플래시·히트스톱, 데미지 숫자, 사망/폭발/소환/펄스 이펙트
- 마왕·보스 대사 출력 (상황별 라인 풀)
- **단계적 온보딩**: 1-1→1-2→1-3(내부 st0/st1/st2)에 걸쳐 메커니즘을 하나씩 학습시키는 가이드 + 게이트 + 카드 풀 게이팅

## 온보딩 커리큘럼 (1-1 → 1-3)

> 원칙: **레벨 구조가 메커니즘을 하나씩 순서대로 손에 쥐여준다.** 매 스테이지 새 도구 하나, 강제 게이트는 "생애 첫 행동"에만, 카드 풀이 학습 진도를 따라간다(CotL/Kingdom Rush식, 플레이 주도 + 최소 게이트).
>
> ⚠️ **스테이지 표기**: 화면 라벨 = `chapter+1`-`stage+1`. 게임 **첫 스테이지 = 1-1**(내부 `current_stage=0`, FTUE 튜토리얼). "1-0"은 없음. 코드는 전부 내부 `current_stage`(0/1/2)로 분기 → 표시 1-1/1-2/1-3.
> ⚠️ **보스 번호 충돌**(미해결): 보스 설계 문서는 1-1/1-2/1-3을 세 보스 스테이지(방패성기사/대마법사/전설용사)로 부르나, 여기선 1-1=튜토리얼. WaveData 보스 로스터도 옛것(사관후보생 등)이라, 보스 코드 진입 시 번호 일괄 정리 필요. → [05_보스](../05_보스/) 소관.

| 표시(내부) | 새로 배우는 것 | 로드아웃(튜토리얼 오버라이드) | 카드 풀 |
|---|---|---|---|
| **1-1** (st0·FTUE 튜토리얼) | 마물 3종 차례로 + 낙뢰 + 키스톤. **W0 전사**(잡병) → **W1 궁수**(후방 사수 등장) → **W2 탱크**(brute 등장) → **W3 낙뢰**(잡병 무리) → **W3 클리어 키스톤 갈림길**. 기존 중간보스 유지 | 낙뢰만(궁수·탱크 잠금표시, **낙뢰·나팔 버튼도 잠금표시→낙뢰 W3 해금**·숨김 아님=마물과 통일) | **W3 전: 마물+스탯만(마법 카드 전부 제외)** · W3 후: +공격형(낙뢰계). **통제형은 1-3까지 제외** |
| **1-2** (st1) | **마물 강화**(키우기 vs 뽑기) → 스테이지 보스 | 낙뢰만 | 위와 동일. **통제형 제외** |
| **1-3** (st2) | **마법 #2 나팔**(통제형) 해금 → 스테이지 보스 | 낙뢰 + 나팔 | **통제형 해금**(제압 등) |

**게이트 = 안내(벽 아님)**: 튜토리얼 팁은 타깃 버튼만 비우고 배경을 dim(`show_tutorial_tip` 4분할 스트립·α0.55·입력 통과). **freeze 폐기** — freeze-until-action은 골드/쿨다운 부족 시 데드락이라, 막지 않는 dim-only로(게임 계속 진행→자원 모이면 행동). ⚠️**dim 예외**: 낙뢰·나팔 팁은 `dim=false`(적을 조준해 쓸어야 하는데 배경 적이 어두워지면 모순) — 버튼 강조 테두리·화살표·텍스트만.

**카드 뽑기 전용 가이드는 삭제** — 1-1 첫 카드형 화면 = 키스톤 "전투 전략" 화면이 *고르는 제스처*를 흡수. 이후 일반 카드 픽(3장 중 1장)은 같은 동작의 단순 버전이라 자명.

**진행 플래그**(`GameSave.gd`): `tutorial_completed`(1-1=st0) · `taught_enhance`(1-2=st1 강화) · `taught_horn`(1-3=st2 나팔). 카드 게이팅은 `taught_horn`을 읽어 통제형 카드 가시성 결정.

- **온보딩 구현 — 패스2a 완료·미플테** (2026-06-25): ①키스톤 「전투 전략」 갈림길을 **튜토리얼에서 점등**(`end_wave` 키스톤1 분기를 `_is_tutorial` 밖으로, W0 클리어 시). 키스톤2는 비튜토리얼 유지(튜토리얼 mid_boss=마지막 웨이브→game_clear로 안 옴). ②교습 비트(`_trigger_wave_guide`): 1-1 **W0=소환-우선 유도**(전사=상시 방어선 먼저·친절 한 줄 "~세요!"+소환 버튼 강조·시작 1.5s 지연으로 첫 적 접근 무렵)·**W1=낙뢰 게이트**(낙뢰는 쿨 12s라 상시방어 X→버스트 보조라 순서 뒤). 1-2=강화 팁(첫 강화가능 웨이브·`taught_enhance`), 1-3=나팔 팁(`taught_horn`). ③옛 카드 가이드(`_show_card_guide`) 제거(FX14). `AbilitySystem.get_field_button()` 게터 추가. **freeze 없음**·파싱 OK. **결정**: 1-1 중간보스 **유지**(설계 FX8 "보스 없음" 철회)·키스톤 튜토리얼 점등. ④튜토 소환 잠금버그 수정=`_refresh_summon_buttons`·`_on_summon_pressed` 둘 다 `current_wave<1` 잔재→`j>0`/`index>0`만(전사 W0부터·궁수/탱크 잠금).
- **온보딩 — 1-1 마물 점진 학습 + 적 정렬 + 키스톤 이동** (2026-06-25): 1-1(st0)에서 마물 3종 차례로 학습=W0 전사·W1 궁수·W2 탱크·W3 낙뢰, **W3 클리어 후 키스톤**(낙뢰까지 겪고 군대/마법 축 선택→안 꼬임). 점진 해금 헬퍼 `_is_summon_unlocked(display_j)=display_j<=current_wave`(튜토만, 두 가드 공용·press는 `HIRE_TYPE_INDICES.find(index)`로 표시 j 변환). 키스톤1 트리거 `axis_wave=3 if _is_tutorial() else 0`(비튜토 W0 유지). 각 웨이브에 동기부여 적(WaveData st0): W1=후방 사수(궁수), W2=brute(탱크), W3=잡병 무리 normal×5+×3(낙뢰 AoE). ⚠️미적용 선택폴리싱=낙뢰 학습 전 W0~W2에 마법 강화카드(연쇄낙뢰·area) 노출 게이팅(통제형처럼)—원하면 추가. ⚠️동시 세션의 `DENSITY_MULT`·카드텍스트 작업과 트리 공존 → 커밋 시 헝크 분리 필요.
  - **패스2b = dim-only 완료**(2026-06-25, freeze 폐기): `show_tutorial_tip`에 배경 dim(타깃 사각 구멍 4분할 스트립·α0.55·`MOUSE_FILTER_IGNORE`로 입력 통과). 모든 튜토 팁(전사/궁수/탱크/낙뢰/강화) 적용. **freeze 안 씀** — 사용자 지적=freeze-until-action은 골드 부족 시 데드락. `_set_battle_freeze()`는 미사용 잔존(제거 후보).
