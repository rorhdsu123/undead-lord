# 04. 성장 / 경제 (Growth & Economy)

> 한 판 안에서 점점 강해지는 "선택 → 누적 → 강화" 사이클의 핵심.
> 세 축: **영혼**(전투 화폐) · **카드**(웨이브 클리어 빌드 강화) · **영혼 상점**(상점 웨이브 결제).

## 책임

- 영혼 자원: 적 처치 시 획득, 특수기·상점에 소모, 런 종료 시 소멸
- 카드: 웨이브 클리어 후 3장 중 1장 선택 → 영구(런 한정) 빌드 강화. 희귀 등급 롤.
- 영혼 상점: 상점 웨이브에서 영혼으로 1개 구매 (전투·카드 보상 없음)
- 시설 보너스 적용 (로비 시설 → 전투 시작 시 영혼·공격·HP 등 반영)

## 키스톤 / 태그 시너지 설계 (2026-06-01, 진행 중)

곱하기 엔진(시너지+선택적 키스톤)을 카드로 구현하는 설계. 메모리 [[project_keystone_design]] = 결정 로그 기록. **읽기 쉬운 기획 정본 → [카드_키스톤_기획.md](./카드_키스톤_기획.md)** (아래 표는 결정의 근거·로그). 합의 전 코드 수정 금지.

**진단** — 현재 풀(SKILL 3 + STAT 10) 문제: ①전부 더하기(키스톤=곱 0) ②2축 불균형(🗡️영주 7 vs 💀소환사 4, 소환사 키스톤 0) ③카드×카드 시너지 0 ④MD8 폭탄병·MD9 희생과 카드 단절.

**확정 (KS1~KS8)**

| ID | 결정 | 근거 |
|---|---|---|
| **KS1** | **키스톤 = 규칙 바꾸는 카드(곱 진입점), "선택적"**(안 집어도 완주, 집으면 빌드 꺾임). 등장=**보장 분기점**(일반 스탯카드 흐름과 분리), **런당 2개**. | 운 롤은 "이번 판 빌드 못 함" 좌절. 1개는 시너지 죽고 3개는 가독성 과부하. |
| **KS2** | **런 단위 = 스테이지 1개, 빌드 매 스테이지 리셋.** | 코드 검증: GameSave에 카드/빌드 상태 없음, 스테이지 전환=씬 reload(`Game.gd:786~827`)로 전부 리셋. 로그라이트와 정합. |
| **KS3** | **분기점 배치: #1=W1 클리어 직후(빌드 선언) / #2=중간보스 처치(심화).** 최종보스 키스톤 폐기(처치=런끝→활용 전투 0). 1-1 튜토리얼 면제. | 초반 정체성→계획 플레이. 최종보스 직후 키스톤은 쓸 웨이브가 없어 무의미. |
| **KS4** | **트레이드오프=허용·비강제**(대부분 암묵적 기회비용, 일부만 명시 페널티). **2축 배분=셀프캐리·소환사 대칭, 성·공용 키스톤 제외**. | 캐주얼이라 무거운 PoE식 페널티 부담. 성=정체성 아닌 토대. |
| **KS5** | **곱 스케일링 = 키스톤이 같은 축 카드 수에 비례해 강해진다**(키스톤=곱 스위치, 없으면 스탯=더하기). 다른 축 섞어도 페널티 없이 곱만 약화. | 카피바라 Go 분석 차용(무기=빌드강제↔#1키스톤, 속성 시너지). #1×#2 종속/독립 고민 자동 해소(독립 풀+축 모으면 보상). |
| **KS6** | **수치 모델 = 선형**(같은 축 1장당 +X%). | 카드가 3중 1택 *랜덤* → 임계(3/5장 점프)는 원하는 축 연속 안 뜨면 브릭=좌절(모바일 라이트 손실회피와 충돌). 선형은 1장이라도 곱 붙어 랜덤 속 항상 전진. 초반 밍밍은 ①키스톤 0장 기본효과(룰 변경) ②설명문 목표의식("모을수록 강해진다")으로 보정. |
| **KS8** | **#1·#2 관계 = "카운트 공유 + 출력 분기"**. 무엇을 *모으나*(카운트=같은 축 카드 수)는 #1·#2 공유 / 무엇이 *강해지나*(출력)는 #2에서 선택. 같은 축이라 어느 #2를 골라도 모은 카드가 항상 이득(브릭 없음), #2 선택으로 빌드 색깔이 갈림. | 완전 누적(A)=결정 무게0(둘 다가 정답), 배타 분기(B)=다양성↑이나 나쁜 조합 약함=MD6 함정, 단순 계승(C)=#2 무의미. 분리하면 A의 보상감+B의 다양성, 둘의 약점(무게소실·브릭) 회피. 결정 무게는 "#2 출력 베팅"에 집중, 인지는 "축 하나 모으기"로 최소. |
| **KS7** | **명시적 태그 UI 폐기** — 🗡️/💀 배지·아이콘 등 별도 라벨 레이어 안 만든다. 카드 축 분류는 **내부 메커니즘**(`CARD_CATEGORY_MAP`, 이미 코드에 존재)으로만 두고, **키스톤이 그 카운트를 자기 설명문 안 자연어로 흡수**(예 "하인을 강화할수록 강해진다"). 플레이어는 키스톤 카드 텍스트 한 줄만 읽으면 됨. | 사용자 지적(2026-06-01): 이미 등급(일반/레어) 레이어가 있는데 태그 배지를 또 얹으면 학습 코스트 중복. MD6 교훈(인지 안 되는 시스템=없는 것). **→ (나) 태그 입도 2 vs 5 논쟁 자체 소멸**: 명시적 라벨이 없으니 플레이어가 태그 종류를 알 필요 없음. "무엇을 세는지"는 각 키스톤 문구가 콘텐츠 단계에서 정함. 트레이드오프(빌드 내 축 카드 수 한눈에 못 셈)는 선형이라 정확히 셀 필요 없어 거의 무해. |

### 소환사 키스톤 콘텐츠 (1차, 2026-06-01 — 이름·수치 전부 가제)

> 카운트 풀 = 소환사 축 일반 카드(`minion_count`/`minion_attack`/`minion_speed`/`summon_speed`). "모을수록 강해진다"의 대상. 이름은 [[project_worldbuilding]] 피벗 대기라 가제, 메커니즘만 확정. 각 키스톤 = ①0장 기본효과(룰 변경) + ②선형 스케일링(KS6) + ③출력 색깔.

**#1 (W1 선언, 1종 = 토대)**

| 가제 | 기본효과(0장) | 스케일링 | 역할 |
|---|---|---|---|
| 「언데드 군단」 | 소환 슬롯 +2 | 소환사 카드 1장당 하인 공격력 +8% | 빌드를 "소환사"로 선언. #2가 이 위에 특화를 얹음. W1 선언은 갈래보다 토대가 맞음. |

**#2 (중간보스 심화, 출력 분기) — 2종 채택 + 1종 보류**

| 가제 | 기본효과(0장) | 스케일링 | 색깔 | 연동 | 상태 |
|---|---|---|---|---|---|
| 「영원한 군세」 | 하인 사망 시 30% 즉시 재소환 | 카드 1장당 하인 최대수/부활률↑ | 끝없는 물량(수·지속 극대) | #1 직결 | ✅ 채택 |
| 「죽음의 메아리」 | 하인 죽으면 주변 폭발 | 카드 1장당 폭발 위력 +X% | 수동 자폭(많이 소환→많이 죽음→광역) | MD8 폭탄병 결 | ✅ 채택 |
| 「제물의 의식」 | 희생 반경·위력↑ + 희생 시 슬롯 즉시 회전 | 카드 1장당 희생 폭발 위력↑ | 능동 자폭(희생 버튼으로 직접 터뜨림) | MD9 희생 코어 승격 | ⏸ 보류 — MD9 밸런스 확정 후 3번째로 |

**채택 근거**: 자폭 2종(메아리=수동/제물=능동, MD8·MD9 평행)은 결은 다르나 MVP 단계 인지 혼란 위험 → 직관적인 수동(메아리) 먼저, 능동(제물)은 MD9 희생 수치가 굳은 뒤 추가. 2종으로도 물량 올인 / 자폭 두 갈래 확보.

**진행**: KS1~KS8 확정. 소환사·영주 키스톤 콘텐츠 1차 완료 → 정본 [카드_키스톤_기획.md](./카드_키스톤_기획.md). 소환사 카드 보강 완료(7 대 7 대칭, 강철 골수·뻗는 손아귀·피의 갈증). 남은 = 설명문/이름 다듬기(세계관 피벗 후) · 수치 밸런스(플레이테스트) · 보류 키스톤 2종(제물의 의식·파멸의 일격) · 코드 구현(별도 합의 후).

## 미해결 의제

- **상점 메뉴 코드 ≠ 기획 (5개 모두 다름)**
  | 기획 §10 | 코드 `SHOP_ITEMS` |
  |---|---|
  | 성벽 수리 50 / +30 | 성벽 수리 40 / +60 |
  | 영혼 폭주 150 / 공2배 | 공격 강화 35 / +15% |
  | 죽음의 메아리 150 / 드롭2배 | 하인 치료 25 / 전체회복 |
  | 어둠의 계약 300 / 공+15% | 하인 강화 18 / +10% |
  | 묘지 확장 300 / HP+50 | 저주 확장 30 / 범위+50 |
  → **어느 쪽이 정본인지 결정 필요.** 코드 가격이 전반적으로 저렴 = 밸런스 패스 흔적일 가능성.
- **영혼 소비처 4번째 = 하인 희생 (2026-05-30 신설, →[03 MD6](../03_하인_소환/))** — 희생은 직접 영혼을 쓰진 않지만 슬롯을 비워 *재소환*으로 영혼 소비를 유도. 소환 슬롯 고정 시 생기는 영혼 잉여의 배출 경로. 밸런스 시 소환·특수기·상점과 함께 4갈래로 튜닝.
- **카드 풀 단계 확장(해골 수 연동)** — 기획 §4 메타 루프 "해골 3+ 강화카드, 5+ 전설…". 코드의 `RARE_CHANCE`와 연동 여부 미확인.
- **D3(의식 상점) 위치** — 로비 결정 D3에서 "의식은 출정 전이 아닌 전투 내"로 이동. 현재의 영혼 상점이 그 자리인지, 별도 의식 시스템인지 정리 필요. → [Lobby/05_출정](../../Lobby/05_출정/) 미해결 의제와 교차.
