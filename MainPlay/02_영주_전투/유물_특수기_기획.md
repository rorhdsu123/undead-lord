# 유물 특수기 — 전투 참여 재설계 기획서 (가제)

> 목적: 전투 중 플레이어의 **참여감**을 살리기 위해 영주 본체를 전장에서 들어내고, 플레이어를 **"단순한 탭 마법 두어 개를 쥔 지휘관"**(Kingdom Rush 모델)으로 재편한다. 라이브 컨트롤 = **유물 2 자유 슬롯**의 탭 마법(쿨다운 발동). 영혼은 전투 능동에서 빠져 **군대/경제 트랙**으로 재정의.
> 이 문서 = 읽기 쉬운 기획 정본. 결정 근거·기각 대안은 [README.md](./README.md) 결정 로그(`RD#`) 참조.
> 작성 2026-06-12 · **설계 단계(미구현)** — 현행 구현(아바타 기반 `A1~A7`)은 교체 전까지 유효. 이름·수치는 전부 가제.

## 1. 핵심 개념

1.1 **문제** — 고정-자동 모델의 수동성. 영주가 성 안에 고정된 채 자동 공격하고, 단조로운 전체화면 특수기 하나만 쓴다. 플레이어가 "전투에 참여하는 느낌"이 약하다. (이 리스크는 [README 2026-06-01]이 이미 예견 → 플레이테스트 판정 "여전히 수동")

1.2 **해결 방향** — 영주 아바타를 **전장에서 완전 제거**한다. 플레이어는 *전장에 선 전투원*이 아니라 **성을 지키는 의지(운영자)** 가 된다. 참여는 지리(위치)가 아니라 **능동 마법(특수기)** 에서 나온다.

1.3 **정체성 = 디펜스.** 이 게임은 디펜스다 — 한 판 안에서 점점 강해지며 성을 지킨다. 따라서 특수기는 *상시 휘두르는 무기*가 아니라 **방어선의 결정적 개입 수단**이다. "어디가 무너지는가"를 읽어 그곳에 마법을 꽂는 것이 곧 재미.

1.4 **로그라이트 빌드 축.** 현재 빌드 시스템(카드=패시브, 키스톤=곱연산)은 전부 자동·수동적이다. 유물은 **플레이어의 능동 표현을 빌드로 정하는** 빠져 있던 축을 채운다. **유물 2개를 자유 조합**하므로 그 조합 자체가 빌드 정체성이 된다(공격2=글래스캐논 / 통제2=요새 봉쇄 / 1+1=균형). 런마다 조합이 바뀌면 *능동 플레이 방식*이 바뀐다.

1.5 **두 트랙 분리(Kingdom Rush 모델).** *마왕의 손*(라이브 전술)과 *자동 군대*(경제)를 자원으로 분리한다 — 마법은 **쿨다운**(공짜), 군대는 **영혼**(처치로 획득→편성·업글). §5 참조.

## 3. 라이브 컨트롤 = 탭 마법 2개

3.0 **발동 UX = Kingdom Rush식 2버튼 + 3스텝 탭(`RD11`).** **우하단**에 **유물 슬롯 2개에 대응하는 원형 마법 버튼 2개**(쿨 = 베벨 링 레이디얼 프로그래스). 발동 흐름:
1. **마법 버튼 탭** → 무장(해당 마법 선택).
2. (취소 시) **무장된 버튼 재탭** → 사용 취소. *X 배지는 취소 가능 힌트*(필드 밖 탭으로는 취소 안 함). → **`RD11` 보정**(원안 "X 단일 경로·재탭 미채택" → Phase B 플테로 *재탭*이 모바일 엄지에 더 자연스러워 채택, 2026-06-12).
3. **원하는 위치 탭** → 그 지점에 발현.

- **버튼 상태 색**(검증 빌드 구현): 쿨 중 = 회색 링 + 흰색 충전(링+아이콘 내부 동기화), 준비 완료 = 흰색 풀 + 되는 순간 1회 깜빡 + **준비 동안 외곽 글로우 상시 맥동**(`RD17` — 흰색 통일, ≈2.2초 주기. 1회 깜빡은 *완료 순간*만 알려 공백이 생기므로, 시선이 필드에 가 있다 돌아와도 "쓸 수 있음"을 상시 인지시킴), 무장(사용중) = 시안. 배치 = 우하단(세로 모바일 한 손, 중앙은 성과 겹침). 설명 캡션 = 하단 중앙 가로 바(무장 시).

- **조준 미리보기 없음(순수 탭-탭).** 무장 후 손가락 따라오는 풋프린트 레티클은 미채택 — 각 마법의 범위는 *학습*으로 익힌다(가볍고 모바일 손맛 우선). 단 사거리 제한이 있으므로(아래) 무장 시 **도달 경계선만 옅게** 표시(손가락 위치 무관 고정선, 위치별 미리보기 아님) → 헛탭 방지.
- 게이팅 = **쿨다운**, 비용 영혼 아님(`RD9`). 자유 슬롯 2개라 "버튼 없이 직접 탭"은 어느 유물인지 모호 → 2버튼 채택(`RD8`).

3.1 **발현 = "강림"(가제), "휘두름" 아님.** 시전자 몸도 투사체 출발점도 없다. 플레이어가 **조준한 지점에 마법이 직접 발현**한다(from-above). 예: 탭한 곳에 낙뢰가 떨어지고, 역병 지대가 피어나고, 충격파가 터진다.
- 기본 원점 = **표적 강림.** 일부 유물만 "성에서 발사"(from-castle, 예: 부채꼴 충격파)를 *개성*으로 섞는다.

3.2 **순간 깊이 = 조준 + 상황 반응형.**
- **조준** — 누를 때마다 *어디에* 꽂을지 결정.
- **상황 반응형** — 같은 버튼이 **전장 상태를 읽어** 효과가 달라진다(자동·암묵 방식). 적이 뭉치면 광역, 보스가 와인드업 중이면 끊기+치명타, 외곽 탱크엔 넉백. 플레이어는 *모드를 고르는 게 아니라*, 유리한 상황을 *만들고 읽어* 꽂는다.

3.3 **와인드업 치명타 = 전 유물 공통 규칙.** 현재 보스 와인드업 끊기+×2(`Player.gd:177~`)는 특정 특수기의 특수 동작이 아니라, **모든 유물 특수기가 와인드업 중 보스에 적중 시 발동**하는 공통 규칙으로 일반화한다.

3.4 **디펜스 개입의 형태(예).**
- 무너지는 레인 → 넉백으로 시간 벌기
- 뚫린 틈 → 지대로 봉쇄
- 성에 닿기 직전 누수 적 → 강림으로 쳐내기(클러치)
- 보스 와인드업 → 끊기+치명타

## 4. 유물 시스템 (가제)

4.1 **2 자유 슬롯.** 런당 **유물 2개**를 장착. **슬롯 역할 고정 없음** — 어떤 유물이든 아무 슬롯에 자유 장착(`RD3`). 게이팅 = **유물별 쿨다운**(영혼 비용 폐기, `RD9`). 밸런스 레버 = **쿨 길이**(무거운 강림=긴 쿨, 잦은 통제=짧은 쿨) + **사거리**(긴 reach=전 화면 저격 / 짧은 reach=성 근처 last-line, `RD11`). 내 2개 조합이 곧 *내 전술 리듬* — reach 안배(긴+짧은)도 빌드 고민.

4.2 **처치/통제는 *유물 속성*, 슬롯 속성 아님(`RD6`).** 유물마다 디펜스를 *푸는 방식*이 다르다 — **통제형**(넉백·둔화·봉쇄로 *시간을 버는* 방어) ↔ **처치형**(우선 위협을 *지워서* 라인을 구함). 손맛 축(단일/지대/광역, 쿨 길이, 리듬)으로도 차별화.

| 유물(가제) | 성향 | 손맛 | 발현 |
|---|---|---|---|
| 낙뢰의 홀 | 처치 | 조준 단일·고화력·긴 쿨 | 표적 강림 |
| 운석 낙하 | 처치 | 조준 광역·강력·긴 쿨 | 표적 강림 |
| 진흙 늪 | 통제 | 조준 지대·둔화·중간 쿨 | 표적 강림 |
| 가시덤불 | 통제 | 조준 장벽·차단·중간 쿨 | 표적 강림 |
| 망령의 나팔 | 통제 | 광역·넉백·짧은 쿨 | 표적 강림 |
| 성벽의 포효 | 통제 | 부채꼴 충격파 | 성에서 발사 |

*(예시 — 실제 풀 규모·쿨·수치는 남은 작업. 처치/통제 어느 쪽이든 두 슬롯에 자유 조합)*

4.3 **획득·교체 구조(CotL 차용).**
- **장착** = 로비에서(수집·메타 성장). 유물 수집이 로비 메타 목표가 된다(2층 구조의 메타 강화층과 정합).
- **중간 교체·강화** = 새 시스템을 만들지 않고 **기존 노드에 매핑** — 웨이브 사이 카드 선택, 영혼 상점.
- **카드/키스톤** = 장착 유물을 *증폭*(역할 분리: 유물=능동 동작, 카드=패시브 증폭).

4.4 **검증 빌드 — 재미 검증용 2종 확정(`RD12`, 2026-06-12).** 풀 전체를 만들기 전에 *이 능동 루프가 재밌나/수동성 벗었나*를 가장 빨리 증명할 **최대 대비 쌍**(1처치 + 1통제)만 먼저 확정. 구현은 후순위(설계만). 같은 성향 2개로는 2슬롯 정체성의 심장(`RD6` 성향 대비)을 못 건드리므로 의도적으로 대비 쌍 선정.

| 검증 유물 | 성향 | 형태 | 쿨 | 사거리 | 핵심 동작 | 상황 반응형 |
|---|---|---|---|---|---|---|
| **낙뢰의 홀** | 처치 | 점(**작은 임팩트 반경**) | 긴 쿨 | 전 화면 저격 | 착탄점 단일 고화력. 순수 1체 아닌 작은 반경(빗맞음 허무 방지 = 정밀+약간의 관용) | 보스 와인드업 중 적중 → **끊기 + ×2 치명타**(처치형 풀 적용) |
| **망령의 나팔** | 통제 | 원(광역 펄스) | 짧은 쿨 | 넉넉 | 착탄점 중심 펄스 → **일괄 위쪽(스폰 방향) 넉백 + 착지 둔화**(`A안`). 피해 ≈ 0(순수 통제 — 처치로 번지면 성향 대비 흐려짐). VFX = *상방 스윕 돌풍/음파*(대칭 링 아님 — 방사형 오인 방지) | **질량 기반 넉백 차등**(hp_mult, 기존 코드) + 와인드업 끊기(피해 미미해 치명타 의미 적으나 끊기는 유효) |

> **통제 가시화 튜닝(`RD18`, 2026-06-19 플테 통과).** 1차 플테에서 넉백이 "효과 체감 안 됨"(넉백 260=속도 시드라 일반 적 ~48px만 밀림) → **넉백 560(~220px 가시적 던짐) + 착지 둔화 1.5s(속도 60%↓·파란 틴트)** 로 "흩뜨림+멈칫"을 가시화. 넉백의 *번 시간*이 비가시·자가복구라 통제 동사 중 제일 안 읽히는 문제를 페이백 가시화로 해소. 값은 "너무 센 편" 메모 → 밸런싱 가제. 코드 = `AbilitySystem.gd:_fire_trumpet`.

- **넉백 방향 = 일괄 위쪽 확정(`A안`).** 방사형(`B안`, 중심서 바깥)은 중심보다 아래 적을 *성 쪽으로* 밀어 역효과 → 기각. 탭=폭발원점 방사(`C안`, 조준 퍼즐)는 표현력 매력적이나 *검증 신호를 흐림*(조준 깊이는 낙뢰가 이미 검증) → 검증 후 확장으로 보류.
- **상황 반응형 = 검증용 최소.** 새 매트릭스(뭉침→광역 등) 미작성. *이미 확정된* 공통 와인드업 치명타/끊기 + 기존 질량 넉백 **2개로만** 한정 → 조준·템포로 핵심 재미를 깨끗이 검증. 본격 §7.3은 검증 통과 후.

## 5. 페이싱

- **템포는 위협 에스컬레이션이 정한다.** 초반 웨이브=한산(가끔 개입), 후반=조밀(쉴 새 없이 triage). 에스컬레이션 자체가 한 판의 곡선.
- **"쿨 도는 사이"는 공백이 아니다** — 쿨다운이 도는 동안 *전장을 읽으며 다음 개입을 노리는* 시간 = 디펜스의 긴장.
- 따라서 "N초마다 강제로 눌러 채운다"는 액션 게임식 페이싱은 **기각.** 손이 멈춰도 머리가 움직이게 한다.

## 6. 두 트랙(손·군대) · 인프라

Kingdom Rush의 *마법(쿨다운)* ↔ *골드(타워)* 분리를 차용(`RD10`). 영혼은 전투 능동에서 빠져 **군대/경제 트랙**으로 재정의된다.

| 트랙 | 자원 | 무엇 |
|---|---|---|
| 마왕의 손 (라이브 전술) | **쿨다운** | 유물 마법 2개 — 처치·통제 개입 |
| 자동 군대 (경제) | **영혼** | 하인 편성·업글·영혼 상점 (자동 방어선 구축) |

- **하인 = 자동 지원군.** 외곽 전선을 자동으로 지킨다. 라이브 지휘(집결·즉석배치) 시스템은 **추가하지 않는다**(`RD7`, 복잡도 최소). 딜·라인 유지는 하인·자동에 분담, 플레이어 손은 두 마법에 집중.
- **영혼 = 군대 경제.** 처치로 영혼을 벌어 **웨이브 사이 편성·하인 업글·영혼 상점**에 쓴다(KR 골드 모델). 기존 영혼 상점·시설 보너스가 이 트랙에 흡수. 트레이드오프: "영혼 아껴 큰 거 한 방"식 *마법 절약-소비* 긴장은 사라지고, 그 긴장은 *경제 트랙*으로 이동 / 마법 쪽은 *쿨다운 타이밍* 긴장으로 대체.
- **위협 텔레그래프(④) 승격.** 디펜스적 읽기가 성립하려면 "여기 위험하다"가 화면에 보여야 한다. ④ 위협 텔레그래프는 *사치 폴리싱*이 아니라 **이 설계의 필수 인프라**다. → [01_전장_흐름](../01_전장_흐름/) · [07_연출_튜토리얼](../07_연출_튜토리얼/)

## 8. 검증 빌드 — 1단계 구현 범위 (`RD14`, 2026-06-12)

> 풀 시스템 전에 **핵심 가설**을 가장 빨리 증명할 최소 빌드. *손=쿨다운 / 군대=영혼 두 트랙이 같이 도는 게 재밌나 · 수동성 벗었나 · 처치↔통제 성향 대비 느껴지나.* 구현 합의 완료 → 코드 진입 가능.

### 8.1 전략 — 2단계 재매핑
전투 데미지 파이프라인이 **영주 중심 곱엔진**(`keystone_*_mult`·`attack_bonus`가 자동공격·특수기·소환·희생·패시브에 전부 침투)이라 부분 패치가 안 됨 → "마법 중심"으로 갈아끼우는 작업. RD12 정신(검증 먼저)대로 **둘로 분리**:
- **1단계(이 절)** = 검증 가설 증명에 필요한 최소만. 나머지는 *삭제가 아니라 비활성/숨김*(검증 결과로 살릴지 갈리므로 지금 지우면 낭비).
- **2단계(검증 후)** = 패시브 거취·영혼 경제 풀 구현·키스톤 마법 재설계·카드/reach 재배치·유물화·로스터 확장.

### 8.2 1단계 재매핑 표
| 시스템 | 현 위치 | 1단계 처리 |

### 8.3 검증 빌드 구성
**손 트랙 — 마법**: 낙뢰의 홀(처치) + 망령의 나팔(통제). **2슬롯 고정**, 3스텝 탭(`RD11`), 쿨다운(`RD9`). 상세 = §4.4.

**골드 트랙 — 군대**(`RD13`/`RD15`): *(자원 표시명 = **골드**, 코드 식별자·구설계 표기 = `souls`/영혼 그대로)*
- **라이브 골드 고용(`RD15`, KR 정통)**: 군대 편성은 *웨이브 사이가 아니라* **전투 중 라이브**. 하단에 **상시 표시되는 고용 버튼**(종류별, 골드 비용 버튼에 표시) → 누르면 즉시 고용. KR이 골드로 전투 중 타워를 짓는 것과 동일. → "손=쿨다운 마법 / 군대=라이브 골드" 두 트랙이 *둘 다 라이브*.
- **고용 메뉴**: 탱크/전사/궁수 3종. **폭탄병 제외**(자폭 일회용 = 누적·영구사망 모델에 안 맞고, 낙뢰[처치 버스트]와 역할 겹쳐 검증 신호 흐림 → 검증 후 "골드 마법"류로 재검토).
- **고용 가능 시점**: **모든 전투 웨이브**(보스 포함). 단 **골드 상점 등 특수(비전투) 웨이브에선 비활성**.
- **수입**: 처치 → 골드 적립(`Enemy`/`Boss` 현행 유지), HUD 표시. 웨이브 클리어 보너스 없음.
- **강화 = 종류별 글로벌 레벨(`RD16`)**: 전투 HUD에 **강화 버튼 1개** → **미니 팝업**(레퍼런스식 KR 갸챠 강화, 종류별 가로 카드: 탱크/전사/궁수 각 `Lv + 강화 비용`) → 탭하면 그 종 레벨↑. 강화 시 **그 종 하인이 더 강해짐**(현재+미래 전부, 종류별 글로벌). **팝업은 전투 정지 안 함**(RD15 라이브). 골드 성장 트랙(넓게=고용 vs 깊게=강화).
- **지속**: 고용한 하인은 **웨이브를 넘어도 안 사라지고 계속 싸움**(런 내 영구 누적, KR 타워식). **영구사망 = 몸만(`RD16`)** — 죽으면 그 *몸*은 영구 제거(전선 공백 + 재고용 골드), 단 **종류별 강화 레벨은 유지**(글로벌이라 죽어도 안 날아감). RD13의 "per-unit 승진 소실"보다 부드러움(단순·인지 우선). 자동 리필·키스톤 무료재소환 없음.
- **군대 캡**: **있음**(밸런싱 수치 TBD). 캡이 있어야 "넓게(고용) vs 깊게(강화)" 결정이 성립(없으면 몸 스팸이 정답). 원래 "너무 많이 소환됨" 문제의 해결. *현재 구현 = 종류별 상한(`HIRE_CAP_PER_TYPE`, 임시). → **전체 합산 캡**(전 하인 수 총합 제한)으로 변경 예정 — 추후 논의·구현(2026-06-12 사용자 요청).*
- **시작 골드**: 소량(가제 50) → 웨이브1부터 라이브 고용.
- **구현**: Phase A가 *숨긴* 옛 소환 버튼을 되살려 골드 고용 버튼으로 재활용(3종·웨이브 넘어 유지·키스톤 refill 없음). 강화 버튼+팝업·종류별 레벨·캡 추가. 별도 고용 화면 불필요.
- **전투 행동**: 수비적 마중 요격(`RD13` — 성 앞 밴드, 돌진X, 침투 적 우선, leash, 블로킹=기존 `MINION_ENGAGE_RANGE`) — Phase D.

**비활성/숨김**: 영주 아바타·자동공격·기존 특수기 UI·키스톤·카드·희생·패시브 3종.

### 8.4 검증 후(2단계) 잔여
편성 메타(승진 내용·군대 캡·풀 편성 UI·출처 하이브리드[보스 충신 편입]) = [03_하인_소환 "재설계" 남은 작업](../03_하인_소환/). 하인 **로스터 다양성 확장**도 편성 경제(승진 깊이 vs 횡적 종 수)가 정해진 뒤 content pass로(아트 추가 의뢰 수반). 유물 전체 풀(≈6~8)·상황 반응형·키스톤 마법 재설계 = §7.
