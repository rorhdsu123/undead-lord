# 04. 거주민 시스템 (Observation)

> 해골 부하들이 *시설에서 일하며 산다*. §기획문서 11. 관찰 축. **현재 가장 얕은 축**.

## 책임

- 해골 캐릭터 배치 (시설별 위치, 최대 8명)
- idle 행동 머신 (idle → wander → return → work → idle)
- 시각 차별 (시설별 색 틴트)
- 탭 반응 (바운스 트윈)
- 등장 연출 (새 해골 도착 시 스케일+알파+먼지)

## 현재 상태

| ID | 기능 | 상태 |
|---|---|---|
| D1 | 해골 시설별 배치 (`SKELETON_PLACEMENT` 8 슬롯) | ✅ |
| D2 | 시설별 색 틴트 (`FACILITY_TINT`) | ✅ |
| D3 | idle 상태머신 (idle/walk/work) | ✅ |
| D4 | 탭 시 바운스 | ✅ 빈약 |
| D5 | 등장 연출 (`play_arrival`) | ✅ |
| D6 | 직업 라벨 / 외형 차별 | ❌ `job` 필드만 존재, 표시 안 됨 |
| D7 | 직업별 작업 애니 (장인 칼 갈기 등) | ❌ 모두 같은 `slash` 애니 |
| D8 | 요구 응답 / 대화 인터랙션 (D2 c) | ❌ |

## 코드 위치

- `scripts/Lobby.gd`
  - `SKELETON_PLACEMENT` — 8 슬롯 (시설·직업·오프셋)
  - `FACILITY_TINT` — 시설별 색
  - `_build_skeleton_garden()` — 거주민 인스턴스화
- `scripts/SkeletonResident.gd`
  - 상태 머신 (`State.IDLE/WALKING/RETURNING/WORKING/ARRIVING`)
  - `_on_area_input` — 탭 감지
  - `_bounce_tap` — 반응
  - `play_arrival` — 등장 연출

## 진단

§핵심재미_검토 §3 "🔍 관찰 — *얕음*"
- 정적. 색만 다름. "누가 살고 있다"가 아니라 "점이 찍혀 있다".
- 탭 반응 빈약 (바운스만).
- *직업·외형 차별*과 *요구 응답*이 들어와야 진짜 관찰 축이 작동.

## 미해결 의제

- **거주민 능동화** (M2) — D4·D6·D7·D8을 묶어 *말 거는 캐릭터*로 격상 → [07_미구현_의제/거주민능동화.md] (예정)
- **교리 EXP 원천이 거주민인가** — 직전 토론 핵심. 결합 시 D8이 *진척 시스템*으로 격상.
- 해골 캡(`SKELETON_CAP`) — 8 적정인가
- 직업 종류 — 시종/장인/요리장/경비/묘지기/호위/견습/보조 8종. 외형 sprite 부담 검토.
