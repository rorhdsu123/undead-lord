# 05. 보스 (Boss)

> 스테이지의 절정 — 중간보스·최종보스 패턴 전투. 처치 시 왕관 조각·해골 보상([06](../06_결과_보상/)).
> 핵심 설계 의제 = **와인드업 ↔ 특수기 치명타** (타이밍 기반 약점 노출 윈도우). 기획 확정, 코드 미반영.
> **적 진영·보스 라인업 = 챕터 단위.** 아래는 Ch1 정본 (2026-06-17 확정). 세계관 = [세계관_기획.md §8](../../세계관_기획.md).

## Ch1 적 진영 · 라인업 (정본, 2026-06-17)

> **구조 원칙**: 진영 = **챕터 단위**, 스테이지(1-1·1-2·1-3) = 그 진영 내부의 **직급 사다리**. 챕터가 올라갈수록 더 거창한 조직이 온다.

### 진영 — "동네 초보 모험가"
- 갓 즉위한 초보 마왕에게 현상금이 걸리자, **만만해 보여서 몰려든 동네 초보 모험가들.** 성은 낡고 마왕은 작아 보이니 진짜 거물은 안 온다.
- **초보 마왕 ↔ 초보 용사**의 거울 구조 — 둘 다 미숙하나 둘 다 진지. (톤 헌법 정합.)
- Ch1 잡몹·미니보스 = 떨거지·한탕꾼. **수집형 보스만은** 현상금 보고 직접 나선 "이름값 있는" 용사 → 위엄 정당화.

### 잡몹 5역할 (행동으로 차별화 — 외형은 리스킨)
> **역할 = 플레이어에게 던지는 질문 1개.** 좋은 잡몹은 *서로 다른 정답*을 강요한다 (핵심재미 = "머리 쓰는 라이트 전략"). `EN7`(2026-06-17)로 `EN3`(리스킨만) 수정 — Ch1부터 **행동 비트 2개**(사수=진짜 원거리, 돌격병=하인 무시)를 넣어 5개 답안이 1챕터부터 살아나게 한다. 그 외 행동 추가는 Ch2부터 진영별로.

**플레이어의 답안 공간**: 하인 3종(전사=근접딜 · 궁수=원거리딜·적 어그로 안 끎 · 탱크=블로커) + 마법(낙뢰의 홀=광역 즉발 · 망령의 나팔=넉백). ※폭탄병은 라이브 고용 풀에서 제외(`HIRE_TYPE_INDICES=[0,1,3]`) → **광역 정답 = 낙뢰의 홀(마법) 뿐** = swarm은 "쿨다운을 언제 터뜨리나" 결정으로 작동.

기준값: HP 50 · 속도 60 · 피해 10 · 근접 사거리 50 · 쿨다운 1.5s. 배율은 `Enemy.gd:TYPE_PRESETS` 기준.

| 코드 타입 | 역할 | Ch1 정체 (가제) | 어그로 | 사거리 | HP/속도/피해 | 강요하는 질문 → 정답 |
|---|---|---|---|---|---|---|
| `normal` | **기준점** | 견습 모험가 (검사/창병/도끼병 변형) | 하인 교전 | 근접 50 | 1.0 / 1.0 / 1.0 | (기준점) → 아무거나 |
| `brute` | **방어선 고착** | 한물간 용병 | 하인 교전 | 근접 50 | **3.5** / 0.5 / 1.5 | "벽을 어떻게 녹이나" → 전사+궁수 지속딜 (탱크 1기론 못 녹임) |
| `swarm` | **물량 압박** | 마을 자원봉사 토벌대 (농부/청년단) | 하인 교전 | 근접 50 | 0.3 / 1.3 / 0.5 | "단일 타겟으론 부족" → 낙뢰의 홀 (3~4마리 묶음 스폰) |
| `scout` | **후열 견제** | 떠돌이 궁수 | 하인 교전 | **단거리 ~120** | 0.5 / 1.0 / 0.6 | "전선 밖에서 때린다" → 능동 차단(나팔·낙뢰·궁수 맞사격) |
| `runner` *(신규)* | **방어선 돌파** | 막무가내 돌격꾼 | ⚠️**하인 무시** | 근접(성) | 0.6 / **1.7** / 1.2 | "벽으로 다 못 막는다" → 나팔 넉백·낙뢰·궁수 선제 |

**신규 행동 2개 (구현 비용 = 이것뿐, 아트는 전부 리스킨):**
- **사수 = 후열 견제형**(scout, `EN9`로 단순화 → `EN11`로 밸런스 확정) — 일반 적처럼 근접 어그로(`_find_nearby_minion()`)에 걸려 전선에서 막히되, **사거리 ~120에서 활로 사격**(`is_ranged`). 근접으로만 막히는 다른 적과 달리 **전선 밖·전선 도달 전에 아군/성을 때려** 수동 방어를 무력화 → 능동 처리(나팔로 끊기·낙뢰·궁수 맞사격)를 강제하는 **우선 처치 대상**. `EN11`(2026-06-18 플테 확정): standoff를 120으로 낮춰 사수가 라인 *안*으로 전진해 근접 교전에 걸리게(150 이상은 라인 위로 직사=불가항력, 80은 완전 흡수=위협 0 → 80~150 브래킷 후 120). 동시에 **아군 궁수가 적 사수를 자동 최우선 저격**(↓`EN11`). ~~`EN8`의 "궁수 사냥꾼"(아군 궁수 다이브)는 폐기~~(↓`EN9`) — 잡몹 단계에선 "특정 타겟 응징"이 과한 복잡도라 단순 원거리로 회귀.
- **돌격병**(`runner`, 신규) — `_find_nearby_minion()` 건너뛰고 **항상 성 타겟**. 빠르고 물렁한 글래스러너. 위협은 피해가 아니라 **템포**(병력이 앞 웨이브에 묶인 사이 성 도착). 나팔로 밀어내는 게 가장 쫀득한 답.

> **창발 구조 (2026-06-18 `EN9`로 갱신)**: 벽(탱크·전사)이 "기본 안전답" — `normal`·`brute`·`swarm`을 막는다. 남은 압박 2개가 벽 의존을 **양방향으로** 흔든다. **돌격병**(`runner`)=벽을 *무시*하고 성으로 레이스 → 벽만으론 못 막음(나팔·낙뢰 능동 대응). **사수**(`scout`)=벽에 막혀도 *사거리 밖에서 계속 때림* → 패시브로 방치 불가, 능동으로 끊어야 함(나팔로 밀거나 궁수로 맞사격). 즉 **돌격병은 벽을 우회하고, 사수는 벽 너머로 쏜다** — "벽+딜+마법" 균형이 정답. 5역할이 서로 다른 답을 강요.

### Ch1 잡몹 진영 캐릭터 레이어 (정본, 2026-06-23 · `EN21`)
> 행동(5역할)은 위에서 잠금. 그 위에 얹는 **정체·외형 레이어** = 보스 `EN19`의 잡몹판. 아트 정본 = [아트의뢰_잡몹_Ch1_5종.md](../../아트의뢰_잡몹_Ch1_5종.md).

- **코미디 엔진 = 군상(群像)**: 보스는 *개별* 갭(직함↔실체)이지만 잡몹은 떼로 죽으니 개별 서사 0. **현상금=일확천금에 혹해 생업 버리고 몰려온 동네 사람들** — 자격 미달자들이 어설프게 무장하고 *줄지어 오는* 부조리. 우스움은 개체가 아니라 집단(떼·줄)에서. 개체는 데드팬.
- **공유 진영 DNA = 「동네 살림 무장」**: 자급 살림(농기구·주방기구·가보)·안 맞는 핏·흙빛 팔레트. **번쩍이는 새것 ❌**(보스와 대비). 어설픔은 *비율·소품·마모*로만(`아트의뢰_보스_Ch1_3종` 외형 화법 정합).
- **프레임 = 「역할 슬롯 / 진영 스킨」**: 역할 5칸은 고정 슬롯(행동·실루엣 요구 불변), 진영은 갈아끼우는 스킨 → **Ch2 새 진영은 5역할 그대로·외형만 리스킨**.
- **Ch1 정체(가제)**: `normal`=갓 검 잡은 동네 청년(흙갈) · `scout`=**동네 사냥꾼**(숲녹, ※가제 "떠돌이 궁수"에서 재명명) · `brute`=**동네 장사**(力士, 무쇠회·최대 체구, ※가제 "한물간 용병"에서 재명명) · `swarm`=마을 자원봉사대(밀짚누렁·최소) · `runner`=막무가내 동네 막내(주황·옵션 작화). 역할별 주조색으로 군집 식별.

### Ch1 스테이지 thematic 척추 — "보스 = 그 스테이지 잡몹의 정점" (정본, 2026-06-24 · `EN25`)
> CotL "보스 = 그 지역 잡몹의 합체/정점" 구조를 우리 챕터에. 각 스테이지가 **그 보스를 *어떻게* 싸우는지 미리 가르친다**(잡몹·엘리트가 보스 메커니즘을 예고) → 챕터에 서사·학습 척추가 생김. 근거 = [레퍼런스_타게임_보스.md](./레퍼런스_타게임_보스.md)(미니보스 구조).

| 기둥 | 잡몹 (예고·웨이브 강조) | 엘리트(중간) | 보스(정점) | 플레이어의 답(빌드축) |
|---|---|---|---|---|
| **① 벽/방어** | `brute` 움직이는 벽 | — (1-1=FTUE) | **1-1 방패 성기사**(고정 근접 DR) | 지속딜(군대 축) |
| **② 물량/소환** | `swarm` 떼 | **자원봉사대장**(swarm 강화) | **1-2 대마법사**(후열 swarm 소환) | 광역(낙뢰) |
| **③ 원거리/돌파** | `scout`+`runner` | **궁수두목**(scout 강화) | **1-3 전설의 용사**(원거리 카이팅) | 도달·차단(나팔+낙뢰) |

- **`normal` = 전 스테이지 기준점(尺).** 강조는 **mono 아닌 lean** — 5역할 다 나오되 기둥 역할을 더 많이/클라이맥스 웨이브에 배치(변화·다양성 유지).
- **②의 페이오프(백미)**: 1-2 내내 swarm을 싸우다 대마법사가 **그 swarm을 직접 소환** → "그 떼를 보낸 게 너였구나"(메커니즘=서사).
- **벽 기둥의 정점 = 1-1 보스**라 brute 엘리트 불필요 → 1-2 엘리트를 swarm 강화(자원봉사대장)로 재배치, 옛 "강화 용병대장(brute)"은 폐기(`EN25`).
- **③ 정합**: scout(원거리)·runner(돌파)는 "벽으론 못 막는다"를 가르치고, 1-3 용사가 그 정점(원거리+카이팅). 궁수두목(scout 강화)은 그대로 유지.
- ⚠️ **웨이브 강조 비율의 *구현*은 난이도 곡선([[웨이브 펄스 스폰]] 펄스)과 동반 튜닝** — 이 표는 *설계 가이드*, `WaveData.gd` 편성은 별도 작업에서 척추를 반영하며 난이도와 조율.
- 🎨 **brute 살림성(솥·문짝·마모)을 특히 loud하게** → 1-1 보스(정예 번쩍 벽)와 "급 상승" 대비 극대화(`아트의뢰_잡몹_Ch1_5종` §5.3).

### 중간보스(엘리트) 2종 — "무리의 우두머리" 외형 (정본, 2026-06-24 · `EN26`)
> 비수집·아트 최소. 척추(`EN25`)의 *예고 부대* = 그 무리의 우두머리. **잡몹과 보스 사이 중간**에 둔다. 발주 = [아트의뢰_잡몹_Ch1_5종.md](../../아트의뢰_잡몹_Ch1_5종.md)(잡몹 리스킨이라 같은 의뢰서).

- **컨셉 위치 = 무리의 우두머리**: 잡몹보다 위(체구↑·리더 tell), 보스보다 아래(여전히 동네 사람·살림 DNA·**후광X·수집X·직원 형태X**).
- **톤 = 완전 군상**: 개별 서사 0·데드팬. "대장/두목"이라는 **역할 tell만**(직함↔실체 갭은 보스 전용, 엘리트엔 안 줌).
- **외형 원칙 = 「진짜 장비 1점」 그라데이션**: 잡몹(전부 살림) → **엘리트(살림 + 딱 한 점의 '진짜' 장비)** → 보스(전부 정예+후광). 엘리트가 보스의 정예를 *한 조각 미리* 보여줌 → 3등급 시각 연속성.
- **"급 상승" 신호 = 체구↑ + 진짜 장비 1점 + 리더 자세뿐** (후광·새 아우라·색 광휘 ❌ — 보스 전용 + 신호색 충돌 회피). 사용자 결정(2026-06-24).
- **2종**(EN25 척추 예고 기능 내장):

| 엘리트 (슬롯) | base | 진짜 장비 1점 | 리더 tell·자세 | 예고하는 보스 |
|---|---|---|---|---|
| **자원봉사대장** (1-2 · 1000) | `swarm`(농민 떼) 리스킨+체구↑ | 낡은 **군용 흉갑/검 1자루**(부하는 농기구뿐) | 헝겊 깃대·주방 도구 치켜든 **"다들 가자!" 동원 포즈** | 무리 지휘 → **대마법사**(소환·지휘) |
| **궁수두목** (1-3 · 2000) | `scout`(사냥꾼) 리스킨+체구↑ | **제대로 된 사냥 활**(부하는 임시 활) + 사냥 트로피(뿔·가죽 망토) | 후방에 버틴 **명사수 자세** | 거리 두고 명중 → **전설의 용사**(원거리 카이터) |

- **아트 비용**: base 잡몹(swarm/scout) **리스킨+스케일+소품 1점**, base 애니 재사용. 비수집 → **직원 형태·Hurt·Dying 없음**(잡몹과 동일: 피격=빨강 점멸·사망=공용 effect).

## 수집형 보스 3종 — 캐릭터·외형·설정 (정본, 2026-06-22)

> 라인업·실루엣(위)·전투 패턴(아래)에 얹는 **캐릭터 레이어** = 각 보스가 *누구이고·왜 쳐들어오며·어떻게 생겼나*. 세계관 §8의 "직함↔실체 갭·왜 쳐들어오나·계약 후 직원 성격" 빈칸을 채운다. 이름은 전부 **가제**(정식 명명은 세계관 §8 명명 의제와 함께).

### 관통하는 코미디 엔진
> **세 보스 다 거창한 직함을 달고 마왕성을 *부수러* 왔는데, 알고 보면 마왕성이 주는 그 직무가 평생 진짜 원하던 자리였다.**

- 직함은 웅장한데 실체는 좁다 — Ch1 "동네 초보 모험가" = *작은 동네 한정 거물*(초보 마왕 ↔ 초보 용사 거울 구조).
- "어제의 적이 오늘의 동료"(세계관 §3)를 *기계적 보상*이 아니라 **웃긴 안도**로 전환 → "위엄→귀요미" 변신에 서사적 동기를 줌(용사로 사는 것보다 직원이 본인한테 더 맞음, 본인은 죽어도 인정 안 함).

### 외형 화법 (3종 공통)
- 단일 치비(2~3등신, `EN6`) · 얼굴은 **데드팬**(정색, 웃기려 하지 않음) · 코믹은 *비율·소품·마모*로만(자뻑 허세 금지, 톤 헌법).
- **외형에 텍스트 0** — 읽히는 글자 금지(다국가 서비스, 현지화 생존). 모든 코믹 tell은 *비율·소품 형태·마모*로만 작동.
- 위엄은 *크기·디테일 밀도·아우라*로(비율 안 키움, `EN6`).
- 위엄→귀요미 **동일 캐릭터**: 식별자(장비·색·실루엣) 고정, 변하는 건 크기·표정·아우라.

#### 1-1 방패 성기사 *(가제 Sir Aldous, the Bulwark)*
- **외형**: 거대 타워실드 + 풀판금, 둔중한 "벽" 실루엣. 투구로 얼굴 가려 **눈만**. 방패 전면에 무수한 찍힌 자국·마모(평생 막아낸 이력). 식별자 = 타워실드·판금·색.
- **직함↔실체 갭**: "아무도 그를 지나치지 못했다"는 무패 명성 = *애초에 아무도 통과를 시도 안 해서* 생긴 전설. 직함 = 불패의 수호기사 / 실체 = 도전받은 적 없는 문지기.
- **왜 쳐들어오나**: 현상금 ❌ — 마왕성 성문에 *제대로 된 문지기가 없다는 게* 직업적 모독이라 진군.
- **계약 후**: 성문 방어 구역(성 HP·방어력 ↑). 과묵·고지식, 자기를 *원하는* 초소를 얻어 만족.

#### 1-2 대마법사 *(가제 Magister Orin)*
- **외형**: 공중부양 + 룬 소용돌이 + 거대 로브·뾰족 모자. 모자 그늘에 **눈만**, 모자 끝에 동그란 안경. 손엔 펼친 두루마리(읽히는 글자 없이 형태만). 식별자 = 룬 로브·뾰족 모자·안경·색.
- **직함↔실체 갭**: 학위·간판은 진짜인데 실전 마법은 「졸개 소환」 하나뿐인 이론가. 직접 안 싸우고 *위임*만. 직함 = 대마법사 / 실체 = 부하 없으면 무력한 행정가.
- **왜 쳐들어오나**: 마왕성 지하의 *미연구 저주/금서*가 연구에 필요 — 토벌이 아니라 1차 사료 확보.
- **계약 후**: 저주 연구실/연금술실(연구·마법 강화). 깐깐한 이론가, 합법적 연구실+조수를 얻어 천국.

#### 1-3 전설의 용사 *(가제 the Hero of Lowmere)*
- **외형**: 전설의 대검 + 성광 아우라 + 펄럭 망토. **가장 두꺼운 위엄**(크기·디테일 밀도·아우라). 대검이 본인 키보다 큼. 식별자 = 대검·성광·망토.
- **직함↔실체 갭**: 실력도 전설도 *진짜* — 단 **초보들의 동네 안에서만**. 큰 물고기, 작은 연못(본인은 모름/인정 안 함). 직함 = 전설의 용사 / 실체 = 동네 한정 전설.
- **왜 쳐들어오나**: 예언·운명 — "언젠가 마왕을 친다"고 길러졌고, 드디어 (작고 가난한) 마왕이 나타남. Ch1 졸업 시험격, 위엄 최대.
- **계약 후**: 왕좌의 방 간판 고문(Ch1 클리어 상징·종합 버프). 사명감 강함, 무대(간판)를 얻어 영웅질만큼 진지하게 홍보.

### 관통 일관성 — 전투 메커니즘 = 성격 = 직원 (`EN23`)
> 「동일 캐릭터 원칙」(↓외형판)의 **행동 버전.** 플레이어가 전투에서 *몸으로 배운* 그 보스의 행동 양식이, 직원이 되면 **같은 양식의 평화로운 버전**으로 돌아온다 → 변신이 "딴 캐릭터"가 아니라 "같은 사람의 진짜 자리"로 읽힘. (CotL "테마=메커니즘"[기근=굶김·비겁=도주] 적용 — [레퍼런스_타게임_보스.md](./레퍼런스_타게임_보스.md) §4.)

| 보스 | 성격 명사 | 전투에서 (메커니즘 = 성격) | 계약 후 직원 (같은 성격) |
|---|---|---|---|
| **1-1 방패 성기사** | 고지식한 방어 본능 | 평소 DR로 안 뚫림 + **와인드업에만 정직하게 틈** = 우직하게 막다가 틈도 정직 | 성문 방어 구역 — 시키지 않아도 문을 지키는 **과잉 충성**(허점마저 정직) |
| **1-2 대마법사** | 손 안 대고 위임 | 직접 안 싸우고 **소환진으로 졸개만 뱉음** = 부하 시켜 처리 | 저주 연구실 — 실무는 조수에 떠넘기고 본인은 이론·설계. **위임이 곧 일하는 방식** |
| **1-3 전설의 용사** | 거리 두고 폼(작은 연못 큰 물고기) | **카이팅+검기** = 직접 안 붙고 원거리서 폼나게 처리 | 왕좌의 방 간판 고문 — 현장 안 뛰고 무대(간판)서 상징·홍보. **거리 두기가 곧 포지션** |

- **효과 1 — 전투 = 무료 캐릭터 소개.** 메커니즘 자체가 성격을 전달 → 텍스트 0으로 인물을 각인(외형 화법 §과 정합). 플레이어는 *싸우면서* 누구인지 배우고, 직원판이 그 읽기를 **페이오프**.
- **효과 2 — 아트 제약(발주 반영).** 직원판 포즈·소품이 전투 메커니즘을 **에코**해야 일관: 1-1 직원=막는 포즈 / 1-2 직원=위임(떠넘기는) 포즈 / 1-3 직원=거리 두고 지시 포즈. → [아트의뢰_보스_Ch1_3종.md](../../아트의뢰_보스_Ch1_3종.md) 반영 대상.
- **1-3 escalation도 이 성격의 시간축 버전**(`EN22`) — "작은 연못의 큰 물고기"가 무너지자 *거리 두기 폼*이 **발악**으로(P3 카이팅 포기). 메커니즘 변화 = 자존심 붕괴 아크.

## 수집형 보스 3종 — 전투 패턴 · 공격 컨셉 (정본, 2026-06-19)

> 라인업·실루엣은 위에서 확정. 이 절은 그 위에 얹는 **전투 메커니즘 레이어** = 각 보스가 *무엇으로 때리고, 어떻게 끊기는가*. 중간보스 2종(엘리트)은 페이즈 없는 스탯 정예라 보류.
> **⚠️ 코드 미반영** — `Boss.gd`는 아직 옛 2패턴(`_pattern_intern` 돌진·`_pattern_albaeng` 3페이즈)만. 신규 패턴·공격 컨셉은 기획 확정·미구현(↓현재 상태 표 `BS8~BS11`).

### 마스터 클록 = 낙뢰의 홀 쿨다운 **12초**
모든 "끊는 윈도우"는 이 12초에 상대적으로 설계한다 (`AbilitySystem.gd:LIGHTNING_COOLDOWN = 12.0`). 핵심 원리 한 줄:

> **윈도우 주기 > 12초 → "낙뢰 항상 준비됨 = 무조건 끊어라"(학습).** **< 12초 → "낙뢰 못 차 = 어느 걸 끊나(선택)".**

낙뢰는 와인드업/시전 적중 시 캔슬+스턴 1.5s+×2 치명타(`LIGHTNING_DMG_BOSS_WINDUP = 2.0`). 나팔(6s 쿨)은 보스 넉백면역이라 캔슬 도구 아님. 하인 평타로도 캔슬 불가 — **캔슬은 낙뢰 전용**(의도된 마법 한 방).

### 거리 차별화 — 3칸 안 겹치게 + 낙뢰 1마법을 3가지로 가르치기

| 슬롯 (HP) | 보스 | 거리·거동 | 시그니처 공격 (와인드업) | 난이도 | 낙뢰가 가르치는 것 |
|---|---|---|---|---|---|
| **1-1** (500) | 방패 성기사 | **고정 근접** | 방패 **치켜듦**(2s) → 내리꽂기 강타 | 튜토 | **타이밍** — 끊는 한 순간 |
| **1-2** (3000) | 대마법사 | **후열 고정 소환** | **대소환진** 전개(2s) → swarm 한 무리 | 쉬움 | **위치·묶음** — 멀티타겟 |
| **1-3** (6000) | 전설의 용사 | **이동 원거리(카이팅)** | **검기 장판** 시전(주기 7→5→3.5s·페이즈별) | 본 시험 | **선택·도달** — 어느 시전을 끊나 |

#### 1-1 방패 성기사 — "철벽과 균열"
- **거동**: 성벽 앞 고정. 평소 방패로 전신을 가려 **받는 피해 ×0.5**(DR 50%) = 안 깨지는 벽.
- **시그니처 = 와인드업 그 자체.** 방패를 머리 위로 **치켜든 2초**만 몸통 무방비(DR 해제·풀딜). 바로 그때 낙뢰 = 캔슬+치명타. **취약창과 공격예비동작이 같은 순간** → 1-1이 가르치는 전부가 이 한 동작.
- 페이즈 X · 소환 X. 가장 단순 → 첫 구현 후보.

#### 1-2 대마법사 — "소환진"
- **실루엣 재해석**: 캐스터를 근접으로 두면 어색 → **소환사형**으로. 후열 고정, 직접 안 싸우고 **소환진을 열어 졸개(swarm)를 계속 뱉음**. "근접 아닌데 쉬움" 조건 자연 충족.
- **시그니처**: 주기 swarm 소환. 와인드업 = **대소환진**(2s) — 끊으면 그 무리 통째 캔슬.
- **낙뢰 학습**: 본체가 아니라 **소환진/swarm 묶음**에. "근원을 끊나, 졸개를 치나" 선택(잡몹 ×3 배수).

#### 1-3 전설의 용사 — "삼위일체" (본 시험)
- **실루엣 재해석**: 영웅을 순수 근접으로 두면 카이팅("벽으론 못 막는다")이 안 나옴 → **검기를 원거리로 쏘는 신속검사**. 성검에서 검기/성광 투사 + **잔상 대시**로 거리 유지. "벽이 의미없다"가 영웅에겐 "너무 빠르고 검기가 날아와서"로 읽힘. 만능 3페이즈 = 피날레 격.
- **어휘는 셋뿐, escalate = 압축만** (CotL 샤무라 원칙 — "새 기술 없이 케이던스로 escalate", `EN22`). 새 기믹 0:
  - **① 검기 시전** — 후열 장판 검기. *시전 동안 고정(카이팅 멈춤) = 무방비 = 딜 초대장.* 바닥 선형 슬래시 마커 + 낙뢰 캔슬 가능.
  - **② 잔상 대시(카이팅)** — 하인 붙으면 후방으로, 단 후방 한계선까지만.
  - **③ 부하 기사(swarm)** — 접근로 차단, 캡 6.
- **페이즈 = 같은 어휘의 케이던스 압축**:

| | HP대 | 시전 주기 | 검기 | 카이팅 | swarm | 가르치는 것 |
|---|---|---|---|---|---|---|
| **P1 도달시험** | 100–66% | 7s | 단발 | 약(살짝 백스텝) | 없음/최소 | "벽으론 못 막아 — 마물을 *도달*시켜라" |
| **P2 카이팅+차단** | 66–33% | 5s | 2연발 | 적극(한계선까지) | 접근로 차단 | 동시 위협 2소스(밀도) — *경로*가 줄어듦 |
| **P3 발악** | 33–0% | 3.5s | 연타(chain) | 포기·자리잡음 | 대량(캡6 회전) | 막판 폭발 + 자리잡음 = 영구 딜창 |

> **escalation이 곧 캐릭터 아크** — P1 여유 거리두기 → P2 하인 시킴 → P3 자존심 발악("작은 연못의 큰 물고기"가 무너짐). 끊기 인터랙션·시각·공간 답은 ↓ `EN22` 절.

### 1-3 공정성 가드레일 (어렵게가 아니라 *공정하게*)
> 1-3이 망하는 전형 = ①영영 못 잡는 카이팅 ②세 압박 동시 폭격 ③성 녹음. 셋을 구조로 막아 "Ch1 졸업 시험"으로 안착시킨다. 실패해도 메타(왕관·해골·EXP)는 보존 → 도전적이어도 처벌이 아님(로그라이트 실패 완충).

| 가드레일 | 규칙 | 이유 |
|---|---|---|
| **카이팅은 몰 수 있다** | 후퇴는 **맵 후방 한계선까지만**. 벽에 닿으면 더 못 빠짐 → 하인이 따라붙어 **보장된 딜 윈도우** | 무한 후퇴 = 어려움 아닌 "안 끝남" |
| **압박은 페이즈로 엇갈림** | P1=도달만 · P2=카이팅+약 swarm · **3압박 동시는 P3뿐**(HP 25%↓·짧은 스프린트) | "지속되는 벽" 대신 "막판 폭발" → 어려움이 짜릿함으로 |
| **낙뢰는 선택지지 의무 아님** | 검기 장판 = **텔레그래프 회피 가능** + 1~2발 안 막아도 버틸 피해 | 낙뢰가 *필수 반응*이면 12s 쿨에 묶여 숨막힘 |
| **④ 시전 중 고정 = 보장 딜창** (`EN22`) | 검기 시전 동안 보스 정지·무방비 → 카이팅이 답답해도 **매 시전마다 창이 열림**(낙뢰/마물 평타) | 텔레그래프 = 딜 초대장(CotL 레시·아임). 가동률 바닥 보장 → HP6000 슬로그 완화 |
| **⑤ P3는 빌드를 *시험*하되 *몰수* 않음** (`EN22`) | P3 발악도 마법·마물을 끄지 않음. swarm 캡 6 유지·검기 탱킹 가능 유지 | "쌓은 엔진 vs 막판 버스트"지 "버스트가 엔진 무시"가 아님. 나린더 안티패턴 회피(로그라이트 파워판타지 보존) |

- **HP 6000 = 1순위 튜닝 노브.** 카이팅으로 딜 가동률이 낮으면 6000은 3분 슬로그(지루함). 실측에서 **가동률 vs HP**를 같이 보고, 낮으면 HP부터 깎는다.

### 1-3 끊기 인터랙션 · 시각 · 공간 (2026-06-24 · `EN22`)
> A 재설계의 못 = 1-3을 *닷지 게임이 아니라 운영 게임*으로 박는다. 외부 근거 = [레퍼런스_타게임_보스.md](./레퍼런스_타게임_보스.md) (Cult of the Lamb · Capybara Go!).

**끊기 타임라인** — 한 번의 검기 시전:
```
[시전 시작] ── 와인드업(마커 fill ~1.8s) ── [임팩트] ──(짧은 고정)── [카이팅 재개]
   정지+검 치켜듦      ◄═══ 캔슬 윈도우 ═══►        못 끊으면 장판 발동
```
- **언제** = 와인드업 구간(정지~임팩트). 임팩트 후엔 못 끊음(이미 나간 공격).
- **어떻게** = **낙뢰만**(캔슬 전용). 용사는 평소 카이팅으로 안 맞다가 *시전 중 정지*해야 낙뢰가 본체에 꽂힘 → **메커니즘이 곧 카운터 성립 이유.** 적중 = 장판 무효 + 스턴 1.5s + ×2 치명타(`BS6` 재활용).
- **와인드업 ~1.8s = 공정성 하한선.** 3스텝 탭 실행(~1s)보다 길어야 "봤는데 못 끊음"(불공정)이 안 남. **페이즈 무관 일정** — 압박은 *주기*로만 오름(개별 시전은 항상 공정).

**가능성은 보편, 자원은 희소** (끊기의 두 층):
- **개별 시전은 다 끊을 수 있다** — 낙뢰만 준비됐으면 *어느 시전이든* 골라 끊는다(P3 연타 한 링크도 개별론 공정).
- **전체 시전은 다 못 끊는다** — 낙뢰 12s 쿨 < 시전 빈도라 *골라서.* 끊는 비율 P1 ~3/5 → P2 ~2/5 → P3 ~1.5/5. ⇒ 1-3의 "선택" 교훈.
- → **공정성은 가능성으로 보장, 도전은 자원으로.** 칼라마르 함정(못 끊는 공격)도, 1-1식 "무조건 끊어" 반사도 **둘 다 회피.**

**나팔은 끊지 못한다 — 대신 "도달"** — 캔슬은 낙뢰 전용(나팔 6s까지 끊으면 "자원 희소" 붕괴 → 선택 사라짐). 게다가 나팔 = 넉백/제압인데 보스는 면역·저항이라 본체에 무효. **나팔의 1-3 임무 = swarm을 밀어/정지시켜 마물이 보스에 닿는 길 열기**(낙뢰 = 끊기 / 나팔 = 길 열기, 분업).

**못 끊는 시전의 답 = 흡수 + 공간(소환 운영)** — 닷지가 없으니:
- **흡수(주력)** — 성 HP 예산으로 1~2발 탱킹(Capybara식 *라운드 예산*). 우리는 CotL보다 흡수 비중이 큼 = 우리 정체성.
- **공간(보조) = 소환 운영**, 유닛 마이크로 아님(마물은 자율 AI). 레버 3: ①소환 타이밍(검기 차오르는 레인에 신참 안 던짐) ②구성·역할(전방=탱크 흡수·후방=무른 딜) ③과투자 자제(선호 레인 몰빵 금지). *느린 전략 층 = 머리 쓰는 라이트 전략.*
- **한계** — 이미 박힌 마물은 검기에서 *못 빼냄*(후퇴 명령 없음) · **성 직격 검기엔 공간 답 없음**(끊거나/흡수뿐).

**검기 표적 비율 = 질감 노브** — 검기가 *레인(마물)* 직격이면 "소환 운영+끊기"(군대 소모 vs HP 레이스), *성* 직격이면 "끊기/흡수"(낙뢰 선택 압박). **추천 = 레인 위주 + 가끔 성 직격** → 소환 레버와 낙뢰 선택 둘 다 의미.

**시각 표현** (색 최종은 [08_UI](../08_UI/) 가독성에서):
- **와인드업 = 정지 대비 극대화** — 카이팅 정지 + 대검 치켜듦(성광 차오름) + 발밑 캐스팅 링, **3신호 동시** → "멈췄다 = 기회" 각인.
- **마커 = 선형 슬래시**(원 아님) — 검기 정체성 + 기존 원형 인디(근접 파랑·원거리 빨강 `EN14`)와 **형태로 구분.**
- **fill = 임팩트 카운트다운** — 마커 차오름 = 남은 반응 시간(위치 아니라 *채워짐*으로 읽음).
- **escalate = 같은 마커 더 촘촘**(P1 1개 → P2 2개 → P3 연쇄). 신규 이펙트 0.
- **캔슬 피드백** — 검 떨굼 + 마커 깨지며 소멸 + 스턴 별 + ×2 치명타 플래시(`BS7` 재활용). 장판 *소멸*이 "위협 지움" 보상.
- **색 잠정** — 성광 **흰금 코어 + 짙은 외곽선**(흰색 저대비 함정 회피). 기존 4색(낙뢰 노랑·나팔 보라·근접 파랑·원거리 빨강)과 안 겹치게 08_UI 확정.

**비용** — 페이즈별 주기/연발수·표적 비율은 *튜닝 파라미터*(샤무라 이득). **신규 코드는 `EN15` 원안 2개에서 변동 없음**(방패 DR·검기 시전+카이팅).

### 위엄 → 귀요미 「동일 캐릭터 원칙」
> 적 형태와 계약 후 형태가 **한눈에 같은 인물**로 읽혀야 한다 (안 그러면 보상이 아니라 혼란).

> **화풍은 단일** — 전 캐릭터 치비(2~3등신) 유지. 보스 위엄은 비율 키우기 ❌ → **크기·디자인 밀도·아우라·묵직한 애니**로 (2026-06-17 `EN6`).

| 변하는 것 | 변하지 않는 것 (식별자) |
|---|---|
| 크기: 큼 → 작음 | 시그니처 장비 (방패·대검·모자 등) |
| 표정·포즈: 위풍당당 → 풀죽음·순응 | 색 팔레트 · 문장/엠블럼 |
| 아우라: 위압 광휘 → 없음 | 실루엣 핵심 요소 |

→ "왜 바뀌나"의 답 = **계약 마법이 위압만 빼고 길들인다 (정체성·장비는 그대로).** 작아져도 본인은 여전히 진지.

### 계약 후 = 부서 직원 (직군 → 부서 매핑)
> 처치한 보스는 **귀요미 직원**으로 성에 편입, 클래스 = 직무. 전투 불참(방화벽), 메타 강화만. 정확한 수치·효과는 로비 메타([Lobby/](../../Lobby/) D1~D7·위엄)와 정합 — 신규 시스템 신설이 아니라 *연결*.

| 보스 | 부서 | 기능(메타) |
|---|---|---|
| 방패 성기사 | 성문 방어 구역 | 성 HP·방어력 ↑ |
| 대마법사 | 저주 연구실 / 연금술실 | 연구·마법 강화 |
| 전설의 용사 | 왕좌의 방 (간판 고문) | Ch1 클리어 상징·종합 버프 |

### 연출
위엄 등장 → 처치 → 계약서 사인 → **펑(귀요미 변신)** → 부서 배치. 기존 충신 획득 연출(`feat/충신-획득-연출` 브랜치) 재활용.
