# 03. 하인 소환 (Undead Minions)

> 영혼으로 해골 하인을 소환해 전선을 형성. 소환 타이밍·종 선택 = "사용자 결정"의 핵심 축.
> ✅ **MD1 (2026-05-29): 4종 + 영혼 비용 소환 = MVP 정본.** 기획 §7("단일 종, 다종/진화는 라이브 확장")은 *구버전* — 게임 방향을 "머리 쓰는 라이트 전략"으로 확정하면서 코드 현 상태가 정본이 됨.
> ⚠ **MD6 (2026-05-30): 진화는 폐기** — 플레이 중 전혀 인지 안 됨 → 단순화. 하인=키우지 않는 **소모품**. 대신 **희생 액션**(살아있는 하인을 능동적으로 비워 국소 광역+슬롯 회전) 신설. ([결정 로그](#결정-로그) 참고)
> 🔴 **재설계 진행 중 (2026-06-12, `RD13`)** — 전투 운영자 리디자인([02 RD1~RD13](../02_영주_전투/))에서 영주 아바타 제거·유물 2슬롯 탭 권능으로 가면서, 하인도 **라이브 4버튼 소환·슬롯(`max_minions`)·희생 버튼·소모품 모델(MD1~MD10)** 을 버리고 **런 내 영구 누적 군대 + 영혼 경제 편성 + 수비적 마중 요격 + 영구사망**으로 전환. 아래 `책임`·`현재 상태`·`MD1~MD10`은 *교체 전 현행 기록*. 새 방향 = [재설계 섹션](#재설계-운영자-리디자인-2026-06-12) ↓. 근거 = 02 `RD7`/`RD10`/`RD13`. 브랜치 `feat/전투-운영자-리디자인`.

## 재설계 (운영자 리디자인, 2026-06-12)

> `RD13` 확정·**미구현**. 하인을 "라이브 소환하는 소모품"에서 "런 동안 키우는 영구 군대"로 전환. 카드(권능 증폭)·키스톤과 **병렬로 자라는 세 번째 빌드 트랙**.

### 경제·지속성
- **런 내 영구 누적 군대** — 런 동안 죽지 않는 한 계속 따라오는 *자라는 자산*. 웨이브 리셋 아님(KR 타워식 매판 재편 = 기각, 자유이동이라 위치 빌드가 없어 누적·애착이 핵심).
- **영혼 = 처치당 적립**(잡몹 12~20·보스 100~200, 현행 유지). **웨이브 클리어 보너스 없음.** 전투 중 소비처 0(권능=쿨다운) → 웨이브 사이에 몰아 **고용·승진**에 소비. → 처치형 권능(낙뢰)이 곧 경제를 돌림.
- **영구사망** — 죽으면 개체 **+ 쌓은 승진** 영구 손실 → 영혼으로 신병 재고용(절대 손실 아닌 *복구 비용*). 죽음의 소용돌이는 **실패 완충이 메타(런 밖: 왕관·해골·EXP)에 있어** 설계상 허용 → 영구사망의 무게가 정직. (재생형 = 기각)

### 전투 행동 — 수비적 마중 요격
- 하인은 **성 앞 수비 밴드** 안에서만 활동. 적진(밴드 위)으로 **돌진 안 함**(돌격형 = 영구사망 정예를 적진 투하 → 기각. 고정라인 = `feat/충신-획득-연출`에서 이미 롤백).
- 밴드 안에서 다가오는 적을 **맞으러 짧게 이동**해 막음(레인 폭 빈칸 커버). 타겟 = **가장 깊이 침투한 적**(수비 본능). *순수 거치(턴렛)는 가로 빈칸으로 적이 샘 → 마중 허용*.
- **leash** — 교전 적이 밴드 밖으로(넉백 등) 끌려나가면 추격 포기·복귀. 적 없으면 성 앞 대기. (마중 허용 거리 = 밴드 크기 = 레버: 좁히면 거치형, 넓히면 능동적)
- **블로킹 = 기존 어그로 반경(`Enemy.gd MINION_ENGAGE_RANGE`) 재활용** — 적이 하인 반경에 들면 멈춰 교전(이미 작동). 하드 바디블록 신설 안 함. *(잠정 추천, 플테 재확인)*
- **4종 밴드 층위**: 탱크=최전방·넓은 어그로(벽) / 전사=중간·블로킹+근접딜 / 궁수=후방 **순수 사수(어그로 안 끎)** *(잠정)* / 폭탄병=예외(밴드 내 뭉친 적 돌진 자폭 = 영구사망과 결합한 의도적 소모).

### 권능 맞물림 (왜 자동 하인인데 "활용"이 성립하나)
RD7로 라이브 지휘는 없음 → **권능 선택이 곧 하인 운용**(간접 레버):
- **나팔(통제)**: 밴드 뚫은 적을 위로 밀어 → 하인 재정비·재집결 시간을 벎(통제의 가치 = 하인에게 시간을 사줌).
- **낙뢰(처치)**: 후방 궁수를 노리는 적·탱크가 못 붙잡고 새는 침투 적을 점 제거(요격 빈틈 메움).

### 코드 전환 방향 (구현 시)
- `SkeletonWarrior` AI: `_find_nearest_enemy()`(돌격형) → 수비 밴드 + 침투 우선 + leash 마중.
- `Enemy._find_nearby_minion()`/`MINION_ENGAGE_RANGE`: 블로킹 도구로 유지·튜닝.
- 라이브 소환 4버튼·`max_minions` 슬롯·희생 버튼: 제거(→ 웨이브 사이 편성으로 이전).
- 영혼: 전투 중 소비 분기 제거, 적립만. 소비 = 웨이브 사이 편성 UI(기존 영혼 상점 노드 매핑 후보).

### 남은 작업 — 편성 메타 (2026-06-12 보류, 재논의 대기)
전투 *활용*은 확정. 웨이브 사이에 *어떻게 키우나*는 미설계:
- **승진(업글) 내용** — 등급 티어? 스탯 상승? 무엇을 올리나.
- ~~**군대 규모 캡** — 무한 누적 vs 소프트 캡(구 `max_minions=3` 대체). 영혼 게이팅으로 자연 제한될지.~~ → **MD12 해소 (2026-06-14): 전역 총량 캡 기본 6 + `minion_count` 카드 성장. 종류별 캡 폐지.**
- **편성 UI** — 영혼으로 고용/승진하는 웨이브 사이 화면.
- **출처 하이브리드** — 일반 하인=영혼 추상 고용 / 보스=충신 편입(`feat/충신-획득-연출`)와 정합 정리.
- 검증 빌드엔 **고정 프리셋**으로 대체(편성 미구현, [02 RD12 검증 빌드](../02_영주_전투/) 참조).

## 미해결 의제 (MD1 결정으로 새로 열린 후속 의제)

4종+진화를 정본화하면서 *닫힌* 의제(종 수·비용 모델)는 [결정 로그](#결정-로그)로, 그 결정이 *새로 강제한* 의제는 아래로:

- **MD2 — 단계 해금 스케줄** — "머리 쓰는 전략"이라도 첫 화면에 4버튼을 한 번에 들이밀면 캐주얼·한 손 가독성이 깨짐. **챕터별 1종씩 해금**(전사 시작 → 챕터마다 +1, 4챕터에 4종 완성)을 권장. 어느 챕터에 어느 종? 미확정.
- ~~**MD3 — 진화 가시화**~~ → **MD6 진화 폐기로 소멸.** (진화 자체가 없어져 가시화 의제 무의미)
- **MD4 — 영혼 밸런스** — 소환(15~35)·특수기(50)·상점(18~40)이 한 풀을 공유. **희생(MD6)**은 직접 영혼을 쓰진 않지만 슬롯을 비워 *재소환*으로 영혼 소비를 유도하는 4번째 배출 경로. 적 처치 드롭(12~20)과 [05_보스](../05_보스/) 치명타 영혼 부족 레버가 여기서 충돌·상호작용. 별도 밸런스 패스 필요.
- **MD5 — 소환 쿨타임 잔존 여부** — 기획 §5/§7은 "5초 쿨 + 빠른 부활 카드(-1초)". 코드는 슬롯+영혼 게이트만 보임. 쿨타임을 비용 모델과 병행할지(이중 게이트) 아니면 영혼 비용으로 일원화할지 확정 필요. (`summon_speed`·`minion_cost_reduction` 카드 정합)
- ~~**MD7 후속 — 폭탄병 슬롯 점유 여부**~~ → **MD8 해결**: 폭탄병=자동 미사일(소환=발사, 상주 안 함) → 슬롯 거의 안 씀. 상주 슬롯은 전사/궁수/탱크 3종 차지.
- **MD7 후속 — 군세확장 카드 상한** — `max_minions += 1`이 무제한(`Game.gd:603`). 소환사 후반 슬롯 폭주 방지 위해 상한(예: 7) 둘지 점검.
- **와인드업 중 하인 소환 보너스** — devlog wip §6-3 미논의 가지: 4종 차별화 기회. → [05_보스](../05_보스/) 치명타 설계와 함께 논의.
- **로비 거주 해골과 별개 시스템** — 전투 하인 ≠ 로비 해골 정원([04_거주민](../../Lobby/04_거주민/)). 혼동 방지 명시.

| **MD8** | **폭탄병 = 자동 미사일** (범용 희생과 위계 분리) | 2026-05-30 | MD6 희생으로 "모든 하인=폭탄"이 되자 폭탄병 자폭이 안 특별해짐 → 폭탄병을 *능동 미사일*로 차별화. **소환=발사**(돌진→자폭, 상주 안 함, 슬롯 거의 안 씀). 다른 3종=상주 전선(희생 가능). **광역 3수단 위계**: 특수기(전체화면/영혼50/즉발) > 폭탄병(국소/영혼~20/돌진, 소환사 자원) > 범용 희생(하인 위치 국소/비용=하인 소모/슬롯 비우기 주목적, 폭발 약함). 코드 현 동작과 일치 → 범용 희생 폭발만 폭탄병보다 약하게 잡으면 됨. MD7 후속(슬롯 점유) 자동 해결. |
| **MD9** | **희생 액션 설계 확정 + 구현** (발동·범위·쿨·비용·위력) | 2026-06-01 / 구현 2026-06-02 | MD6가 남긴 미정(발동·비용/쿨·수치)을 해소. **발동 = A′(버튼 무장 → 하인 탭)**: 순수 직접 탭(A)은 어포던스 0이라 진화처럼 *인지 실패* 위험 → 하단 "희생" 버튼=발견 / 하인 하이라이트=이해 / 탭=위치 전술로 인지 3요소 충족. 순수 버튼자동(B)은 위치 전술이 죽어 차선, 버튼=전체일괄(C)은 특수기와 겹쳐 탈락. **범위 = 연속 허용**(슬롯 3 → 최대 3탭, 빈 곳/버튼 재탭으로 모드 종료). **쿨 = 무장 세션당**(발동 1회당 쿨이면 연속과 충돌) — 모드 끄는 순간 진입, 버튼 게이지로 표시. **비용 = 영혼 무료**(잉여 배출이 목적이라 영혼 매기면 자기모순. 실비용 = 하인 손실 + 재소환 영혼). **위력 = 고정 광역**(HP비례는 "왜 약하지?" 인지 함정 재발 위험 → 진화 교훈), 폭탄병보다 약하게(MD8). **목적 우선순위: ①슬롯 회전 > ②국소 피해**(피해는 행동의 보상). 구현: 희생 버튼(특수기 옆 40% 분할), 무장 모드(하인 붉은 펄스), 탭 판정, 세션당 쿨 8s 가제, 반경70/뎀40 가제, `minion_died` 경유, 「제물의 의식」 키스톤으로 무료 재소환 연동. 수치는 가제, 플레이테스트 조정 대기. |
| **MD10** | **희생 발동 = 1탭 자동(전선 하인)으로 변경** | 2026-06-02 | MD9의 A′(버튼 무장→하인 탭)가 플레이테스트에서 2단계라 너무 복잡·발견성 낮음(진화 MD6의 인지 실패 함정 재발). MD9가 "차선"으로 봤던 버튼 자동(B안)을 채택하되 "전선 하인 자동 선택"으로 위치 전술 손실 최소화. 목적 우선순위 ①슬롯 회전 > ②피해라 위치 선택(②) 포기 수용. **무장 모드·월드 탭·하이라이트·세션 개념 전부 제거.** 쿨=발동당(세션 개념 소멸), 영혼 무료·반경/위력 가제 유지. 전선 하인 = 적과 가장 가까운 상주 하인(`_find_frontline_minion()`, 적 없으면 첫 상주 하인 폴백). |
| **MD11** | **하인 비주얼 = 해골 → 귀여운 마물 소환수 4종** (로스터 전사·궁수·탱크·폭탄병 코드대로 확정, 아트 전면 교체) | 2026-06-04 | 임시 해골 에셋(`skeleton_warrior_1~3`) 전량 교체 결정. **로스터는 MD1 4종(전사/궁수/탱크/폭탄병) 그대로 유지** — 비주얼만 언데드→마물(B안). 세계관 W8(초보 마왕)의 "마왕이 소환하는 마물" 결과 정합: 하인=소환수(일회성·전투용), 계약 직원(옛 용사·비전투)과 별개라 전투 소모에도 톤 충돌 없음. 종족 매핑(가제)=임프(전사)/고블린(궁수)/슬라임(탱크)/버섯(폭탄병) — **역할별 실루엣 구분 가독성** 우선. 아트 의뢰서 = [`아트의뢰_하인_4종.md`](../../아트의뢰_하인_4종.md). 코드 후속: `_build_sprite_frames()` 경로·접두 하드코딩 + `TYPE_PRESETS.variant`(폭탄병이 전사 아트 재사용 중) → 입고 시점에 타입별 폴더 매핑으로 교체. |

| **MD13** | **마물 정지 컷 1차 입고 (전사·궁수·탱크) + 스프라이트 크기 = 콘텐츠 기준 자동맞춤 정규화** | 2026-06-16 | MD11 의뢰의 풀애니(81프레임/종)는 아직 작업 중 — 작화자가 보낸 **정지 컨셉 1컷**(900×900)을 임시로 인게임 적용. 전사=공룡, 궁수=박쥐, 탱크=슬라임(가제 종족은 MD11과 별개로 실제 작화 반영). `SkeletonWarrior.gd:STATIC_SPRITES`에 역할→이미지 경로 등록, `_build_static_frames()`가 idle/walk/slash/hurt/die 5동작을 **같은 한 컷으로 채움**(애니 없음, die는 1프레임 즉소멸). 풀애니 입고 시 같은 폴더(`assets/characters/[Role]/`)에 프레임 넣고 `STATIC_SPRITES`에서 제거→프레임 로더로 자동 전환. **크기 문제 = 정공법으로 해결**: 기존 해골은 `size_limit=256` 임포트로 실제 렌더 ~63px였는데 새 컷은 풀해상도라 같은 `BASE_SPRITE_SCALE 0.246`에서 2.3배 커짐. 에셋마다 캔버스 여백이 달라 고정 배율은 매번 깨짐 → **콘텐츠(불투명 bbox) 높이를 런타임 측정해 목표 px로 정규화**(`_get_fit_scale`, `get_used_rect().size.y` 기준, 타입별 캐시). `scale = TARGET / 콘텐츠높이 × base_scale`로 **여백 무관·에셋 교체에 강건**. `base_scale`(탱크 1.45 등)은 그 위에 곱해 게임플레이 크기 위계 유지. bbox 높이만으론 실루엣 질량(공룡 다부짐·슬라임 두툼) 차이를 못 잡아 `TYPE_TARGET_PX` 역할별 오버라이드 추가 — 플레이테스트 확정값: **전사 55 / 궁수 63 / 탱크 38**(셋 다 렌더 ~53~55px로 수렴). 폭탄병은 **현재 플레이서 제외** 상태라 미교체(해골 유지). 진화(MD6 폐기) 잔재 `_evolve()`의 스케일도 `sprite_base_scale` 공유로 일관화(제거는 별건). |
