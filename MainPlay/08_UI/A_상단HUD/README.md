# A. 상단 상태 HUD

> 레이어 **L1 (상시 HUD)**. 전투 내내 항상 보이는 위치·진행·성 상태 정보.
> 플레이어가 "지금 어느 웨이브인지", "앞으로 몇 개 남았는지", "성이 버티는지"를 한눈에 파악하는 축.

## 구성 요소

| ID | 이름 | 노드 경로 | 역할 |
|---|---|---|---|
| A1 | 스테이지명 라벨 | `$UI/WaveLabel` | **"스테이지 N-N"** 포맷 (예: 스테이지 1-1). 트래커 **위**에 배치 |
| A2 | 웨이브 진행 트래커 | `$UI/WaveTracker` (HBoxContainer) | **압축형 노드 스트립** — 앞쪽 3개 + "…" + 최종보스 (카피바라고 참고) |
| A3 | 성 HP 바 | 상단 고정 (현 `$Castle/CastleHP` → 상단 HUD 이전 예정) | **분절형 성벽 블록**, 화면 상단 고정, **유일한 패배 게이지** |

## 위치 / 크기 (현재)

- **A1** 스테이지명 라벨: 트래커 **위** (현 코드는 트래커 아래 y=42 → 순서 반전 + "스테이지" 접두어 추가 후속)
- **A2** 트래커: 상단 가로 배치. 현 코드는 웨이브 수만큼 전체 버튼 생성 → **압축 스트립으로 변경 후속**(아래 상태 정의)
- **A3** 성 HP 바: **상단 HUD 고정**(전폭 ~460). 정보 0순위라 화면 최상단 영역 차지. 현 코드는 월드부착(`$Castle/CastleHP`)이나 **상단 이전 예정** (→ 아래 결정 로그). 월드의 성 스프라이트엔 바 제거, 피격 피드백만 잔존

## 상태 정의

### A2 웨이브 트래커 — **압축형 노드 스트립** (2026-06-09 재설계, 카피바라고 참고)

> 트래커 = "런 여정 지도". 앞에 뭐가 오는지(상점/중간보스/보스)를 미리 보여줘 플레이어가 자원 운영을 계획하게 함 — 핵심재미(머리 쓰는 라이트 전략)와 직결. 단, 스테이지 웨이브가 길어질 수 있어 **전체를 다 보여주지 않고 압축**.

**표시 규칙:**
- 현재 위치 기준 **앞쪽 노드 3개** → **"…"**(생략) → **최종보스 노드(우측 끝 고정)**
- 최종보스는 항상 우측에 보여 "목표"가 늘 시야에. 진행하면 앞 3칸 윈도우가 슬라이드
- 노드 **종류별 아이콘**: 일반 / 상점 / 중간보스 / 최종보스 (텍스트 "상점·중간·보스"에서 아이콘 구분으로 격상)

**노드 진행 상태:**

| 상태 | 색상(현 구현 참고) | 표현 |
|---|---|---|
| 현재 | `Color(1,1,0)` 노랑 | 강조(확대·펄스) |
| 지난 | `Color(0.4,0.4,0.4)` 회색 | 흐림 |
| 남은 | `Color(1,1,1)` 흰색 | 아이콘 프리뷰(무엇이 올지) |

**미결(플테 조정):** 앞 3칸이 "현재 포함"인지 "다음부터"인지 / 중간보스도 끝처럼 고정 앵커로 띄울지(현재는 윈도우 진입 시에만 표시 가정) / 윈도우 슬라이드 타이밍.

### A3 성 HP 바 — **분절형 상단 고정바** (2026-06-09 설계 확정)

> 유일한 패배 게이지 = 화면 0순위 정보. 단순 ProgressBar가 아니라 **"성벽" 은유**로, 적이 닿을 때마다 칸칸이 부서져 패배 임박을 체감시킴.

- **형태**: 분절형 성벽 블록. 칸당 고정 HP(예: 10HP/칸 → 기본 100 = 10칸). 상점 「성벽 수리 +60」 등으로 max 증가 시 **칸 추가**(성벽 보강 은유). 미세 피해는 현재 칸 부분채움으로 흡수
- **위급 3단 연출** (긴장 = 시선이 전장에 있어도 주변시로 감지):

  | 단계 | 조건 | 연출 |
  |---|---|---|
  | 정상 | >50% | 차분한 색, 변화 없음 |
  | 경고 | 25~50% | 바 황색 + 느린 맥동 |
  | 위급 | <25% | 바 적색 + **화면 가장자리 붉은 비네트 펄스** |

- **0%가 되면 게임오버** → [E_결과시퀀스](../E_결과시퀀스/) 붉은 오버레이로 전환
- 영주는 HP가 없으므로 이 바가 게임의 유일한 생존 지표 (→ 상위 README "의도된 부재")
- **월드의 성**: HP 바 제거. 피격 시 성 스프라이트 깜빡임 + 낙하 데미지 숫자만 ([F_월드피드백](../F_월드피드백/) 결) — 상단 이전으로 약해진 "저 성이 맞고 있다"는 공간 연결을 보완

## 디자인 의제

- ✅ **A1 ↔ A2 정보 중복** — *해소(2026-06-09)*: A1=스테이지 식별(스테이지 N-N), A2=스테이지 내 노드 진행으로 층위 분리. A1을 트래커 **위**로 올려 "스테이지 1-1" 형식 라벨로 확정.
- ✅ **A2 트래커 시인성** — *해소(2026-06-09)*: 압축형 노드 스트립 + 종류별 아이콘으로 격상. 텍스트→아이콘.
- ✅ **A3 HP 바 위치·강조** — *해소(2026-06-09)*: 상단 HUD 분절형 고정바로 격상 + <25% 비네트 펄스로 확정. 구현 후속 = 코드상 `$Castle/CastleHP`(월드)를 상단 UI로 이전 + 분절 렌더링.
- **명명** — "1-2" 포맷·성(Castle) 명칭 모두 가제. 세계관(마왕성) 적용 시 교체.
