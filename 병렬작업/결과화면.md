# 결과 화면 작업 영역

> 게임오버 / 스테이지 클리어 / 결과 시퀀스 / 씬 전환.

## 담당 파일
- `scripts/ResultScreen.gd` — game_over·game_clear·결과 패널·페이드·씬 전환

## 책임 (이 안에서 자유)
- 게임오버/클리어 시퀀스(`game_over`·`game_clear`)·오버레이·위엄 EXP·진행 저장
- 결과 패널 콘텐츠 빌드(`_show_result`)·보상 표시·버튼(`_on_result_btn1/2_pressed`)
- 콘페티(`_spawn_confetti`)·페이드인(`_fade_in`)·씬 전환(`_fade_to_scene`)·시간 포맷(`_format_time`)

## 경계 — 건드리지 말 것
- 공유 상태: `game.wave_active`·`game._battle_over`·`game.crowns_this_run`·`game.run_start_time`·`game._majesty_exp_granted` → game. 경유.
- 결과 UI 노드(`game.result_panel`·`game.result_btn1/2`)·`game.card_panel`·`game.shop` → game.
- **`game_over`/`game_clear`는 Game 전투 로직(`castle_take_damage`·`on_boss_killed`)이 `result_screen.X`로 호출** → 시그니처 유지.
- 메타 저장은 `GameSave.X`(autoload) 경유.

## 안전 편집
- ⚠️ ResultScreen은 `extends Node` → 씬 노드는 `$UI` 대신 `game.get_node("UI")`.
- ⚠️ `shop` 같은 컴포넌트 참조도 `game.shop`.
- ⚠️ 버튼 연결은 `setup()`에서(컴포넌트 생성 후라야 함).
- 검증: `godot --headless --quit-after 5 scenes/Game.tscn 2>&1 | grep -iE "error|not found"`
