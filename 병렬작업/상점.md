# 상점 작업 영역

> 골드 상점 — 항목·구매·진입/퇴장 트랜지션.

## 담당 파일
- `scripts/ShopController.gd` — 상점 UI·구매 로직 (build/open/close/buy)
- `scripts/data/ShopData.gd` — `SHOP_ITEMS` (항목·가격·라벨·설명)

## 책임 (이 안에서 자유)
- 상점 항목 추가/삭제·가격·라벨/설명(`SHOP_ITEMS`)
- 구매 효과(`_apply_item` match)·구매 게이트(`buy_item`)
- 진입/퇴장 트랜지션·버튼 스타일·구매 글로우(`open`/`close`/`build_buttons`/`_flash_buy`)

## 경계 — 건드리지 말 것
- 구매 효과가 건드리는 공유 상태: `game.souls`·`game.castle_hp`·`game.castle_max_hp`·`game.attack_bonus`·`game.ability_cooldown_mult`·`game.ability_radius_mult` → game. 경유.
- `game._shop_dim_alpha`는 Game 소유(모달 공유) — 그대로 game. 사용.
- `game.shop` = 이 컨트롤러 자신(외부가 `game.shop.X`로 접근, 예: AbilitySystem이 `game.shop.shop_panel.visible`로 상점 열림 판정). **이름/공개 노드 바꾸면 그쪽도 확인.**

## 항목 추가 방법
1. `ShopData.SHOP_ITEMS`에 `{"id": "new", "label": "...", "desc": "...", "cost": N}`
2. `ShopController._apply_item` match에 `"new":` 효과 (공유 상태는 `game.X`)
- ⚠️ 부채: label/desc가 Loc 미경유 하드코딩 — 글로벌화하려면 Loc 이관(별도 작업).

## 안전 편집
- 외부 진입점: `open()`·`build_buttons()`·`close()`. 새로 외부 호출 필요하면 Game facade 1줄.
- 검증: `godot --headless --quit-after 5 scenes/Game.tscn 2>&1 | grep -iE "error|not found"`
