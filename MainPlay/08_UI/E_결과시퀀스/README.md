# E. 결과 시퀀스 (오버레이 → 패널)

> 레이어 **L2 (모달 인터럽트)**. 런이 끝날 때(게임오버/클리어) 뜨는 결과 화면.
> **컬러 오버레이 페이드인 → 결과 패널 등장**이 끊김 없는 한 연출이라 하나의 단위로 묶음.
> ⚠ 상호 배타: 카드(C)·상점(D)과 동시에 뜨지 않음.

## 구성 요소

| ID | 이름 | 구현 | 역할 |
|---|---|---|---|
| E0 | 컬러 오버레이 | 코드 생성 ColorRect | 패널 등장 전 화면 물들이는 전조 연출 |
| E1 | 리본 배너 타이틀 | 동적 PanelContainer + Label | "스테이지 클리어!" / "성이 함락됐다..." (가제) |
| E2 | 부제 | 동적 Label | 스테이지 번호 / 도달 웨이브 |
| E3 | 기록 시간 | 동적 Label | "N분 00초" |
| E4 | 보상 슬롯 | 동적 HBox (아이콘+수치 프레임) | 왕관 👑 / 위엄 ✦ (rewards 배열 기반) |
| E5 | 버튼 1 | `$UI/ResultPanel/Btn1` (.tscn 정적) | 다음 스테이지 / 다시 시작 |
| E6 | 버튼 2 | `$UI/ResultPanel/Btn2` (.tscn 정적) | 로비로 돌아가기 |

## 연출 시퀀스 (2단계)

```
[전투 정지] → E0 오버레이 페이드인 → [잠깐 유지] → ResultPanel 등장 (scale pop + fade)
   적·하인         0.6~0.9초          0.3초          0.25초 TRANS_BACK EASE_OUT
   physics 정지                                       is_clear=true: 콘페티 병행
```

| 케이스 | 트리거 | E0 오버레이 색 |
|---|---|---|
| 게임오버 | 성 HP = 0 | 붉은 `Color(0.4, 0, 0)` → α 0.55 (0.9초) |
| 클리어 | 최종 보스 처치 / 전체 웨이브 완료 | 금빛 `Color(0.9, 0.8, 0.1)` → α 0.4 (0.6초) |

## 상태별 내용

### 게임오버
```
E1: "성이 함락됐다..."                     (가제)  — 암적색 배너
E2: "스테이지 1-2  웨이브 3"
E3: "2분 15초"
E4: 👑 "왕관 +1 (총 3)"  ✦ "위엄 +5"   (왕관=런 중 획득 시만, 위엄=런당 1회)
E5: "↩  다시 시작"
E6: "로비로 돌아가기"
```

### 스테이지 클리어
```
E1: "스테이지 클리어!"                     (가제)  — 금빛 배너
E2: "1-2 완료"
E3: "3분 40초"
E4: 👑 "왕관 +5 (총 8)"  ✦ "위엄 +20"
E5: "다음 스테이지"  (마지막 스테이지면 비활성)
E6: "로비로 돌아가기"
```

## 보상 표시 규칙

- **왕관**: 클리어는 항상 표시. 게임오버는 런 중 획득(`crowns_this_run > 0`) 시에만
- **위엄 EXP** (런당 1회): 게임오버 +5(실패 완충) / 일반 클리어 +20 / 보스 스테이지 +40

## 비주얼 언어 (상점/카드 컴포넌트와 일관)

| 요소 | 클리어 | 게임오버 |
|---|---|---|
| 패널 bg | `Color(0.20,0.17,0.26,0.96)` | `Color(0.13,0.13,0.17,0.96)` |
| 패널 테두리 | 골드 `Color(0.85,0.7,0.3)` 2px | 핏빛 `Color(0.55,0.2,0.2)` 2px |
| 배너 bg | 금빛 `Color(0.78,0.62,0.22)` | 암적색 `Color(0.45,0.15,0.15)` |
| Btn1 | 골드 강조 (`Color(0.60,0.45,0.10)`) | 골드 강조 (동일) |
| Btn2 | 차분한 보라 | 차분한 보라 |

**보상 구분선**: `[───] 보상 [───]` HBox (ColorRect + Label + ColorRect)

**보상 슬롯**: 흰/밝은 테두리 프레임 PanelContainer. 아이콘(이모지 폰트) + 수치 Label.

## 등장 애니 (E0 직후)

- `result_panel.pivot_offset = size / 2`
- `modulate.a` 0→1, `scale` (0.9,0.9)→(1,1), 0.25초, `TRANS_BACK / EASE_OUT` (약한 오버슈트)

## 콘페티 (클리어 전용 — 임시 플레이스홀더)

클리어 시 `_spawn_confetti()` 호출. ColorRect ~22개를 `$UI`에 추가하고 Tween으로 낙하+회전+페이드 후 queue_free. **추후 아트 리소스로 교체 예정.**

## 코드 위치

- `scripts/Game.gd`
  - `game_over()` (1231) — E0 붉은 오버레이 + 보상 적립 + `_show_result()` 호출
  - `game_clear()` (1289) — E0 금빛 오버레이 + 보상 적립 + `_show_result()` 호출
  - **`_show_result(is_clear, title, subtitle, time_text, rewards, btn1_text, btn1_action, btn1_enabled)`** (1353) — 패널 콘텐츠 동적 빌드, 등장 애니, 버튼 스타일, 콘페티 트리거
  - **`_spawn_confetti()`** (1629) — 클리어 전용 콘페티 플레이스홀더
  - `_on_result_btn1_pressed()` (1658) — `action` meta 분기 ("next_stage"/"retry")
  - `_on_result_btn2_pressed()` (1668) — 로비 씬 전환
  - `earn_crown_shards()` / `GameSave.add_majesty_exp()` — 보상 적립

- `scenes/Game.tscn`
  - `ResultPanel` (Panel, z_index=10, offset 30/180/450/720) — 패널 루트. 내부 콘텐츠는 코드로 동적 빌드
  - `ResultPanel/Btn1` (앵커 하단, offset_top=-106) — 주행동 버튼 (.tscn 정적)
  - `ResultPanel/Btn2` (앵커 하단, offset_top=-50) — 보조 버튼 (.tscn 정적)

## 아트 리소스 후 폴리싱 (후순위)

- **콘페티** — `_spawn_confetti()` 플레이스홀더 → 파티클/스프라이트 시트로 교체
- **배너 핀테일** — 현재 둥근 박스, 실제 리본 핀테일 형태는 아트 입고 후 9-slice로
- **캐릭터 초상** — 클리어/게임오버 결과 화면 초상 이미지 (아트 의뢰 후)
