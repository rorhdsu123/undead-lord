# 06. 결과 / 보상 (Result & Rewards)

> 한 판의 끝 — 왕관 조각 회수, 게임오버/클리어 패널, 로비 복귀·재도전·다음 스테이지 전환.
> 전투의 성과를 메타 프로그레션(로비)으로 넘기는 다리.

## 책임

- 왕관 조각 획득 (보스 처치당 1개) + 이번 판 누적 표시·획득 연출
- 게임오버(성 HP 0) / 게임클리어(최종 웨이브) 판정과 결과 패널
- 결과 화면 버튼 (이어하기/재도전 · 로비 복귀) → 씬 전환
- 진행도·자원 저장(`GameSave`)과 다음 스테이지 좌표 갱신

## 현재 상태

| ID | 기능 | 상태 |
|---|---|---|
| R1 | 보스 처치 → 왕관 조각 +1, 획득 연출 | ✅ |
| R2 | 이번 판 왕관 조각 누적(`crowns_this_run`) + 결과 패널 표시 | ✅ |
| R3 | 게임오버 패널 (영주 대사 + 재도전/복귀) | ✅ |
| R4 | 게임클리어 패널 (마무리 대사 + 다음/복귀) | ✅ |
| R5 | 클리어 시간 표시(`_format_time`) | ✅ |
| R6 | 페이드 전환 + 씬 이동 | ✅ |
| R7 | 진행도 저장 (다음 스테이지 좌표) | ✅ |

## 미해결 의제

- **만랩 8 해골 → 영혼 +50 변환** — 기획 §11 해골 정원: cap 8 도달 후 보스 처치는 해골 대신 영혼 보너스. 전투 종료 보상 분기에 반영됐는지 확인 필요.
- **3중 보상 동시 연출** — 보스 처치 = 영혼 폭탄 + 왕관 조각 + 해골 +1. 세 연출이 겹칠 때 가독성 폴리싱.
- **챕터별 보스 영구 처치 표시** — 진척감 강화 (Lobby/05_출정 미해결 의제와 공유).
- **부활(광고) 흐름** — 기획 §16 "게임오버 후 광고 1회 부활". 결과 패널에 미반영(수익화 Phase).
