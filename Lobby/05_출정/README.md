# 05. 출정 (Sortie)

> 로비 → 전투(Game.tscn) 진입 지점. 챕터-스테이지 선택과 씬 전환.

## 책임

- 출정 버튼 (현재 챕터-스테이지 표기)
- 출정 시 자원·진척 저장
- 페이드 아웃 + 씬 전환

## 현재 상태

| ID | 기능 | 상태 |
|---|---|---|
| E1 | 출정 버튼 — `출정  (챕터-스테이지)` 표기 | ✅ |
| E2 | 페이드 + Game.tscn 전환 | ✅ |

## 코드 위치

- `scripts/Lobby.gd`
  - `start_btn` — `$UI/StartBtn`
  - `_update_start_btn()` — 라벨 갱신
  - `_on_start_pressed()` — `start_chapter`/`start_stage` 저장 후 씬 전환
- `scripts/GameSave.gd` — `current_chapter`, `current_stage`, `start_chapter`, `start_stage`

## 미해결 의제

- **스테이지 선택 UI** — 현재 *현재 위치만* 진입 가능. 클리어한 스테이지 재도전·챕터 점프 등 자유도 없음.
- **출정 전 의식/축복 선택** — D3로 *전투 내 의식 상점*으로 이동. 로비 출정 단계엔 영향 없음 (D2 a 폐기 산물).
- **출정 전 상태 요약** — 현재 적용된 시설 효과·교리 등 *프리뷰*. 폴리싱 항목.
- **챕터별 보스 영구 처치 표시** — 진척감 강화.

## 관련 결정

- [D3](../핵심재미_검토.md) — 의식이 출정 전이 아닌 *전투 내*로 이동. 출정 흐름엔 결정 액션 없음.
