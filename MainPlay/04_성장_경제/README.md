# 04. 성장 / 경제 (Growth & Economy)

> 한 판 안에서 점점 강해지는 "선택 → 누적 → 강화" 사이클의 핵심.
> 세 축: **영혼**(전투 화폐) · **카드**(웨이브 클리어 빌드 강화) · **영혼 상점**(상점 웨이브 결제).

## 책임

- 영혼 자원: 적 처치 시 획득, 특수기·상점에 소모, 런 종료 시 소멸
- 카드: 웨이브 클리어 후 3장 중 1장 선택 → 영구(런 한정) 빌드 강화. 희귀 등급 롤.
- 영혼 상점: 상점 웨이브에서 영혼으로 1개 구매 (전투·카드 보상 없음)
- 시설 보너스 적용 (로비 시설 → 전투 시작 시 영혼·공격·HP 등 반영)

**채택 근거**: 자폭 2종(메아리=수동/제물=능동, MD8·MD9 평행)은 결은 다르나 MVP 단계 인지 혼란 위험 → 직관적인 수동(메아리) 먼저, 능동(제물)은 MD9 희생 수치가 굳은 뒤 추가. 2종으로도 물량 올인 / 자폭 두 갈래 확보.

## 상점 재설계 (영혼 상점, 2026-06-19)

> 읽기 쉬운 정본 슬레이트 = [기획문서.md §10](../../기획문서.md). 아래는 결정 로그(근거).

**진단** — RD(운영자 리디자인)로 영주 아바타 제거 후, 옛 상점 5종 중 2종이 죽거나 거짓 라벨:
- `range_up`(저주 확장 +50) = **완전 무효**: `Player.basic_range`는 시각 원만 갱신, 자동공격이 Phase A2 가드(`Player.gd:156 if true: return`)로 차단돼 게임플레이 영향 0.
- `atk_boost`(공격 강화 +15%) = **반쯤 죽음/거짓**: `attack_bonus`가 영주 자동공격(차단)엔 무의미. 살아있는 건 **낙뢰(마법) 데미지**(`AbilitySystem.gd:_fire_lightning` 463~473에 곱)뿐. 라벨 "공격력"은 영주 직접 공격을 연상 → 거짓.
- `minion_atk`(하인 공격 +10%)·`atk_boost` 같은 **양적 +%는 강화팝업 소관**(`KS10`). 상점이 같은 공간을 중복으로 팖.

**경제 구조** — 골드 소비처 4갈래 중 **마법**(골드 비용 0·쿨다운만, `AbilitySystem.gd:13`)과 **성**(약한 `repair`뿐)은 상시 골드 소비처가 **없음**.

| 코드 | 결정 | 근거 |
|---|---|---|
| `SH1` | **상점 정체성 = "연속 루프가 못 파는 것 = 성(방어) + 마법" 전담** (2026-06-19) | 군대(하인)는 고용·강화팝업이 상시 책임 → 상점이 또 팔면 중복(`KS10` 위반). 마법·성은 상시 골드 소비처가 없어 상점이 그 빈자리를 메우면 4갈래가 안 겹치고 각자 선명. 기각: 양적 +% 잡화점 유지(중복·죽은 항목 존속). |
| `SH2` | **5슬롯 재구성 = 성 2 + 마법 3** (2026-06-19, 수치 가제) | 성벽 증축(최대HP +120, `repair` 격상) / 긴급 수복(성+하인 완전회복, `heal_minion` 흡수=상황형 패닉, +%아님→`KS10` 합법) / 낙뢰 증폭(낙뢰 +20%, `atk_boost` 정직 리네임) / 마법 가속(쿨 −15%, `range_up` 교체) / 마법 확산(반경 +25%, `minion_atk` 교체). `range_up`·`minion_atk` 폐기. |
| `SH3` | **위력은 낙뢰(처치)에만 유효** (2026-06-19) | 나팔은 순수 통제(`TRUMPET_DAMAGE 1.0`≈0). `attack_bonus`는 낙뢰 데미지에만 의미 → 라벨을 "낙뢰 피해"로 좁혀 정직. |
| `SH4` | **가격 굵게 + 종류당 1회 구매** (2026-06-19) | 옛 가격(18~40)이 진입 보유 골드(~400~480)보다 너무 싸 전부 구매 가능=결정 긴장 0. 합산(~520)>보유로 올려 **2~3개만** 선택하게. 옛 "1회 1개(전체)" 룰은 런당 1회뿐인 상점엔 과도 → **종류당 1회**(구매 시 비활성)로 대체. 비활성 상태가 구매 피드백 연출 훅도 됨. |
| `SH5` | **신규 코드 노브 2종** (2026-06-19, 구현 예정) | 쿨다운·반경은 `const`라 곱할 변수 없음 → `game.ability_cooldown_mult`(`AbilitySystem` fire 때 `ability["cooldown"]`에 곱) + 마법 반경 mult(`LIGHTNING_IMPACT_RADIUS`/`TRUMPET_PULSE_RADIUS`에 곱) 신설. 위력은 `attack_bonus` 재활용이라 신규 코드 없음. |

## 미해결 의제
- **영혼 소비처 4번째 = 하인 희생 (2026-05-30 신설, →[03 MD6](../03_하인_소환/))** — 희생은 직접 영혼을 쓰진 않지만 슬롯을 비워 *재소환*으로 영혼 소비를 유도. 소환 슬롯 고정 시 생기는 영혼 잉여의 배출 경로. 밸런스 시 소환·특수기·상점과 함께 4갈래로 튜닝.
