# F. 월드 피드백 (휘발성)

> 레이어 **L4 (휘발 피드백)**. 이벤트 발생 시 떴다 사라지는 일시적 UI.
> 고정 HUD와 달리 "어디서 무슨 일이 일어났는지" 월드 맥락에 붙거나 화면을 잠깐 덮음.
> ※ 결과 화면의 컬러 오버레이는 [E_결과시퀀스](../E_결과시퀀스/)로 이동(한 연출이라).

## 구성 요소

| ID | 이름 | 생성 방식 | 역할 |
|---|---|---|---|
| F1 | 캐릭터 대사 | `show_dialogue()` 코드 생성 Label | 플레이어/보스 대사 버블 |
| F2 | 자원 획득 텍스트 | 코드 생성 Label (2종) | "영혼 +50", "해골 +1" 등 킬 피드백 |
| F3 | 씬 전환 페이드 | `$UI/FadeRect` (ColorRect) | 전투 진입/퇴장 페이드 |

## F1 캐릭터 대사

- **발생**: 게임 시작(30%), 웨이브 클리어(30%), 게임오버/클리어 시
- **위치**: `player.global_position + Vector2(0, -60)` (플레이어 위)
- **레이아웃**: 너비 440, height 60, 중앙 정렬, 폰트 20
- **연출**: 즉시 표시 → 2초 유지 → 1초 페이드아웃 → 삭제
- **색상**: 일반 `Color(0.75,0.85,1.0)` 하늘 / 게임오버 `Color(0.9,0.55,0.55)` 빨강 / 클리어 `Color(0.85,0.95,0.75)` 초록

## F2 자원 획득 텍스트

| 종류 | 텍스트(가제) | 색상 |
|---|---|---|
| 하인 소환 | "해골 +1" | `Color(0.7,0.85,1.0)` 하늘 |
| 영혼 과잉 드롭 | "영혼 +50 (해골 만랩)" | `Color(0.85,0.65,1.0)` 보라 |

- **위치**: 이벤트 발생 위치 (`pos + Vector2(-100,-140)`)
- **연출**: 위로 60px 이동 + 1.2초 페이드아웃
- **폰트**: 26 / 22

## F3 씬 전환 페이드

- `$UI/FadeRect` (ColorRect 480×960 검정)
- 진입: 검정→투명 (`_fade_in()`), 퇴장: 투명→검정 후 씬 전환

## 디자인 의제

- **F1 말풍선** — 현재 plain 텍스트. 말풍선 UI(배경 박스·꼬리) 검토. 블랙코미디 톤 [[블랙코미디 톤]].
- **F1 보스 대사 경로 통합** — 보스 발화(`_start_rage_charge()`)는 보스 위치, `show_dialogue()`와 다른 경로 — 통합 여부 검토.
- **F2 종류 확장** — 현재 2종. 특수기·희생 성공 등 피드백 추가 여부.
- **F2 겹침 처리** — 빠른 전투 중 텍스트 겹칠 수 있음. 동시 등장 시 위치 분산.
