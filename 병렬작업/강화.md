# 강화 작업 영역

> 마물 강화 버튼 + 팝업 + 강화 적용.

## 담당 파일
- `scripts/UpgradeSystem.gd` — 강화 버튼·팝업·구매·살아있는 유닛 갱신
- 강화 밸런스 데이터는 `scripts/data/MinionData.gd`의 `HIRE_UPGRADE_*` (마물 영역과 공유 — 수치만 손댈 땐 협의)

## 책임 (이 안에서 자유)
- 강화 버튼·팝업 빌드(`_build_upgrade_ui`)·열기/닫기(`_toggle/_open/_close/_refresh_upgrade_popup`)
- 강화 구매(`_on_upgrade_pressed`)·살아있는 유닛 즉시 스탯 갱신(`_apply_upgrade_to_alive_minions`)
- 팝업 마왕 장식·트랜지션·골드 표시

## 경계 — 건드리지 말 것
- 공유 상태: `game.souls`·`game.hire_levels`·`game.minions_node`·`game.minion_*_bonus` → game. 경유.
- 강화 UI 노드(`game._upgrade_btn`·`game._upgrade_popup` 등)는 Game 소유(레이아웃·튜토리얼이 참조) → game.
- **`_close_upgrade_popup`·`_set_upgrade_btn_visible`는 Game facade로 ShopController가 호출** → 시그니처 유지.

## 강화 밸런스
- 레벨당 스탯%: `MinionData.HIRE_UPGRADE_STAT_MULT`
- 비용 공식: `MinionData.HIRE_UPGRADE_COST_BASE × 현재레벨`

## 안전 편집
- ⚠️ UpgradeSystem은 `extends Node` → `get_viewport_rect()` 같은 CanvasItem 메서드는 `game.get_viewport_rect()`로.
- ⚠️ UI const(`UI_BTN_GOLD`·`UI_POPUP_CORNER`·`UI_COST_SHORT` 등)는 Game 소유 → `game.UI_*`.
- 외부 호출 함수 추가 시 Game facade 1줄.
- 검증: `godot --headless --quit-after 5 scenes/Game.tscn 2>&1 | grep -iE "error|not found"`
