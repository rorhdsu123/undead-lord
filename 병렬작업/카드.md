# 카드 / 키스톤 작업 영역

> 카드 뽑기·키스톤·효과 적용·카드 뷰. 콘텐츠 추가 빈도 1순위.

## 담당 파일
- `scripts/CardSystem.gd` — 로직·뷰 (뽑기/픽/효과/카드 빌더)
- `scripts/data/CardData.gd` — 카드 풀·등급·축·카테고리·키스톤 튜닝
- `scripts/Loc.gd` — `card_<id>` 문구 (이름\n설명)

## 책임 (이 안에서 자유)
- 카드 추가/삭제·풀 구성·등급(`RARE_CHANCE`/`ALWAYS_RARE`/`NEVER_RARE`)
- 카드 효과(`_apply_card` match)·키스톤(`_apply_keystone`/`_recompute_keystones`)
- 카드/키스톤 화면 UI(`_build_card_row`·`_build_keystone_card`·`_card_value_preview`·`_format_axis_tags`)
- 동적 수치 표시·축 색·빨강 강조

## 경계 — 건드리지 말 것
- 키스톤 **효과 결과 변수**(`vulnerability_amount`·`execution_threshold`·`keystone_echo_dmg`·`ability_*_card_mult` 등)는 Game 소유 → `game.X =` 로 **쓰기만**. 선언은 Game.gd. (이걸 Enemy/Boss/AbilitySystem이 읽음)
- 카드 픽이 건드리는 공유 상태(`game.souls`·`game.max_minions`·`game.castle_max_hp`·`game.current_wave`)는 game. 경유.
- 다른 도메인 파일·Game.gd 본체.

## 카드 추가 방법 (3곳)
1. `CardData.STAT_CARDS`에 `{"id": "newcard"}` (+ `"magic": true`/`"alignment": "통제"` 필요 시)
2. `CardData.CARD_CATEGORY_MAP` + `CARD_AXIS`에 `"newcard"` 분류
3. `Loc.gd`에 `"card_newcard": "이름\n[축] 설명"`
4. `CardSystem._apply_card` match에 `"newcard":` 효과 (공유 상태는 `game.X`)
5. 동적 수치면 `_card_value_preview`에 case 추가

## 안전 편집
- 효과 적용은 `game.` 역참조. 새 키스톤 효과 변수가 필요하면 Game.gd에 `var`로 추가 + 여기선 `game.` 사용(읽는 쪽과 합의).
- 외부에서 부를 함수 추가 시 Game.gd facade 1줄.
- 검증: `godot --headless --quit-after 5 scenes/Game.tscn 2>&1 | grep -iE "error|not found"`
