# B. 하단 컨트롤 클러스터

> 레이어 **L1 (상시 HUD)**. 화면 최하단에 고정된, 플레이어가 직접 조작하는 영역 전체.
> **자원 표시 + 그 자원을 쓰는 액션 버튼**을 한 클러스터로 묶음 — 영혼 수치(B1)는 소환·특수기 비용(B3·B4)이 존재하는 이유라 떼어 보면 안 됨.
> 3개 행 구조: (행0) 자원 라벨, (행1) 소환 버튼 4종, (행2) 특수기 + 희생.

## 현행 — 운영자 리디자인 반영 (2026-06-14, RD15~RD19 + MD12)

> ⚠️ 아래 `구성 요소`·`레이아웃`·`B1~B5`·`디자인 의제`는 **운영자 리디자인 이전(영혼 소모품 + 특수기/희생 모델)** 기록 — *역사*로 보존. 현재 전투 하단은 [02 RD13~](../../02_영주_전투/) · [03 MD12](../../03_하인_소환/) 로 전환됨. 코드 정본 = `Game.gd` 하단 함수군.

현재 하단 클러스터 구성(아래→위, `_layout_bottom_ui_phase_c()`):

- **접지 트레이** (`_bottom_tray`): 다크보라 반투명 패널을 하단 밴드(y795~960)에 최하단 z로 깔아 컨트롤 접지. RD19에서 **알파 0.55로 흐리게** → 위 버튼(α0.96)이 또렷이 강조됨. 근거: 트레이·버튼 명도차가 작아 버튼이 묻혔음.
- **자원 캡슐** (`_resource_capsule`, RD19): 골드+하인을 **알약 영역 하나로 묶음**(소환 버튼 폭 `SUM_W`에 맞춤, 내부 중앙정렬). `_make_capsule_stylebox()` 공용 스타일. 내용 = `🪙(노란 ●) 골드숫자` + `👤(NotoEmoji) N/M`(N=`active_minions`, M=`max_minions`). 골드/하인 숫자 **동일 16px 흰색**, 아이콘만 색. 캡 도달 시 캡슐 우상단에 **빨간 `MAX` 배지**(`_max_badge`). 골드 아이콘은 폰트 글리프 ● 금색(`1.0,0.85,0.40`)로 통일(코인 이모지 시도→가독성 위해 폐기).
- **소환 버튼 3종** (전사/궁수/탱크): 콘텐츠 = **풀렉트 VBox 중앙정렬**(`[이름]`/`[● 비용]`, 겹침 방지). 비용은 `[노란 ● 아이콘][숫자]` 분리 — ●은 항상 금색, 숫자만 부족 시 빨강(`UI_COST_SHORT`). **상시 활성**, 튜토리얼 잠금만 `disabled`(🔒).
- **강화 버튼**: `▲(초록) 강화`(버튼 내부 HBox 중앙정렬, `_upg_icon`) → 탭 시 **강화 팝업**(아래 항목).
- **강화 팝업** (RD19 풀도크 리디자인): **불투명 풀폭** 패널이 하단 조작 도크를 덮음(마법 버튼까지 가림). 바닥은 **소환 컨테이너 하단에 딱 맞춰**(소환행 가림), 강화 버튼은 팝업 아래 노출. 높이는 콘텐츠 기준 위로 자람(top 상한 700, 성 보호). 상단 중앙 **골드 캡슐**(`● 골드`, `PopupGoldLabel`) + 우측 **✕**(제목 텍스트 폐기). 카드 3장(전사/궁수/탱크) = 종류명/아이콘슬롯56/Lv/**비용 알약**. 알약 = **다크 보라(`0.24,0.20,0.34`) + 골드 테두리 + `[노란 ●][숫자]`**(min 높이 30). 상시 활성, 부족 시 숫자 빨강.
- **마법 버튼** (우하단): `AbilitySystem` 원형 글로우 2슬롯이 **특수기/희생 버튼(B4·B5)을 대체**. 강화 팝업 열림 중엔 팝업이 위에서 덮음.
- **버튼 피드백** (RD19): hover/pressed **색 변화 제거**(`_apply_button_styleboxes` normal 재사용) → 대신 탭 시 **스케일 바운스**(`_add_button_press_bounce`, 0.90 축소→1.0 복귀 BACK이즈). 소환·강화 토글·알약에 적용.
- **골드 획득 플로터**: 획득 시 `souls_icon` 위로 `● +N` 팝→상승+페이드(~0.55s), 버스트 자동 스택(소프트캡 8). `add_souls()` 단일 퍼널. **강화 팝업 열림 중 생략**. (캡슐 reparent로 `souls_icon`이 HBox 자식 → 플로터는 `$UI` CanvasLayer에 `global_position` 기준 부착)

성 위치: RD19에서 **`Castle` (240,700)→(240,620)** — 강화 팝업이 성 바로 아래에서 시작해 성/전투를 안 가림(적 타겟·하인 소환은 `$Castle` 동적 참조라 안전).

캡 룰: 종류별 캡 폐지 → **전역 총량 캡 기본 6**([03 MD12](../../03_하인_소환/README.md)). 다양성은 강제 대신 **적 로스터 분화**([01 BD1](../../01_전장_흐름/README.md))로 유도.

## 자원 표시 상태

### B1 영혼 수치
- 평상시 "◆ N" (아이콘 ◆ + 숫자), 색상 기본. affordability(쓸 수 있는지)는 **버튼 점등**이 담당 → 카운터 자체엔 색 변화 없음(중복 방지).
- **아이콘(2026-06-10)**: 한글 단어 "영혼:"을 떼고 임시 심볼 ◆(금색 `Color(1.0,0.82,0.35)`)로 교체. 코드 생성 Label(`souls_icon`), **아트 입고 시 노드만 교체**. 글리프는 폰트 100% 포함 보장 문자(◆)로 선택(두부 방지).
- **살아있는 카운터(2026-06-10 구현)**: 값 변화 시 ①**롤업** 옛값→새값 0.25s 이징(QUAD out), ②**범프 펀치** 1.15× 튕김(0.07s out+0.10s in, pivot=좌측-수직중앙). 모든 영혼 변화가 `_update_souls_ui()` 한 곳으로 모여 처치 획득·소환/특수기 소비 양쪽에 동일 적용. 방향 틴트(획득 녹색/소비 적색)는 **범위 제외**(미채택).

## 디자인 의제

> 방향(2026-06-09 확정): **미니멀하게 두되, 가치 높은 어포던스만 더한다.** 클러스터는 투명, 게이팅 가시화는 자원 점등·쿨게이지로 한정.

- ✅ **클러스터 통합 레이아웃** — *결정*: **투명/미니멀**. 패널 배경으로 묶지 않음 — 전장 가시영역(하단 ~165px가 이미 차지) 보존 우선. "조작 영역" 구획은 위치만으로.
- ✅ **자원↔버튼 연동 피드백** — *해소*: 영혼이 비용 도달 시 버튼이 disabled→active로 **점등**(글로우/펄스 1회). "이제 쓸 수 있다"를 능동 통지. (기존 조용한 토글 대체)
- ✅ **B5 쿨다운 시각화** — *해소*: 버튼 위 **파이/바 쿨게이지**. 텍스트 초카운트 대체.
- **슬롯 포화 ↔ 소환 비활성 시각 연결** — *보류(후순위)*: 미니멀 유지 위해 B2 빨간 라벨 텍스트로 충분 판단. 플테에서 "왜 소환이 동시에 꺼졌나" 혼동 시 재검토.
- **B3 소환 버튼 아트** — *보류*: 하인 아트 교체(귀여운 마물, MD11) 입고 후 버튼 아이콘 반영. 현재 텍스트만.
- **상점 진입 시 전환** — 상점(D) 열리면 B3·B2 숨김. 클러스터 일부만 사라지는 전환이 자연스러운지 확인.
- ✅ **자원 아이콘화(2026-06-10)** — *적용*: B1·B2 한글 단어를 임시 심볼(◆/●)로 교체, 미니멀 유지(패널 배경 없음). 표기 방식·색·롤업·범프 전부 보존. 세계관/아트 확정 후 노드 텍스처 교체.
- **명명** — "영혼" 가제. 현재 아이콘은 폰트 글리프 임시 심볼(중립).

## 버튼 동작 규칙 (2026-06-19 확정)

전 화면 버튼의 입력 피드백을 **두 규칙**으로 통일. 신규 버튼은 반드시 따른다.

1. **hover 색 변화 없음** — hover/pressed에서 색이 바뀌지 않는다. 배경뿐 아니라 **글자색**도 상태별로 고정해야 한다(Godot 기본 테마의 `font_hover_color`/`font_pressed_color`/`font_focus_color`가 hover 시 글자를 밝게 바꾸므로, 텍스트 버튼은 이 셋도 `font_color`와 동일하게 override). 스타일박스는 `normal`을 hover/pressed/focus에 재사용.
2. **눌림은 "성공했을 때만"** — 탭 시 스케일 바운스(0.90→1.0 BACK)로 "눌림"을 표현하되, **동작이 실제 성립할 때만** 재생한다. 불가 상태(골드 부족·슬롯 포화·쿨다운·웨이브 비활성 등)에서는 눌림 표시도 없다.
   - 구현: 바운스를 `pressed`에 무조건 붙이지 말고, 핸들러의 차단 가드(early-return) **뒤 성공 경로**에서 `_play_button_bounce(btn)` 호출. 항상 성립하는 버튼(강화 팝업 토글 등)만 `_add_button_press_bounce`로 무조건 연결.
   - 닫기/전환 버튼(✕·상점 닫기): 즉시 닫히면 바운스가 같이 사라져 안 보이므로, **풀 바운스 후 close 콜백**. 결과창 버튼은 0.35s 페이드 동안 보이므로 단순 연결로 충분.
   - 마법 탭 버튼: 투명 오버레이라 탭 버튼이 아닌 **드로어(`AbilityButtonDrawer`)를 스케일 펀치**(`_punch_drawer`). 무장 성공·취소 시에만, 쿨다운 탭은 무반응.

> 적용 범위: 소환·강화(팝업)·상점 구매/닫기·결과창·마법. 레거시 특수기/희생 버튼은 Phase A 가드로 숨김·제외.
