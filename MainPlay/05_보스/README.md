# 05. 보스 (Boss)

> 스테이지의 절정 — 중간보스(W5)·최종보스(W10) 패턴 전투. 처치 시 왕관 조각·해골 보상([06](../06_결과_보상/)).
> 핵심 설계 의제 = **와인드업 ↔ 특수기 치명타** (타이밍 기반 약점 노출 윈도우). 기획 확정, 코드 미반영.

## 책임

- 보스 등장·입장 연출·대사, 보스별 스프라이트/스케일
- 패턴 실행: 인턴(랜덤 돌진) / 알바생(3페이즈 + rage charge + 잡몹 소환)
- 처치 시 보상 트리거 (왕관 조각·해골·영혼) → [06_결과_보상](../06_결과_보상/)
- **(기획)** 와인드업 중 특수기 적중 → 캔슬 + 스턴 1.5초 + ×2 피해 + 치명타 연출

## 현재 상태

| ID | 기능 | 상태 |
|---|---|---|
| BS1 | 보스 등장·입장 연출·페이즈 대사 | ✅ |
| BS2 | 인턴 패턴: 주기적 랜덤 돌진 + 경고 변색 | ✅ |
| BS3 | 알바생 3페이즈 (정의→야근→폭주, 속도·데미지·색 변화) | ✅ |
| BS4 | rage charge (와인드업 후 강타) + 잡몹 소환 | ✅ |
| BS5 | 보스 처치 → 보상 콜백(`on_boss_killed`) | ✅ |
| BS6 | **와인드업 중 특수기 → ×2 + 캔슬 + 스턴 1.5초** | ⏳ 기획 확정·**미구현** |
| BS7 | **치명타 3계층 데미지 시각 + 풀 연출 패키지** | ⏳ 기획 확정·**미구현** |

## 코드 위치

- `scripts/Boss.gd` — 보스 본체
  - 색상 상수 `COLOR_NORMAL/DASH/OVERTIME/PHASE3`(19–22), `RAGE_DIALOGUES`(24–)
  - 스탯 `hp/speed/damage`(35–43), `boss_type`(44, mid_boss/…)
  - 인턴 돌진 — `dash_*`(50–55), `DASH_SPEED 400`
  - 알바생 페이즈 — `overtime_triggered`/`phase3_triggered`(58–59)
  - rage — `rage_*`(61–66), `is_charging_rage`/`rage_charge_duration 1.5`
  - 잡몹 소환 — `summon_timer`(68)
  - `BOSS_SPRITE_MAP`/`BOSS_SCALE_MAP`(5–17)
- `scripts/Game.gd`
  - `_on_boss_entered()`(263), `on_boss_killed()`(281), `boss_summon()`(332)
  - `_show_boss_title()`(1020), `BOSS_INTRO_DIALOGUES`/입장·처치 대사(115–126)
  - 치명타 구현 시 진입점: `_on_attack_pressed()`(846, 보스 와인드업 체크) + `spawn_damage_number()`(1051, 3계층 분기)
