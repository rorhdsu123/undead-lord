# D. 상점 패널

> 레이어 **L2 (모달 인터럽트)**. 상점 웨이브에서 전투 전역을 덮고 나오는 구매 화면.
> 영혼을 소비해 즉각 효과를 사는 "전투 내 회복/강화 포인트".
> ⚠ 상호 배타: 카드(C)·결과(E)와 동시에 뜨지 않음.

## 구성 요소

| ID | 이름 | 노드 경로 | 역할 |
|---|---|---|---|
| D1 | 상점 패널 전체 | `$UI/ShopPanel` (Panel) | 전장 위 전체 오버레이 |
| D2 | 상점 제목 | `$UI/ShopPanel/ShopTitle` | "영혼 상점" (가제) |
| D3 | 상점 아이템 버튼 5종 | `$UI/ShopPanel/ShopItems` (VBoxContainer) | 아이템별 구매 버튼 |
| D4 | 닫기 버튼 | `$UI/ShopPanel/CloseBtn` | 닫고 다음 웨이브 진행 |

## 노출 조건

- 웨이브 타입 = `"shop"` 시 자동 등장 (`_show_shop()`)
- 닫기 → `_close_shop()` → `current_wave += 1` → 다음 웨이브
- 상점 동안: 하단 컨트롤(B)의 소환 컨테이너·슬롯 라벨 숨김

## 버튼 상태

| 상태 | 조건 | 시각 |
|---|---|---|
| 활성 | 영혼 ≥ 비용 | 테두리 또렷 + 밝은 배경(누를 수 있음 인지) |
| 비활성 | 영혼 < 비용 | 흐린 테두리/배경 + 텍스트 흐림 |

텍스트 포맷: `"{이름}  [영혼 N]\n{설명}"` (2줄, height=58)

## 비주얼 (2026-06-10 구현 — 카드 화면과 톤 통일)

- **전체화면 dim**: 상점은 공용 `ModalDim`(z9, 0.72)으로 화면 전체를 덮어 웨이브·하단 HUD를 가림(콘텐츠만 또렷). 카드/결과와 동일. **입력은 트리 순서로 판정**되므로 `HUD < ModalDim < 모달 < FadeRect` 순서를 `_ready`에서 재정렬(z_index만으론 클릭이 dim에 막힘).
- **골드 배너 타이틀** "영혼 상점"(카드 `TitleBanner` 리소스 재사용) + **부제** 1줄(`shop_subtitle`, Loc).
- **보유 영혼 표시**: 헤더에 `보유 영혼  ◆ N`(골드, `shop_souls`/Loc `shop_owned_souls`), `_refresh_shop_buttons`에서 갱신 → 구매 시 즉시 감소. (dim이 하단 영혼 카운터를 가려 안 보이던 문제 해소)
- **항목 테두리**: 각 버튼 StyleBoxFlat 4상태(normal/hover/pressed/disabled)로 선택 가능 어포던스 + 구매가능 게이팅 시각화.
- **다음 웨이브 버튼**: 골드 채움(SubResource `NextWaveBtn*`) 강조.

## 디자인 의제

- **레이아웃** — D3가 VBoxContainer 세로 5개. 그리드/카드형 등 대안 검토.
- **구매 완료 피드백** — 즉각 효과(HP·범위 변화 등) 시각 확인(플래시/사운드) 미설계.
- **닫기 어포던스** — 닫기=구매 종료. 즉시 닫기 vs 확인 팝업 (현재 즉시).
- ✅ **타이틀** — 골드 배너 + 부제로 구현(2026-06-10). 명칭 "영혼 상점"은 가제(세계관 피벗 대기).
