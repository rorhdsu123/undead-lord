# 이벤트 노드 — 카피바라고식 도전/통과

> **상태**: 기획 단계 / 코드 미반영
> **최신 합의 갱신**: 2026-05-28
> **진행 박제 (역사)**: `devlog/wip_이벤트노드.md`
> **블록 사유**: 메타 자원 풀어내기 결정 — 로비 경영 메타 수정 후 재논의

---

## 1. 한 줄 컨셉

웨이브 사이에 *이벤트 웨이브*가 등장 → **이진 선택** `⚔ 도전(자원 비용 → 보상)` vs `🚶 지나가기(안전, 변화 없음)`. 카피바라고식 — *이벤트가 그 자체로 웨이브 슬롯을 차지*, 별도 팝업 없음.

---

## 2. 합의 사항

### 2-1. 챕터 구조 (MVP)

5챕터 × 3스테이지 = 15스테이지. 추후 변동 가능성 있음.

### 2-2. 빈도 곡선 (스테이지별 차등)

```
1-1: 0개   (튜토리얼 — 카드·소환·특수기·와인드업 학습만으로 충분)
1-2: 1개   (후반 슬롯 W6/W7/W8 중 랜덤 1 — 새 시스템 등장 모먼트)
1-3 이후: 2개 고정 (전반 W1/W2/W4 중 1 + 후반 W6/W7/W8 중 1)
```

**근거:**
1. *결정 인플레이션 방지* — 매 웨이브 카드 선택 + 보스 와인드업 + 소환·특수기 결정이 이미 많음
2. *각 이벤트의 무게감 ↑* — 자주 안 나오니 한 번이 중요
3. *온보딩 부담 ↓* — 첫 챕터에서 점진 학습 (0 → 1 → 2)
4. *후기 깊이는 빈도가 아니라 풀의 질로 보강* — 메모리 §3 원칙 유지

### 2-3. 노출 방식 — 웨이브 슬롯 대체

이벤트 = 그 자체로 하나의 웨이브 슬롯을 차지. 진입 화면이 곧 결정 화면.

```
W1 (전투) → W2 (이벤트 슬롯) → W3 (상점) → W4 (전투) → ...
            ↓
            화면 진입 = [⚔ 도전 / 🚶 지나가기] 화면
            지나가기 → 바로 W3로 이동
            도전 → 자원 차감 + 보상 → W3로 이동
```

- 별도 팝업·트리거·타이밍 결정 불필요
- 1-3 이후 전투 횟수: 7회 (W1,2,4,6,7,8) → 5회 (이벤트 2개 빠짐)

### 2-4. 풀 등급 — 보상의 영속성으로 구분

| | **일반** | **희귀** |
|--|--|--|
| 보상 | *이번 런 내* (영혼, 카드, 하인 버프, 보스 약화) | *런 종료 후 잔류* (메타 자원 / 효과) |
| 비용 | 영혼 위주 | 자유 (영혼/성HP/신앙) |
| 망했을 때 | 소멸 — "이번 런 살리기" | 잔류 — "다음 런 강해지기" |

**근거 (사용자 통찰):** *"보스 클리어 못해도 매판 얻고 오는 것이 있어야"* — COL(컬트오브더램) 신도 선택처럼 *런 단위 보상이 곧 메타 영속*인 구조 차용.

## 3. 폐기된 대안

### 3-1. 분기 시스템 (트리/맵 선택)

원래 안: 스테이지 중간에 갈림길 → 카드 3장 중 1장 → 경로별 다른 웨이브.

**폐기 사유**: 모바일에서 *"내가 지금 어디 있고 어디로 갈지"* 인지 부담 / 트리·맵 UI 별도 / 분기·합류 로직 구현 비용 ↑.

### 3-2. 자동 팝업·한 박자·카드 화면 통합 (§6-2 후보 A/B/C)

폐기 사유: 카피바라고식 = *이벤트 자체가 웨이브 슬롯*이라 *노출 시점* 개념 자체가 불필요.

## 4. 미해결 결정

### 4-0. 핵심 블로커 — 메타 자원 풀어내기 ⚠

**상태: 로비 경영 메타 수정 후 재논의 (2026-05-28 사용자 결정)**

희귀 이벤트가 메타 자원(신앙·왕관 조각·해골)을 어떻게 풀어줄지가 *자원별 정통 루트 형태에 따라 다름*:

| 자원 | 정통 루트 형태 | 캡 | 풀어내기 후보 |
|--|--|--|--|
| 신앙 | idle 자동 (해골수 × 시간) | 3 | 방법 3 (흐름 가속) — 직접 지급은 idle 게이트·캡 흔듦 |
| 왕관 조각 | 횟수 (보스 처치 = +1) | 무한 | 방법 1 (가끔 +1 보너스) |
| 해골 | 횟수 (보스 처치 = +1마리) | 8 | 방법 1, 단 캡 8 도달 시 무의미 |

**풀어내기 방법 카드:**
- **방법 1. 소량 보조** — 정통 +N/회 vs 이벤트 +1/회 (보조 통로)
- **방법 2. 새 메타 자원** — *"잊혀진 기억"* 같은 이벤트 전용 자원 신설 (MVP 복잡도 ↑로 보류)
- **방법 3. 간접 영속** — 자원 직접 지급 X, *"다음 신앙 누적 +20% / 1시간"* 같은 *흐름 가속*

→ 로비 경영 메타 자체가 수정될 예정이므로, 그 결과에 따라 자원별 풀어내기 방식 최종 결정.

### 4-1. 후속 결정 (블로커 해소 후 진행)

순서:
1. **풀 크기** — 6종 (일반 4 + 희귀 2) / 8종 (5+3) / 10종 (6+4)
2. **등장률** — 고정 70/30 vs 챕터 변주 (예: 1챕 85/15 → 5챕 55/45)
3. **중복 방지** — 한 런 내 같은 이벤트 재등장 허용 여부, 희귀 1회 캡
4. **풀 안 구체 이벤트 6~10종 디자인** — *결의 결* 원칙 적용 (영혼=즉발, 성HP=변환, 신앙=메타)
5. **도전 실패(자원 부족) 처리** — A. 도전 버튼 회색 비활성 (단순, 추천) vs B. 결과 덜 좋음
6. **튜토리얼·온보딩** — 1-2 첫 만남 학습 방식 (FTUE 오버레이?), 자원 부족 시 도전 불가 학습
