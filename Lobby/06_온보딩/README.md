# 06. 온보딩

> 처음 진입한 사용자를 위한 *서사 도입*과 *시스템 학습*.

## 책임

- 인트로 4컷 슬라이드 (최초 1회)
- 첫 시설 가이드 (튜토리얼 완료 후 첫 방문 시 1회)
- 건너뛰기 옵션

## 현재 상태

| ID | 기능 | 상태 |
|---|---|---|
| F1 | 인트로 4컷 (페이드 인/아웃, 슬라이드 자동 진행) | ✅ |
| F2 | 첫 시설 가이드 (오버레이 + 확인 버튼) | ✅ |
| | 인트로 건너뛰기 버튼 | ✅ |

## 인트로 4컷 (현재 텍스트)

1. "왕관이 있었다. 빼앗겼다."
2. "그 후로 한 200년쯤.\n\n...아직도 죽지 못했다."
3. "매일 토벌대가 온다.\n오늘은 '수습 용사 인턴'이라고 한다."
4. "...일이나 시작하자."

## 코드 위치

- `scripts/Lobby.gd`
  - `INTRO_LINES` — 4컷 텍스트
  - `_show_intro()`, `_play_intro_slides()`, `_finish_intro()` — 인트로 흐름
  - `_show_first_facility_guide()` — 첫 시설 가이드
- `scripts/GameSave.gd` — `intro_seen`, `first_lobby_visit_done`, `tutorial_completed`

## 미해결 의제

- **교리 시스템 도입 시 가이드 추가** — 영주 레벨업 첫 발생 시 *교리 트리 설명* 1회 (D5 박제 후 필요)
- **요구 응답 첫 발생 시 가이드** — D2 c 도입 시 필요
- **인트로 텍스트 검수** — 톤이 거점/세계관과 일관성 있는가
- **건너뛰기 후 *다시 보기*** — 설정 메뉴에서 인트로 재생 — 무게 낮음
