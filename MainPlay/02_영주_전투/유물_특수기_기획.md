# 유물 특수기 — 전투 참여 재설계 기획서 (가제)

> 목적: 전투 중 플레이어의 **참여감**을 살리기 위해 영주 본체를 전장에서 들어내고, 플레이어를 **"단순한 탭 권능 두어 개를 쥔 지휘관"**(Kingdom Rush 모델)으로 재편한다. 라이브 컨트롤 = **유물 2 자유 슬롯**의 탭 권능(쿨다운 발동). 영혼은 전투 능동에서 빠져 **군대/경제 트랙**으로 재정의.
> 이 문서 = 읽기 쉬운 기획 정본. 결정 근거·기각 대안은 [README.md](./README.md) 결정 로그(`RD#`) 참조.
> 작성 2026-06-12 · **설계 단계(미구현)** — 현행 구현(아바타 기반 `A1~A7`)은 교체 전까지 유효. 이름·수치는 전부 가제.

## 1. 핵심 개념

1.1 **문제** — 고정-자동 모델의 수동성. 영주가 성 안에 고정된 채 자동 공격하고, 단조로운 전체화면 특수기 하나만 쓴다. 플레이어가 "전투에 참여하는 느낌"이 약하다. (이 리스크는 [README 2026-06-01]이 이미 예견 → 플레이테스트 판정 "여전히 수동")

1.2 **해결 방향** — 영주 아바타를 **전장에서 완전 제거**한다. 플레이어는 *전장에 선 전투원*이 아니라 **성을 지키는 의지(운영자)** 가 된다. 참여는 지리(위치)가 아니라 **능동 권능(특수기)** 에서 나온다.

1.3 **정체성 = 디펜스.** 이 게임은 디펜스다 — 한 판 안에서 점점 강해지며 성을 지킨다. 따라서 특수기는 *상시 휘두르는 무기*가 아니라 **방어선의 결정적 개입 수단**이다. "어디가 무너지는가"를 읽어 그곳에 권능을 꽂는 것이 곧 재미.

1.4 **로그라이트 빌드 축.** 현재 빌드 시스템(카드=패시브, 키스톤=곱연산)은 전부 자동·수동적이다. 유물은 **플레이어의 능동 표현을 빌드로 정하는** 빠져 있던 축을 채운다. **유물 2개를 자유 조합**하므로 그 조합 자체가 빌드 정체성이 된다(공격2=글래스캐논 / 통제2=요새 봉쇄 / 1+1=균형). 런마다 조합이 바뀌면 *능동 플레이 방식*이 바뀐다.

1.5 **두 트랙 분리(Kingdom Rush 모델).** *마왕의 손*(라이브 전술)과 *자동 군대*(경제)를 자원으로 분리한다 — 권능은 **쿨다운**(공짜), 군대는 **영혼**(처치로 획득→편성·업글). §5 참조.

## 3. 라이브 컨트롤 = 탭 권능 2개

3.0 **발동 UX = Kingdom Rush식 2버튼 + 3스텝 탭(`RD11`).** 좌하단에 **유물 슬롯 2개에 대응하는 권능 버튼 2개**(쿨 게이지 = 버튼 링). 발동 흐름:
1. **권능 버튼 탭** → 무장(해당 권능 선택).
2. (취소 시) **선택된 버튼의 X 탭** → 사용 취소. *취소는 버튼 X 단일 경로*(재탭·필드 밖 탭 등 다중 취소 미채택).
3. **원하는 위치 탭** → 그 지점에 발현.

- **조준 미리보기 없음(순수 탭-탭).** 무장 후 손가락 따라오는 풋프린트 레티클은 미채택 — 각 권능의 범위는 *학습*으로 익힌다(가볍고 모바일 손맛 우선). 단 사거리 제한이 있으므로(아래) 무장 시 **도달 경계선만 옅게** 표시(손가락 위치 무관 고정선, 위치별 미리보기 아님) → 헛탭 방지.
- 게이팅 = **쿨다운**, 비용 영혼 아님(`RD9`). 자유 슬롯 2개라 "버튼 없이 직접 탭"은 어느 유물인지 모호 → 2버튼 채택(`RD8`).

3.1 **발현 = "강림"(가제), "휘두름" 아님.** 시전자 몸도 투사체 출발점도 없다. 플레이어가 **조준한 지점에 권능이 직접 발현**한다(from-above). 예: 탭한 곳에 낙뢰가 떨어지고, 역병 지대가 피어나고, 충격파가 터진다.
- 기본 원점 = **표적 강림.** 일부 유물만 "성에서 발사"(from-castle, 예: 부채꼴 충격파)를 *개성*으로 섞는다.

3.2 **순간 깊이 = 조준 + 상황 반응형.**
- **조준** — 누를 때마다 *어디에* 꽂을지 결정.
- **상황 반응형** — 같은 버튼이 **전장 상태를 읽어** 효과가 달라진다(자동·암묵 방식). 적이 뭉치면 광역, 보스가 와인드업 중이면 끊기+치명타, 외곽 탱크엔 넉백. 플레이어는 *모드를 고르는 게 아니라*, 유리한 상황을 *만들고 읽어* 꽂는다.

3.3 **와인드업 치명타 = 전 유물 공통 규칙.** 현재 보스 와인드업 끊기+×2(`Player.gd:177~`)는 특정 특수기의 특수 동작이 아니라, **모든 유물 특수기가 와인드업 중 보스에 적중 시 발동**하는 공통 규칙으로 일반화한다.

3.4 **디펜스 개입의 형태(예).**
- 무너지는 레인 → 넉백으로 시간 벌기
- 뚫린 틈 → 지대로 봉쇄
- 성에 닿기 직전 누수 적 → 강림으로 쳐내기(클러치)
- 보스 와인드업 → 끊기+치명타

## 4. 유물 시스템 (가제)

4.1 **2 자유 슬롯.** 런당 **유물 2개**를 장착. **슬롯 역할 고정 없음** — 어떤 유물이든 아무 슬롯에 자유 장착(`RD3`). 게이팅 = **유물별 쿨다운**(영혼 비용 폐기, `RD9`). 밸런스 레버 = **쿨 길이**(무거운 강림=긴 쿨, 잦은 통제=짧은 쿨) + **사거리**(긴 reach=전 화면 저격 / 짧은 reach=성 근처 last-line, `RD11`). 내 2개 조합이 곧 *내 전술 리듬* — reach 안배(긴+짧은)도 빌드 고민.

4.2 **처치/통제는 *유물 속성*, 슬롯 속성 아님(`RD6`).** 유물마다 디펜스를 *푸는 방식*이 다르다 — **통제형**(넉백·둔화·봉쇄로 *시간을 버는* 방어) ↔ **처치형**(우선 위협을 *지워서* 라인을 구함). 손맛 축(단일/지대/광역, 쿨 길이, 리듬)으로도 차별화.

| 유물(가제) | 성향 | 손맛 | 발현 |
|---|---|---|---|
| 낙뢰의 홀 | 처치 | 조준 단일·고화력·긴 쿨 | 표적 강림 |
| 운석 낙하 | 처치 | 조준 광역·강력·긴 쿨 | 표적 강림 |
| 진흙 늪 | 통제 | 조준 지대·둔화·중간 쿨 | 표적 강림 |
| 가시덤불 | 통제 | 조준 장벽·차단·중간 쿨 | 표적 강림 |
| 망령의 나팔 | 통제 | 광역·넉백·짧은 쿨 | 표적 강림 |
| 성벽의 포효 | 통제 | 부채꼴 충격파 | 성에서 발사 |

*(예시 — 실제 풀 규모·쿨·수치는 남은 작업. 처치/통제 어느 쪽이든 두 슬롯에 자유 조합)*

4.3 **획득·교체 구조(CotL 차용).**
- **장착** = 로비에서(수집·메타 성장). 유물 수집이 로비 메타 목표가 된다(2층 구조의 메타 강화층과 정합).
- **중간 교체·강화** = 새 시스템을 만들지 않고 **기존 노드에 매핑** — 웨이브 사이 카드 선택, 영혼 상점.
- **카드/키스톤** = 장착 유물을 *증폭*(역할 분리: 유물=능동 동작, 카드=패시브 증폭).

4.4 **검증 빌드 — 재미 검증용 2종 확정(`RD12`, 2026-06-12).** 풀 전체를 만들기 전에 *이 능동 루프가 재밌나/수동성 벗었나*를 가장 빨리 증명할 **최대 대비 쌍**(1처치 + 1통제)만 먼저 확정. 구현은 후순위(설계만). 같은 성향 2개로는 2슬롯 정체성의 심장(`RD6` 성향 대비)을 못 건드리므로 의도적으로 대비 쌍 선정.

| 검증 유물 | 성향 | 형태 | 쿨 | 사거리 | 핵심 동작 | 상황 반응형 |
|---|---|---|---|---|---|---|
| **낙뢰의 홀** | 처치 | 점(**작은 임팩트 반경**) | 긴 쿨 | 전 화면 저격 | 착탄점 단일 고화력. 순수 1체 아닌 작은 반경(빗맞음 허무 방지 = 정밀+약간의 관용) | 보스 와인드업 중 적중 → **끊기 + ×2 치명타**(처치형 풀 적용) |
| **망령의 나팔** | 통제 | 원(광역 펄스) | 짧은 쿨 | 넉넉 | 착탄점 중심 펄스 → **일괄 위쪽(스폰 방향) 넉백**(`A안`). 피해 ≈ 0(순수 통제 — 처치로 번지면 성향 대비 흐려짐). VFX = *상방 스윕 돌풍/음파*(대칭 링 아님 — 방사형 오인 방지) | **질량 기반 넉백 차등**(hp_mult, 기존 코드) + 와인드업 끊기(피해 미미해 치명타 의미 적으나 끊기는 유효) |

- **넉백 방향 = 일괄 위쪽 확정(`A안`).** 방사형(`B안`, 중심서 바깥)은 중심보다 아래 적을 *성 쪽으로* 밀어 역효과 → 기각. 탭=폭발원점 방사(`C안`, 조준 퍼즐)는 표현력 매력적이나 *검증 신호를 흐림*(조준 깊이는 낙뢰가 이미 검증) → 검증 후 확장으로 보류.
- **상황 반응형 = 검증용 최소.** 새 매트릭스(뭉침→광역 등) 미작성. *이미 확정된* 공통 와인드업 치명타/끊기 + 기존 질량 넉백 **2개로만** 한정 → 조준·템포로 핵심 재미를 깨끗이 검증. 본격 §7.3은 검증 통과 후.

## 5. 페이싱

- **템포는 위협 에스컬레이션이 정한다.** 초반 웨이브=한산(가끔 개입), 후반=조밀(쉴 새 없이 triage). 에스컬레이션 자체가 한 판의 곡선.
- **"쿨 도는 사이"는 공백이 아니다** — 쿨다운이 도는 동안 *전장을 읽으며 다음 개입을 노리는* 시간 = 디펜스의 긴장.
- 따라서 "N초마다 강제로 눌러 채운다"는 액션 게임식 페이싱은 **기각.** 손이 멈춰도 머리가 움직이게 한다.

## 6. 두 트랙(손·군대) · 인프라

Kingdom Rush의 *권능(쿨다운)* ↔ *골드(타워)* 분리를 차용(`RD10`). 영혼은 전투 능동에서 빠져 **군대/경제 트랙**으로 재정의된다.

| 트랙 | 자원 | 무엇 |
|---|---|---|
| 마왕의 손 (라이브 전술) | **쿨다운** | 유물 권능 2개 — 처치·통제 개입 |
| 자동 군대 (경제) | **영혼** | 하인 편성·업글·영혼 상점 (자동 방어선 구축) |

- **하인 = 자동 지원군.** 외곽 전선을 자동으로 지킨다. 라이브 지휘(집결·즉석배치) 시스템은 **추가하지 않는다**(`RD7`, 복잡도 최소). 딜·라인 유지는 하인·자동에 분담, 플레이어 손은 두 권능에 집중.
- **영혼 = 군대 경제.** 처치로 영혼을 벌어 **웨이브 사이 편성·하인 업글·영혼 상점**에 쓴다(KR 골드 모델). 기존 영혼 상점·시설 보너스가 이 트랙에 흡수. 트레이드오프: "영혼 아껴 큰 거 한 방"식 *권능 절약-소비* 긴장은 사라지고, 그 긴장은 *경제 트랙*으로 이동 / 권능 쪽은 *쿨다운 타이밍* 긴장으로 대체.
- **위협 텔레그래프(④) 승격.** 디펜스적 읽기가 성립하려면 "여기 위험하다"가 화면에 보여야 한다. ④ 위협 텔레그래프는 *사치 폴리싱*이 아니라 **이 설계의 필수 인프라**다. → [01_전장_흐름](../01_전장_흐름/) · [07_연출_튜토리얼](../07_연출_튜토리얼/)

2. **유물 시스템 상세** (진행) — [x] 손맛 축 4좌표계(성향/형태/무게/사거리)·[x] **검증 빌드 2종 확정**(§4.4, `RD12` — 낙뢰의 홀+망령의 나팔). 남음: 전체 풀 규모(검증 후 ≈6~8 확장), 획득·장착 경로(로비 메타 확정 후), 중간 교체(=카드/키스톤 증폭, 스왑 노드 미신설).
3. **상황 반응형 규칙** (검증 후) — 전장 상태→효과 매핑 규칙화/자동화. 검증 빌드는 공통 와인드업 치명타/끊기 + 질량 넉백 2개로 최소화(§4.4).
- [x] **기존 전투 시스템 재매핑** (2026-06-12 설계 완료, `RD14`) — **2단계 전략**: 1단계=검증 빌드 최소 절단(삭제 아닌 끄기/숨기기), 2단계=검증 후 본격. 1단계 범위·재매핑 표 = **§8**. 자동공격(`A1`) 정지·기존 특수기(`A2`)→낙뢰 이식·소환 4버튼→영혼 고용 루프·희생/패시브/키스톤/`basic_range` 끄기·곱엔진 1.0 고정. 2단계 잔여(패시브 거취·키스톤 권능 재설계·range 카드 reach 재배치·유물화·로스터 확장) = 검증 후.
5. **UI·아트·연출** — 하단 컨트롤 개편(공격/소환/희생 버튼 → 권능 버튼 2개), **아트 의뢰 재스코핑**(영주 *전투 모션* 의뢰가 무의미 — 단 로비 존재·유물 컨셉은 유효하므로 *재조정*이지 폐기 아님), "화면 활기" 공백 대응, ④ 위협 텔레그래프 구현.

## 8. 검증 빌드 — 1단계 구현 범위 (`RD14`, 2026-06-12)

> 풀 시스템 전에 **핵심 가설**을 가장 빨리 증명할 최소 빌드. *손=쿨다운 / 군대=영혼 두 트랙이 같이 도는 게 재밌나 · 수동성 벗었나 · 처치↔통제 성향 대비 느껴지나.* 구현 합의 완료 → 코드 진입 가능.

### 8.1 전략 — 2단계 재매핑
전투 데미지 파이프라인이 **영주 중심 곱엔진**(`keystone_*_mult`·`attack_bonus`가 자동공격·특수기·소환·희생·패시브에 전부 침투)이라 부분 패치가 안 됨 → "권능 중심"으로 갈아끼우는 작업. RD12 정신(검증 먼저)대로 **둘로 분리**:
- **1단계(이 절)** = 검증 가설 증명에 필요한 최소만. 나머지는 *삭제가 아니라 비활성/숨김*(검증 결과로 살릴지 갈리므로 지금 지우면 낭비).
- **2단계(검증 후)** = 패시브 거취·영혼 경제 풀 구현·키스톤 권능 재설계·카드/reach 재배치·유물화·로스터 확장.

### 8.2 1단계 재매핑 표
| 시스템 | 현 위치 | 1단계 처리 |
|---|---|---|
| 영주 아바타 | `Player` 노드 `(240,620)` | **전장 비가시화**(스프라이트/충돌/자동행동 제거). 노드는 권능 발동 임시 거처로 유지(2단계에 `ArtifactSystem` 분리) |
| 자동공격(`A1`) | `Player.gd:136~` | **정지**(basic_timer) |
| 특수기(`A2`) | `Player.gd:170~` | **낙뢰의 홀로 이식**(데미지·×2 끊기·×3 치명타 *재활용*, 입력=3스텝 탭, 게이팅=쿨다운, 전체화면→탭 타겟 강림) |
| 하단 UI | 공격1+소환4+희생1 | **전부 제거 → 권능 버튼 2개**(슬롯 대응·쿨 링·3스텝 탭) |
| 소환 4버튼 | `Game.gd:1149~` | 라이브 소환 제거 → **웨이브 사이 영혼 고용 루프**(§8.3) |
| 희생 | `Game.gd:1050~` | 버튼/입력 비활성(코드 잔존) |
| 패시브 3종 | `death_aura`/`skull`/`curse` | 카드풀 제외(코드 잔존) |
| 키스톤+곱엔진 | `Game.gd:524~` | 선택 UI 비활성, **곱 배수 1.0 고정** |
| `basic_range` | `Player.gd:9` | 폐기 → 검증 2종은 **유물 고유 reach** 하드코딩(낙뢰=전화면/나팔=넉넉) |
| 망령의 나팔 | — | **신규**(통제 권능, §4.4) |

### 8.3 검증 빌드 구성
**손 트랙 — 권능**: 낙뢰의 홀(처치) + 망령의 나팔(통제). **2슬롯 고정**, 3스텝 탭(`RD11`), 쿨다운(`RD9`). 상세 = §4.4.

**영혼 트랙 — 군대**(`RD13`):
- **시작**: 자동 배치 없음. **소량 영혼 지급 → 유저가 직접 첫 편성**(첫 결정 = "뭘 고용할까").
- **고용 메뉴**: 탱크/전사/궁수 3종. **폭탄병 제외**(자폭 예외는 처치/통제 신호를 흐림 → 별도 설계).
- **수입**: 처치 → 영혼 적립(`Enemy`/`Boss` 현행 유지), HUD 표시. 웨이브 클리어 보너스 없음.
- **편성**: 웨이브 사이에 영혼으로 추가 **고용/재고용**(승진·업글은 *보류*). 기존 웨이브 사이 영혼 상점 노드 재활용.
- **지속**: 런 내 영구 누적 + 영구사망(죽으면 영혼으로 재고용). 자동 리필 없음.
- **군대 캡**: 영혼으로 자연 제한(하드 캡 보류).
- **전투 행동**: 수비적 마중 요격(`RD13` — 성 앞 밴드, 돌진X, 침투 적 우선, leash, 블로킹=기존 `MINION_ENGAGE_RANGE`).

**비활성/숨김**: 영주 아바타·자동공격·기존 특수기 UI·키스톤·카드·희생·패시브 3종.

### 8.4 검증 후(2단계) 잔여
편성 메타(승진 내용·군대 캡·풀 편성 UI·출처 하이브리드[보스 충신 편입]) = [03_하인_소환 "재설계" 남은 작업](../03_하인_소환/). 하인 **로스터 다양성 확장**도 편성 경제(승진 깊이 vs 횡적 종 수)가 정해진 뒤 content pass로(아트 추가 의뢰 수반). 유물 전체 풀(≈6~8)·상황 반응형·키스톤 권능 재설계 = §7.
