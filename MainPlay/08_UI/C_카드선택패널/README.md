# C. 카드 선택 패널

> 레이어 **L2 (모달 인터럽트)**. 웨이브 클리어 후 전투를 가리고 뜨는 빌드 선택 화면.
> 런의 핵심 재미 축 — "이번 판에 어떤 빌드로 갈 것인가"를 결정하는 순간.
> ⚠ 상호 배타: 상점(D)·결과(E)와 동시에 뜨지 않음 (상위 README 화면 상태 머신).

## 구성 요소

| ID | 이름 | 노드 경로 | 역할 |
|---|---|---|---|
| C1 | 카드 패널 컨테이너 | `$UI/CardPanel` (Panel) | 카드 행들의 부모 |
| C2 | 패널 타이틀 | `$UI/CardPanel/Title` | 문맥 타이틀 (일반/키스톤 교체) |
| C3 | 카드 행 | 코드 생성 `Control` | 아트칸 + 배지 + 이름 + 설명 + 전체 탭 버튼 |

카드 행은 `_build_card_row()` 한 함수가 등급에 따라 색/배지를 분기해 생성. 별도 키스톤 행 클래스는 없음 — **같은 행을 등급 스타일로 차별화**한다.

## 노출 조건

| 시점 | 호출 | 내용 |
|---|---|---|
| W1 클리어 직후 | `_show_keystones()` | **키스톤 #1** — 키스톤 2종 + 스탯 필러 1종 (총 3행) |
| 중간보스 처치 직후 | `_show_keystones()` | **키스톤 #2** — 동일 구조 |
| 그 외 웨이브 클리어 | `_show_cards()` | 일반 카드 3장 (풀 셔플 후 3장) |

> **키스톤+필러 혼합은 확정 설계**다. 선언 순간에도 "커밋 회피용 안전패"(스탯 필러)를 한 장 끼우는 것이 의도 — 변경 대상 아님([[카드풀 키스톤 설계 (구현 완료)]]에서 합의됨). 필러는 `일반` 등급 스타일을 그대로 입어 키스톤 티어와 자연 대비된다.

전투 일시 정지, 패널만 인터랙션 가능.

## 카드 행 내부 구성 (`_build_card_row`)

| 요소 | 노드 | 역할 |
|---|---|---|
| 배경 | `Panel` (444×120) | 등급별 bg + 테두리 색 |
| 아트칸 | `Panel` (96×96, 좌측) | **아트 플레이스홀더** (단색) — MD11 아트 대기 |
| 등급 배지 | `Panel`+`Label` | 아트칸 상단 걸침. `일반` / `전설` / **`키스톤`** |
| 이름 | `Label` (font 20) | `_card_name(id)` |
| 설명 | `RichTextLabel` (font 14) | `_card_desc(id)` + 축 태그 색 처리 |
| 탭 버튼 | `Button` (전체 투명) | `_pick_card(index)` |

### 축 태그 색 (`_format_axis_tags`)

설명문 안의 축 소속을 색으로 표기 — **키스톤 위계의 토대**:

| 태그 | 색 | 의미 |
|---|---|---|
| `[영주]` | 적색 `#b5341f` | 영주(근원) 축 카드 — `kingdom`/`berserker`/`doom` 키스톤이 스케일 |
| `[군단]` | 청록 `#0a7d6b` | 군단(소환) 축 카드 — `legion`/`horde`/`echo`/`ritual` 키스톤이 스케일 |

카드는 이미 자기 축을 색으로 말하고 있다. 키스톤은 이 축 색을 **카드 전면(테두리)** 으로 끌어올려 "지금 어느 축을 선언하는가"를 즉시 읽히게 한다(아래 위계 참조).

## 등급 위계 (3단)

코드 실재 등급명은 `일반` / `전설` 2단계(`rarity_common`/`rarity_legendary`). UI는 여기에 **키스톤 티어**를 시각적으로 한 단 더 얹어 3단으로 본다:

| 등급 | 조건 | 현행 시각 | 목표 시각 |
|---|---|---|---|
| **일반** | `rare:false` (RARE_CHANCE 0.3 미달) | 라벤더 bg·보라 테두리 | 유지 |
| **전설** | `rare:true` (`ALWAYS_RARE`/스킬카드 강제 포함) | 크림 bg·금색 테두리 + 등장 플래시 | 유지 |
| **키스톤** | `keystone:true` (항상 `rare`) | **⚠ 전설과 동일(금색)** — 구분 없음 | **축 색 티어 + 키스톤 배지 + 등장 강조** |

> **현행 핵심 공백**: `_build_card_row`가 `keystone` 플래그를 읽지 않아, 런 전체 곱엔진을 바꾸는 빌드 선언이 평범한 스탯 전설카드와 픽셀 단위로 동일하다. C의 1순위 작업.

## 설계 확정 (2026-06-09)

**① 키스톤 = 축 색 티어 (전설 위 3단째)**
- 테두리/측면 스트라이프에 **축 색 전면화** — 영주 키스톤=적색, 군단 키스톤=청록
- 배지 텍스트 `전설` → **`키스톤`**, 아트칸에 왕관/쐐기돌 마크
- "내가 영주 빌드를 선언하는가 / 군단 빌드인가"가 한눈에 읽히는 것이 목표

**② 문맥 타이틀 교체 (C2)**
- 키스톤 노출(`_show_keystones`) → "**빌드를 선언하세요**"(가제)
- 일반 노출(`_show_cards`) → "**카드를 선택하세요**"
- 선택의 무게 차이를 타이틀이 먼저 알린다

**③ 등장 위계**
- 키스톤: 스케일-인 + 글로우 **유지**(강한 진입)
- 전설: 현행 `_flash_card_glow` 빠른 플래시(약)
- 일반: 등장 연출 없음

**④ 선택 연출 (기존 자산 — 유지·서핑)**
`_pick_card` → `_spawn_card_pickup_effect(id)`는 **월드 앵커** 연출이다. 카드 카테고리별로 버프가 꽂히는 곳에 펄스링을 띄움:

| 카테고리 | 펄스링 위치 | 색 |
|---|---|---|
| `player` | 영주 위치 | 적색 |
| `castle` | 성 위치 | 청색 |
| `range` | 영주 사거리원 | 보라 |
| `minion` | 각 하인 위치 | 보라 |
| `skill` | (스킬 획득 연출) | — |

카드가 "효과가 착지하는 대상"으로 날아가 꽂히는 공간 연결이 이미 구현돼 있다. 디자이너는 이 연출을 **강화**하는 방향(궤적/잔상), 새로 만들지 말 것.

## 디자인 의제 (잔여)

- **아트칸** — 현재 단색 플레이스홀더. 카드별 일러스트/아이콘은 MD11 아트 입고 후. 그 전까지 카테고리 색 + 마크로 식별.
- **탭 누름 반응** — 버튼이 전체 투명(`StyleBoxEmpty` ×4)이라 눌림 피드백 없음. 스케일/하이라이트 1프레임 검토.
- **텍스트 레이아웃** — 이름(font 20)+설명(font 14, autowrap) 2줄을 height=120 우측 영역에 가독 확보. 설명 길이 편차 점검.
- **명명** — 카드 이름·설명·타이틀 전부 가제(기능 서술). [[세계관 (초보 마왕)]] 피벗 후 톤 명칭으로 일괄 교체.
