# D. 상점 패널

> 레이어 **L2 (모달 인터럽트)**. 상점 웨이브에서 전투 전역을 덮고 나오는 구매 화면.
> 영혼을 소비해 즉각 효과를 사는 "전투 내 회복/강화 포인트".
> ⚠ 상호 배타: 카드(C)·결과(E)와 동시에 뜨지 않음.

## 구성 요소

| ID | 이름 | 노드 경로 | 역할 |
|---|---|---|---|
| D1 | 상점 패널 전체 | `$UI/ShopPanel` (Panel) | 전장 위 전체 오버레이 |
| D2 | 상점 제목 | `$UI/ShopPanel/ShopTitle` | "영혼 상점" (가제) |
| D3 | 상점 아이템 버튼 5종 | `$UI/ShopPanel/ShopItems` (VBoxContainer) | 아이템별 구매 버튼 |
| D4 | 닫기 버튼 | `$UI/ShopPanel/CloseBtn` | 닫고 다음 웨이브 진행 |

## 노출 조건

- 웨이브 타입 = `"shop"` 시 자동 등장 (`_show_shop()`)
- 닫기 → `_close_shop()` → `current_wave += 1` → 다음 웨이브
- 상점 동안: 하단 컨트롤(B)의 소환 컨테이너·슬롯 라벨 숨김

## 상점 아이템 (현재 코드 — 가제, 기획과 불일치)

| # | 이름(가제) | 비용 | 효과 |
|---|---|---|---|
| 1 | 성벽 수리 | 40 | 성 HP +60 |
| 2 | 공격 강화 | 35 | 영주 공격력 +15% |
| 3 | 하인 치료 | 25 | 전체 하인 HP 완전 회복 |
| 4 | 하인 강화 | 18 | 하인 공격력 +10% |
| 5 | 저주 확장 | 30 | 영주 기본 범위 +50 |

⚠ 기획 §10과 다름 — 정본 미결. → [04_성장_경제 미해결 의제](../../04_성장_경제/README.md)

## 버튼 상태

| 상태 | 조건 | 시각 |
|---|---|---|
| 활성 | 영혼 ≥ 비용 | 정상 |
| 비활성 | 영혼 < 비용 | disabled |

텍스트 포맷: `"{이름}  [영혼 N]\n{설명}"` (2줄, height=58)

## 디자인 의제

- **레이아웃** — D3가 VBoxContainer 세로 5개. 그리드/카드형 등 대안 검토.
- **구매 완료 피드백** — 즉각 효과(HP·범위 변화 등) 시각 확인(플래시/사운드) 미설계.
- **닫기 어포던스** — 닫기=구매 종료. 즉시 닫기 vs 확인 팝업 (현재 즉시).
- **타이틀·아이콘** — "영혼 상점" 가제. 아이콘 추가 여부 디자이너 판단.
