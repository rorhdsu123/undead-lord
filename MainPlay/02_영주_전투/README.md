# 02. 영주 전투 (Lord Combat)

> 플레이어 본체의 공격 수단 — 자동 기본 공격, 수동 특수기(영혼 50), 카드로 얻는 패시브 스킬 3종.
> "사용자 결정"의 절반(*특수기 언제 쓸까*)이 여기서 발생. 나머지 절반은 [03 소환 타이밍](../03_하인_소환/).

> ⚠ **재설계 진행 중 (2026-06-12, `RD1~RD14`)** — 참여감 부족을 풀기 위해 **영주 아바타를 전장에서 완전 제거**하고, 입력을 **유물 2 자유 슬롯의 탭 권능(쿨다운, Kingdom Rush 모델)** 으로 재편하기로 결정. 영혼은 군대/경제 트랙으로 재정의. 아래 `책임`·`현재 상태(A1~A7)`·`감각 폴리싱`은 **교체 전 현행 구현**의 기록이다. 새 방향 정본 = [유물_특수기_기획.md](./유물_특수기_기획.md), 근거 = 아래 `결정 로그(재설계)`. 브랜치 `feat/전투-운영자-리디자인`.

## 책임

- 영주 자동 기본 공격 (1.5초마다 광역) — 화면 활기 유지
- 특수기 발동 (공격 버튼, 영혼 50 소모, 쿨 없음) — 전체 적 큰 피해 + 폭발 연출
- 패시브 스킬 자동 발동 (죽음의 오라 / 저주 해골 던지기 / 부패의 저주) — 카드로 해금
- 공격 버튼 상태 표시 (영혼 부족/사용 가능)

## 감각 폴리싱 (2026-06-01)

- ~~**고정 이동 재검토 → 유지 확정.** 이동 풀면 VS 회피 게임 회귀·정체성 붕괴. 기둥 닫음.~~ → **`RD1`이 전제 변경**(2026-06-12): 두 능동 동사(희생·와인드업 치명타) 투입 후 플레이테스트 판정 "여전히 수동" → 아바타 자체를 제거. 고정/이동 논쟁은 *아바타가 없어져* 무의미해짐. (단 "고정-자동 모델의 수동성" 예견은 적중)
- **기본 사거리 280 확정.** 기획서 400은 피벗 전 수치. 280은 적이 사거리 안까지 밀고 들어와 압박·긴장 유지 + 특수기 "밀어내기" 판돈을 살림. 400은 화면을 비워 오히려 수동성↑. 코드(280)가 의도에 가까움.
- **타격감 추가 (진행):** 히트스톱(특수기 순간 정지) + 넉백(기본/특수기로 적 밀어냄, 타입 질량 = hp_mult로 저항) + 타격 스케일 펀치. 데미지 숫자·히트 플래시·스크린 셰이크·폭발은 기존 보유. 수치는 밸런스로 후순위(튜닝값).

## 미해결 의제
- **특수기 ↔ 보스 와인드업 치명타** — ×2/캔슬/스턴은 [05_보스](../05_보스/)에서 기획만 확정, 미구현. 발동 지점은 `_on_attack_pressed`에서 보스 와인드업 체크 추가 예정.
- **영혼 소모 결정의 무게 — 방향 결정됨 (2026-05-30, →[03 MD6](../03_하인_소환/))** — 특수기 영혼 공유는 잉여 *배출구*로 유지하되, 근본 원인("하인 안 죽으면 슬롯 고정 → 영혼 잉여 → 정체")은 **하인 희생 액션**으로 해소. 특수기↔희생 역할분리: **특수기=영혼50 전체화면 버스트 / 희생=하인 위치 국소 폭발**. 영혼 환급안 기각(영혼 남는 게 문제라 잉여 가중). 디테일(수치·비용/쿨)은 밸런스로 후순위.

| `RD13` | **하인 전투 활용 재설계 — 런 내 영구 누적 군대 + 영혼 경제 편성 + 수비적 마중 요격 + 영구사망.** 라이브 소환 4버튼·슬롯(`max_minions`)·희생 버튼 모델([03 MD1~MD10](../03_하인_소환/)) 폐기. 영혼=처치당 적립→웨이브 사이에 편성·승진 소비. 하인은 성 앞 수비 밴드에서 *마중 요격*(돌진 안 함, 침투 적 우선, leash), 블로킹=기존 어그로 반경 재활용. 상세 스펙·보류 의제 = [03_하인_소환 "재설계" 섹션](../03_하인_소환/). | `RD7`(하인 자동)·`RD10`(영혼 경제) 구체화. **영구 누적** = 로그라이트 빌드 트랙(카드/키스톤과 병렬 성장, 군대 애착). **영구사망** = 권능 보호 동기 최강 + 실패 완충은 메타(런 밖: 왕관·해골·EXP). **마중 요격** = 고정라인(이미 롤백)·돌격형(영구사망인데 정예를 적진 투하) 사이의 수비 절충. **블로킹** = `Enemy.MINION_ENGAGE_RANGE` 어그로 이미 작동 → 하드 바디블록 신설 불필요. 라이브 지휘 부재(`RD7`)는 권능 선택이 간접 대체(나팔=하인 재정비 시간/낙뢰=새는 적 제거). 기각: 재생형(완충이 메타에 있어 영구사망이 정직), 돌격형, 고정라인. 보류(편성 메타): 승진 내용·군대 캡·편성 UI |

**RD가 무효화하는 현행 기록:** `A1`(자동 기본공격) 제거 예정, `A2`(전체화면 특수기)→기본 유물로 흡수, `A4~A6`(패시브 3종)·`A7`(고정)·`basic_range`(권역 폐기로 의미 상실) 재매핑 대상. 추가로 **소환 4버튼→웨이브 사이 편성으로 이전**, **희생 버튼/`keystone2=ritual`→유물화**, **`keystone1=legion`(소환사) 정체성 재정의** → 기획서 §7 남은 작업 4번.
