# 02. 영주 전투 (Lord Combat)

> 플레이어 본체의 공격 수단 — 자동 기본 공격, 수동 특수기(영혼 50), 카드로 얻는 패시브 스킬 3종.
> "사용자 결정"의 절반(*특수기 언제 쓸까*)이 여기서 발생. 나머지 절반은 [03 소환 타이밍](../03_하인_소환/).

## 책임

- 영주 자동 기본 공격 (1.5초마다 광역) — 화면 활기 유지
- 특수기 발동 (공격 버튼, 영혼 50 소모, 쿨 없음) — 전체 적 큰 피해 + 폭발 연출
- 패시브 스킬 자동 발동 (죽음의 오라 / 저주 해골 던지기 / 부패의 저주) — 카드로 해금
- 공격 버튼 상태 표시 (영혼 부족/사용 가능)

- `scripts/Player.gd` — 영주 본체
  - 스탯 — `attack_damage 20`, `attack_speed`, `basic_range 280`, `aura_radius 80`, `curse_radius 120` (3–11줄)
  - 스킬 보유 플래그 — `has_death_aura / has_skull_throw / has_decay_curse` (14–16)
  - 발동 간격 상수 — `BASIC/AURA/SKULL/CURSE_INTERVAL` (24–27)
  - 타이머 기반 자동 발동(`_physics_process` 흐름), 사거리 인디케이터(`_create_range_indicators` 88–)
  - `scenes/Skull.tscn` + `scripts/Skull.gd` — 저주 해골 투사체
- `scripts/Game.gd`
  - `_on_attack_pressed()` (846) — 특수기 발동 진입 (`SPECIAL_COST = 50`, 39줄)
  - `_update_attack_button()` (858) — 버튼 가용 상태
  - `spawn_explosion_effect()` (1078) — 특수기 폭발 연출
  - `attack_bonus`(34), `_apply_facility_bonuses()`(874) — 시설/카드 공격 보너스 합산

## 감각 폴리싱 (2026-06-01)

- **고정 이동 재검토 → 유지 확정.** 이동 풀면 VS 회피 게임 회귀·정체성 붕괴. 기둥 닫음. 단, 고정-자동 모델의 진짜 위험은 *일반 웨이브 × 셀프캐리*의 수동성 — 새 능동 동사(B안)는 시기상조(희생 액션·와인드업 치명타 두 능동 동사가 들어온 뒤 플레이테스트로 재판단). 수동성은 페이싱·타격감으로 우선 해소.
- **기본 사거리 280 확정.** 기획서 400은 피벗 전 수치. 280은 적이 사거리 안까지 밀고 들어와 압박·긴장 유지 + 특수기 "밀어내기" 판돈을 살림. 400은 화면을 비워 오히려 수동성↑. 코드(280)가 의도에 가까움.
- **타격감 추가 (진행):** 히트스톱(특수기 순간 정지) + 넉백(기본/특수기로 적 밀어냄, 타입 질량 = hp_mult로 저항) + 타격 스케일 펀치. 데미지 숫자·히트 플래시·스크린 셰이크·폭발은 기존 보유. 수치는 밸런스로 후순위(튜닝값).

## 미해결 의제
- **특수기 ↔ 보스 와인드업 치명타** — ×2/캔슬/스턴은 [05_보스](../05_보스/)에서 기획만 확정, 미구현. 발동 지점은 `_on_attack_pressed`에서 보스 와인드업 체크 추가 예정.
- **영혼 소모 결정의 무게 — 방향 결정됨 (2026-05-30, →[03 MD6](../03_하인_소환/))** — 특수기 영혼 공유는 잉여 *배출구*로 유지하되, 근본 원인("하인 안 죽으면 슬롯 고정 → 영혼 잉여 → 정체")은 **하인 희생 액션**으로 해소. 특수기↔희생 역할분리: **특수기=영혼50 전체화면 버스트 / 희생=하인 위치 국소 폭발**. 영혼 환급안 기각(영혼 남는 게 문제라 잉여 가중). 디테일(수치·비용/쿨)은 밸런스로 후순위.
