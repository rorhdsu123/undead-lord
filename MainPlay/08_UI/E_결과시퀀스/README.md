# E. 결과 시퀀스 (오버레이 → 패널)

> 레이어 **L2 (모달 인터럽트)**. 런이 끝날 때(게임오버/클리어) 뜨는 결과 화면.
> **컬러 오버레이 페이드인 → 결과 패널 등장**이 끊김 없는 한 연출이라 하나의 단위로 묶음.
> ⚠ 상호 배타: 카드(C)·상점(D)과 동시에 뜨지 않음.

## 구성 요소

| ID | 이름 | 구현 | 역할 |
|---|---|---|---|
| E0 | 컬러 오버레이 | 코드 생성 ColorRect | 패널 등장 전 화면 물들이는 전조 연출 |
| E1 | 결과 제목 | `$UI/ResultPanel/ResultLabel` | "스테이지 클리어!" / "성이 함락됐다..." (가제) |
| E2 | 부제 | `$UI/ResultPanel/SubLabel` | 스테이지 번호 / 도달 웨이브 |
| E3 | 기록 시간 | `$UI/ResultPanel/TimeLabel` | "N분 00초" |
| E4 | 보상 | `$UI/ResultPanel/CrownLabel` | 왕관 조각 +N, 위엄 EXP +N (가제) |
| E5 | 버튼 1 | `$UI/ResultPanel/Btn1` | 다음 스테이지 / 다시 시작 |
| E6 | 버튼 2 | `$UI/ResultPanel/Btn2` | 로비로 돌아가기 |

## 연출 시퀀스 (2단계)

```
[전투 정지] → E0 오버레이 페이드인 → [잠깐 유지] → ResultPanel 등장
   적·하인         0.6~0.9초          0.3초          (E1~E6 채워짐)
   physics 정지
```

| 케이스 | 트리거 | E0 오버레이 색 |
|---|---|---|
| 게임오버 | 성 HP = 0 | 붉은 `Color(0.4, 0, 0)` → α 0.55 (0.9초) |
| 클리어 | 최종 보스 처치 / 전체 웨이브 완료 | 금빛 `Color(0.9, 0.8, 0.1)` → α 0.4 (0.6초) |

## 상태별 내용

### 게임오버
```
E1: "성이 함락됐다..."                     (가제)
E2: "스테이지 1-2  웨이브 3"
E3: "2분 15초"
E4: "왕관 조각 +1 (총 3개)\n위엄 EXP +5"   (런 중 획득 있을 때만)
E5: "↩  다시 시작"
E6: "로비로 돌아가기"
```

### 스테이지 클리어
```
E1: "스테이지 클리어!"                     (가제)
E2: "1-2 완료"
E3: "3분 40초"
E4: "왕관 조각 +5 (총 8개)\n위엄 EXP +20"
E5: "다음 스테이지"  (마지막 스테이지면 비활성)
E6: "로비로 돌아가기"
```

## 보상 표시 규칙

- **왕관 조각**: 런 중 획득 시에만 표시, 없으면 빈 문자열
- **위엄 EXP** (런당 1회): 게임오버 +5(실패 완충) / 일반 클리어 +20 / 보스 스테이지 +40

## 디자인 의제

- **E0→패널 연출 일체화** — 오버레이와 패널은 한 흐름. 패널 자체 등장 애니(슬라이드/팝)를 오버레이 페이드와 이어 설계.
- **게임오버 vs 클리어 차별화** — 오버레이 색 외 패널 레이아웃·폰트도 분리(패배=차갑고 무거움 / 클리어=밝고 경쾌).
- **보상 가독성** — E4가 왕관+위엄을 줄바꿈으로 합침. 아이콘+수치 분리로 향상.
- **버튼 위계** — 게임오버=다시 시작(주)/로비(보조), 클리어=다음 스테이지(주). 주행동 강조.
- **명명** — 전 텍스트 가제.
