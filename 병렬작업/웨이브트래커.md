# 웨이브 트래커 작업 영역

> 상단 캡슐형 웨이브 노드 스트립(현재 웨이브·아이콘·디졸브).

## 담당 파일
- `scripts/WaveTracker.gd` — 트래커 빌드/갱신/렌더 + 아이콘/색 const

## 책임 (이 안에서 자유)
- 트래커 표시·윈도우 계산(`_compute_wave_display`)·렌더(`_render_wave_tracker`·`_make_badge_column`)
- 노드 종류별 아이콘/색(`TRACKER_ICON_*`·`TRACKER_COLOR_*`·`TRACKER_BADGE_SIZE`)
- 크로스페이드 디졸브·하이라이트 이동(`update_wave_tracker`)·등장(`_reveal_wave_tracker`)

## 경계 — 건드리지 말 것
- `game.wave_tracker`(트래커 노드)·`game.current_chapter/stage/wave`·`game._last_tracker_sig` → Game 소유, game. 경유.
- 웨이브 **데이터**(`WaveData.CHAPTERS`)는 읽기만 — 웨이브 구성 변경은 `scripts/WaveData.gd`(별도).
- 외부 호출 0인 도메인이라 facade 없음. Game `start_wave`가 `wave_tracker_ui.X`로 호출.

## 아이콘/색 바꾸기
- `WaveTracker.TRACKER_ICON_*`(👾💰👹💀)·`TRACKER_COLOR_*` 수정.

## 안전 편집
- 노드 추가는 `game.wave_tracker.add_child(...)` (bare `add_child` 아님).
- 검증: `godot --headless --quit-after 5 scenes/Game.tscn 2>&1 | grep -iE "error|not found"`
