# 마물(소환) 작업 영역

> 하인 소환 UI·스폰·생애주기. (강화는 별도 → [강화.md](./강화.md))

## 담당 파일
- `scripts/MinionSystem.gd` — 소환 버튼·소환 입력·스폰·`minion_died`
- `scripts/data/MinionData.gd` — `MINION_TYPES`(로스터·비용) · `HIRE_*`(고용 경제)

## 책임 (이 안에서 자유)
- 하인 종류/비용 로스터(`MINION_TYPES`)·고용 게이팅(`_is_summon_unlocked`)
- 소환 버튼 UI·입력(`_build_summon_buttons`·`_refresh_summon_buttons`·`_on_summon_pressed`)
- 스폰 시 스탯/보너스 적용(`_spawn_minion`)·사망 처리(`minion_died` — horde 환급·echo 폭발)

## 경계 — 건드리지 말 것
- 공유 상태: `game.souls`·`game.active_minions`·`game.max_minions`·`game.hire_levels`·`game.minion_*_bonus`·키스톤 변수 → game. 경유.
- `game.summon_btns` 등 소환 버튼 배열은 Game 소유(튜토리얼이 참조) → game.
- **`minion_died`는 Game facade로 SkeletonWarrior(액터)가 호출**(`game.minion_died`). 시그니처 바꾸면 SkeletonWarrior.gd + facade 동시 확인.
- 카운트 readout(`_update_minion_readout`)·강화 UI는 **이 영역 아님**(Game 본체/강화).

## 하인 추가/밸런스
- 로스터·비용: `MinionData.MINION_TYPES`
- 강화 밸런스: `MinionData.HIRE_UPGRADE_*` (강화 영역과 공유 데이터)
- 스폰 스탯: `_spawn_minion` (`game.minion_attack_bonus` 등 game. 경유)

## 안전 편집
- ⚠️ `m.game = game` 패턴(스폰 시 미니언에 허브 주입) — `self` 아님 주의.
- 외부 호출 함수: `minion_died`·`_refresh_summon_buttons`·`_build_summon_buttons`·`_spawn_minion`(이미 Game facade/repoint됨).
- 검증: `godot --headless --quit-after 5 scenes/Game.tscn 2>&1 | grep -iE "error|not found"`
